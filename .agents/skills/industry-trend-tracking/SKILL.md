# Industry Trend Tracking (申万行业产业趋势跟踪)

本技能定义申万 31 行业在**周期尺度（季度/半年）全球产业趋势确认与跟踪**中的端到端标准操作流 (SOP)
与量化工程规范。它与 [`industry-rotation-strategy`](../industry-rotation-strategy/SKILL.md) 是两套独立体系：

| 维度 | 行业轮动 (rotation) | 产业趋势跟踪 (trend tracking) |
| :--- | :--- | :--- |
| 尺度 | 20-60 日截面博弈 | 季度/半年周期 |
| 矛盾 | A 股内部截面矛盾 | 全球资本开支方向 × A 股供应链承接 |
| 主信号 | 动量/剪刀差/拥挤度 | 全球方向 × 量价齐升 × 议价权 + 现实景气 |
| 目标 | 轮动超额 | 真景气产业的趋势确认与拐点预警 |

## 核心量化原则 (Ground Truth First)

1. **三层共振框架是唯一判定标准**（详见 [`framework.md`](references/framework.md)）：
   - **方向层**：资本开支是不是全球性的（全球景气代理向上：费半 SOX / 光伏装机 / 半导体销售额 / 机器人出货）；
   - **供需层**：承接的是需求驱动还是产能过剩（量价齐升 = 营收 + 净利双正）；
   - **议价权层**：这个制造环节有没有定价权（毛利率扩张 = 净利增速 > 营收增速，微笑曲线偏上非代工）。
   **三层同时成立才是「真全球景气」**；只满足方向（如光伏产能过剩）不是真 alpha。
2. **趋势确认而非追高**：季度调仓追「景气环比改善」而非「景气绝对高低」。已验证：环比改善把样本外
   Sharpe 从 0.22 提升到 0.39（+77%）。
3. **现实景气优于预期景气**：业绩预告向好占比 + 快报利润增速中位数样本外走强（IC 走强），
   分析师预期样本外衰减。主信号必须基于业绩预告/快报，不基于分析师一致预期。
4. **拥挤度防守**：成交额占比高位一票否决/减仓，样本外风险翻倍，防守可把回撤 42% → 26%。
5. **严格 T+1 与摩擦成本**：信号当日收盘生成，次日开盘执行，扣佣金（万一）+ 滑点（万五）+ 3% 调仓死区。
6. **拐点预警来自全球指标，不来自 A 股内部**：拥挤度滞后、环比噪声大，A 股内部信号做不出拐点
   （已验证全劣于不退出）。拐点的正确信号是「全球资本开支见顶」。

## 拐点预警决策矩阵

| 全球景气状态 | 核心信号特征 | 产业趋势动作 |
| :--- | :--- | :--- |
| 全球资本开支向上 + 量价齐升 + 毛利率扩张 | 三层共振全成立 | 持有真景气行业，季度再平衡 |
| 全球资本开支见顶（SOX/装机/出货转弱） | 方向层转负 | **拐点预警**：减仓/退出，不赌 A 股内部反弹 |
| 量价齐升破坏（营收或净利转负） | 供需层转负 | 剔除供给收缩/双负行业 |
| 拥挤度极端（tcr ≥ 85%） | 防守信号 | 一票否决过热行业 |

## 标准执行 SOP (5 步工作流)

### Step 1: 生成产业趋势因子面板
```bash
uv run python -m stock_cli.industry_trend_factors
```
检查面板字段：`direction_score`（全球方向，数据缺口时中性 50）、`supply_demand_score`（量价齐升）、
`bargaining_score`（议价权）、`prosperity_score`（现实景气）、`crowding_score`（拥挤度）、
`composite_trend_score`（复合趋势得分）、`trend_momentum`（环比改善）。

### Step 2: 回测趋势跟踪策略
```bash
uv run python -m stock_cli.industry_trend_strategy --strategy industry_trend_momentum
```
- 基线（`industry_trend_momentum`）：季度调仓追 `trend_momentum`，样本外 Sharpe ≈ 0.39；
- 增强（`industry_trend_quality`）：叠加供需质量门（`supply_demand_min`）+ 拥挤度一票否决（`crowding_max`）。

### Step 3: 验证样本外稳定性
所有改进必须用 2022-01-01 之后样本外检验（对齐国泰海通拆分），不拿全样本刷参数。
样本内 0.47 / 样本外 0.15 的「分析师预期」就是反例。

### Step 4: 三层共振确认真景气
对候选行业按 [`framework.md`](references/framework.md) 做三层判定：
方向（全球 capex 向上）× 供需（量价齐升）× 议价权（毛利率扩张），三者缺一不可。

### Step 5: 拐点预警（数据补齐后启用）
全球指标（SOX/装机/出货）见顶 → 方向层转负 → 触发拐点预警减仓/退出。
当前方向层为数据缺口（`direction_score` 中性 50），接入后替换。
