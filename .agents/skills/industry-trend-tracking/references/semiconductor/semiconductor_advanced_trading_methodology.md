## 一、实战痛点与四大进阶升级

现有基于宏观中观供需（TSMC+SIA vs SEAJ）的剪刀差地基在长周期回测中表现优异（样本外 MaxDD 控制在 26%~29%），但在真实高烈度博弈中暴露了三项实战短板：

| 现有方法论短板 | 2024-2026 实战暴露的事实证据 | 本进阶方法论升级解决方案 |
| :--- | :--- | :--- |
| **痛点一：顶部逃顶滞后 2-3 周** | 2026-06-30 板块在 14332 点见顶，而剪刀差直至 07-21 才翻负（−2.78）。触发防守门时指数已自高点下挫 **−12.7%**，存在明显的顶部钝化时滞。 | **引入海关进出口高频微观雷达**（月频 T+20）：海关芯片出口数量增速在 5-6 月已断崖跌至 **+2.2%**，配合均价 ASP 暴涨打上**“二阶导见顶”**标签，提前 2-3 周发出顶部预警。 |
| **痛点二：高频流量存在成本与内卷盲区** | 海关出口虽然能量化离岸均价（ASP），但无法穿透企业成本结构。如 2026 中报半导体材料营收 TTM 增 **+37.4%**，但净利润暴跌 **−48.0%**（严重增收不增利）。 | **建立毛利率前瞻推演模型**：通过**“晶圆代工 96% 稼动率折旧摊薄 + 海外 8-K 指引 + 海关价差模型”**，提前 1-2 季度锁定企业真实毛利率方向，识破低价内卷。 |
| **痛点三：散户看利润追高，或完全忽视财报** | 2026 中报披露全行业利润大增 **+148.8%**，散户看财报追高买在暴跌起点；另一极端是完全忽视财报，买中存货与商誉暴雷标的。 | **确立“财报攻防双轨制”**：损益表仅作事后逻辑验证（严禁看利润追高）；资产负债表（DOI/负债率）与现金流作排雷底线（DOI≥70 强制防守）。 |
| **痛点四：行业 Beta 极热，个股 Alpha 严重分化** | 2026 年板块暴涨期间，数字芯片设计（270104）毛利率高达 43.2%（ROE 21.6%），而分立器件（270102）ROE 为 **−5.59%** 深度亏损。 | **建立三级子行业阿尔法筛选与轮动矩阵**：优选高毛利与设备国产化龙头，坚决剔除低端同质化价格内卷子行业。 |

## 二、子系统一：海关进出口微观量价雷达（高频择时引擎）

### 2.1 数据源与字段契约
- **本地黄金表**：`data/curated/industry/customs_trade.parquet` 与 `data/analytics/industry/customs_product_volume_price.parquet`；
- **核心商品**：集成电路芯片（`8542`）、半导体设备（`8486`）；
- **核心特征**：`export_value_usd`（金额）、`export_volume`（物理数量）、`asp_3mma`（加权成交均价）、`volume_yoy_3mma`（数量一阶导）、`price_yoy_3mma`（价格一阶导）、`二阶导`（增速变化方向）。

### 2.2 量价四象限判定规则

依据 `docs/research/customs_export_forward/METHODOLOGY_FINAL.md:50-56`：

```
                    均价 ASP YoY > 0
                           ▲
          【价驱动】        │       【量价齐升】
    (供给收缩/顶部前兆)      │    (最健康扩张，主升持有)
    数量 YoY ≤ 0 ──────────┼──────────► 数量 YoY > 0
          【双弱】          │       【量驱动】
    (衰退出清，坚决回避)     │    (放量降价，以价换量)
                           │
                    均价 ASP YoY ≤ 0
```

### 2.3 拐点与二阶导实战杀手锏（高频买卖点）

1. **底部买入拐点（黄金坑特征）**：
   - **判定条件**：出口数量增速率先由负翻正（$Q_{\text{yoy}} > 0$），且均价 ASP 跌幅大幅收窄或转正；
   - **实战案例**：
     - **2024-02（2702 点大底）**：数量连续在 300 亿只上方筑底，海外控产减产推动芯片 ASP YoY 暴增至 **+43.6%**，虽然数量仍负但价格底已现，提示左侧大底；
     - **2026-03（6887 点大底）**：单月出口破 286 亿美元，数量增长稳定在 +13.5%，均价 ASP YoY 飙至 **+57.3%**，量价齐升彻底确立，随后 3 个月暴涨 +108%。
2. **顶部逃顶拐点（二阶导顶背离）**：
   - **判定条件**：**数量增速连续断崖式下滑（二阶导打上“量增速回落”），而金额全靠均价 ASP 暴涨支撑**；若同时叠加“最新季度财报利润仍在高增”，触发定稿规则中的**“最危险组合（量回落 × 财报仍加速）”**；
   - **实战案例**：
     - **2026-06（14332 点峰值）**：芯片出口数量增速从 3 月的 +13.5% 骤降至 6 月的 **+2.2%**，7 月萎缩至 **+1.2%**，出货量已实质停滞；而均价 ASP YoY 被推高到 **+108.9%** 与 **+115.6%**（虚假繁荣）；
     - 此时 2026 中报利润暴增 +148.8%，完美契合“最危险组合”；比中观剪刀差转负（07-21）**提前整整 3 周发出强烈的离场减仓指令**。

## 三、子系统二：毛利率与净资产前瞻推演工程（微观弹性洞察）

### 3.1 毛利率（Gross Margin）前瞻三大测算模型

$$\text{毛利率} = 1 - \frac{\text{单位营业成本}}{\text{单位售价 (ASP)}} = 1 - \frac{\text{单位变动成本} + \frac{\text{固定折旧}}{\text{出货量}}}{\text{ASP}}$$

1. **模型一：产品价格 vs 原材料成本的价差模型（日/周频）**：
   - 跟踪海关 ASP 均价与上游晶圆代工费、高纯材料报价的价差，价差走阔直接预告 1-2 季度后财报毛利率的扩张。
2. **模型二：产能利用率（稼动率）的经营杠杆模型（月/季初）**：
   - 数据源：`data/curated/industry/foundry_capacity_utilization.parquet`；
   - 规则：当台积电（TSMC）与中芯国际（SMIC）稼动率冲破 **95%**（`tight_overheated`）且芯片交期超 30 周时，固定资产折旧被天量出货量非线性摊薄，单片折旧成本腰斩，**代工与封测环节毛利率必然在下季度出现爆发式跳涨**。
3. **模型三：海外设备龙头法定 8-K 前瞻指引模型（季频，领先 1 季）**：
   - 数据源：`data/curated/industry/semiconductor_equipment_gm_multi.parquet`；
   - 规则：监测泛林（LRCX）、科磊（KLAC）、应用材料（AMAT）官方披露的 `gm_guidance_next_pct`（下一季度毛利率指引中枢）。海外指引上修直接作为国内半导体设备与先进制程链条的技术性毛利率上行先导。

### 3.2 净资产积累的先导现金流雷达
1. **自由现金流（$\text{FCF} = \text{OCF} - \text{CapEx}$）爆发拐点**：
   - 当行业经历 2-3 年逆周期扩产后，CapEx 开始断崖收缩（设备出货增速放缓）；此时需求微升，经营现金流充沛而无资本开支失血，企业 FCF 暴增、大额偿还负债，净资产进入最高质量的实质积累期。
2. **现金循环周期（CCC）与 DOI 去库联动**：
   - 原厂库存 DOI 从 180 天下行至 140 天，配合客户预付款激增，资产负债表在季度披露前即通过高频银行流水确证净资产质量的大幅提升。

## 五、子系统四：攻防双轨操作手册（Playbook 决策时序）

```
[阶段一：左侧出清大底] ──► [阶段二：右侧主升满仓] ──► [阶段三：过热顶背离减仓] ──► [阶段四：硬约束防守清仓]
- 剪刀差由负翻正            - 剪刀差处正值高位          - 海关数量增速骤降至接近0      - 剪刀差翻负 (scissors < 0)
- 海关ASP跌幅收窄/转正      - 海关确认"量价齐升"        - 纯靠ASP翻倍拉升总金额       - 原厂DOI高危 (DOI ≥ 70分位)
- 云CapEx见底回升           - 代工稼动率 > 95%          - 触发"量回落 × 财报仍加速"   - 强制清仓锁利，避开深跌
【买入 50% 底仓】            【加满至 100% 进攻仓位】     【平稳降仓至 30%-50%】        【直接空仓 / 权重归零】
```

### 1. 阶段一：左侧出清与买点触发（建仓 50%）
- **触发条件**：
  1. 剪刀差 `scissors_score` 从长期负值区间突破 0 轴（由负翻正）；
  2. 海关芯片出口均价（ASP）同比降幅连续 2 个月大幅收窄，或率先转正；
  3. 北美云厂商 CapEx 季调环比不再恶化。
- **执行动作**：不理会此时损益表上的巨额亏损财报（如 2024 年初利润 -48%），果断买入 50% 仓位。

### 2. 阶段二：右侧主升浪确认（满仓 100%）
- **触发条件**：
  1. 剪刀差持续处于 `> +20` 的健康扩张期；
  2. 海关出口确立为最健康的**“量价齐升”**驱动（数量增 +15%~+20%，ASP 均价逐月抬升）；
  3. 代工产能利用率回升至 90% 以上，海外 8-K 毛利率指引上修。
- **执行动作**：加满至 100% 进攻仓位，核心配置第一梯队（数字设计 + 设备），坚定持股吃满主升浪。

### 3. 阶段三：过热与二阶导顶背离（主动收缩至 30%~50%）
- **触发条件**：
  1. 海关芯片出口数量增速出现断崖式减速（二阶导明确打上**“量增速回落”**，如降至 +2% 附近）；
  2. 出口金额完全依靠单价 ASP 暴涨维系（价驱动/量滞胀）；
  3. 市场成交额占比达历史极端分位（`share_pct_250 ≥ 90`），且最新财报利润增速异常靓丽（“量回落 × 财报加速”陷阱）。
- **执行动作**：主动止盈，仓位降至 30%~50%，绝不追高。

### 4. 阶段四：硬约束双触发强制清仓（仓位归零 / 0.3 防守权重）
- **触发条件**（`config/strategy/semiconductor_research.yaml:31-36` 硬纪律）：
  1. 供需剪刀差正式跌破 0 轴（`scissors_score < 0`）；
  2. 原厂库存处于高危过剩区（`idm_weighted_doi_pct ≥ 70` 分位）。
- **执行动作**：**无条件强制清仓 / 锁定防守**，彻底屏蔽“财报利润依然很好”的噪音诱惑，规避随后的流动性踩踏与估值暴跌（如 2026-07 成功躲过 -33% 暴跌）。

## 六、量化管线调用契约（Python API 范式）

本套进阶方法论在量化策略代码中可直接通过以下统一接口实现特征提取与状态判定：

```python
import polars as pl
from stock_data.catalog import DataCatalog
from stock_data.core.runtime import DataRuntimeContext

runtime = DataRuntimeContext.from_root("data")
cat_industry = DataCatalog(data_source="industry", runtime=runtime)
cat_lx = DataCatalog(data_source="lixinger", runtime=runtime)

# 1. 提取微观海关量价雷达特征 (数量一阶导、均价 ASP、二阶导)
pvp_df = pl.read_parquet("data/analytics/industry/customs_product_volume_price.parquet")
ic_radar = pvp_df.filter(pl.col("product_key") == "semiconductor_ic").select([
    "report_month", "value_yoy_3mma", "volume_yoy_3mma", "price_yoy_3mma", "asp_3mma", "驱动类型", "二阶导"
])

# 2. 提取中观供需剪刀差与原厂 DOI 状态机
panel_df = pl.read_parquet("data/curated/mart/semiconductor_research_panel.parquet")
state_machine = panel_df.select([
    "trade_date", "scissors_score", "idm_weighted_doi_days", "idm_weighted_doi_pct", "defense_trigger", "offense_trigger"
])

# 3. 提取前瞻毛利率指引与代工稼动率
gm_lead = pl.read_parquet("data/curated/industry/semiconductor_equipment_gm_multi.parquet")
foundry_util = pl.read_parquet("data/curated/industry/foundry_capacity_utilization.parquet")

# 4. 执行状态判定 (四阶段状态机)
def evaluate_playbook_state(radar_row, state_row):
    if state_row["defense_trigger"]:
        return "STAGE_4_DEFENSE_CLEAR"     # 阶段四：清仓防守
    elif radar_row["二阶导"] == "量增速回落" and radar_row["volume_yoy_3mma"] < 0.05:
        return "STAGE_3_TOP_DIVERGENCE"    # 阶段三：量背离减仓
    elif state_row["scissors_score"] > 20 and radar_row["驱动类型"] == "量价齐升":
        return "STAGE_2_OFFENSE_FULL"      # 阶段二：量价齐升满仓
    elif state_row["scissors_score"] > 0 and radar_row["volume_yoy_3mma"] > 0:
        return "STAGE_1_BOTTOM_BUILD"      # 阶段一：出清筑底建仓
    return "NEUTRAL"
```

## 七、一句话终极提炼

> **半导体进阶交易体系 = 海关量价二阶导（高敏微观雷达）定逃顶抄底时机 + 供需剪刀差与原厂 DOI（中观状态机）定攻防底座 + 稼动率与价差模型定毛利率扩张 + 财报三张表严格验真排雷。四位一体，攻防正交，方能驾驭半导体极速暴涨与暴跌的周期脉搏。**
