# 半导体周期状态定位 vs 交易逻辑分层（定位层 / 操作层）

> 2026-09 复盘留痕：回答"剪刀差方法论是交易逻辑（微观），周期状态是宏观吗"——不是微观/宏观的并列，
> 而是**定位层（现在在哪）→ 操作层（该怎么交易）**的传导链。本文把该结论与"加库存补全周期定位"
> 的验证一并归档。数据口径：270100（申万半导体），2018-01~2026-08 复算，fwd60、无前视。

## 一、核心命题：不是"微观 vs 宏观"，是"定位层 vs 操作层"

| | 剪刀差方法论（交易逻辑） | 周期状态（含库存） |
| :-- | :-- | :-- |
| 回答的问题 | **怎么做**——何时 LONG、何时防守、何时进攻 | **在哪**——当前处于周期哪个阶段 |
| 输出 | 可执行的信号/动作（scissors>20、剪刀差<0、demand≥70×剪刀差≥0） | 环境认知（复苏/过热/衰退/去库） |
| 性质 | 操作/择时层 | 状态/定位层 |
| 时间尺度 | 时点决策 | 区间/阶段 |

两者不是并列层次，而是**"定位 → 操作"的传导**：周期状态描述"现在是什么阶段"，
交易逻辑决定"这个阶段该怎么交易"。定位是操作的上下文，操作是定位的落地。

## 二、剪刀差 = 周期状态的量化切片

剪刀差 = 需求 − 供给，它本身就是供需维度上的周期状态——只是被拿来当交易信号。
所以两者不是割裂层次，而是**同一个东西的两个用法**：

- 用于决策时 → 是"交易逻辑"（LONG/AVOID/防守、进攻脚）
- 用于描述阶段时 → 就是"周期状态"（供需相对位置）

框架把剪刀差操作化了（压缩成信号），所以观感上"只指导交易、没直接说周期状态"，
缺的只是把状态含义显式表达出来，而不是再造一个信号。

## 三、加库存补全周期定位（衔接"需求×供给象限 + 库存"提议）

框架天然已按此分层：

1. **inventory_score 已是独立的"供给端确认腿"**（`semiconductor_supply_legs`），
   机制上只在贴顶区（≥80）有效（见 `mechanism_factor_saturation.md`）——
   它是**定位**工具，不是独立择时信号。
2. **防守门盲区审计**（`semi_defense_gate_2026.md`）证明纯供需维度**无法区分某些周期状态**：
   2026-07 供需都正常（剪刀差正、DOI 41.7），却是需求/情绪面的疯狂牛末端——这类状态要靠
   库存（堆积确认）+ 拥挤（`share_pct_250`）来定位，供需维度看漏了。

### 三维验证（需求 × 剪刀差 × 库存，2018-2026 复算）

| 组合 | n | fwd60 中位 | 上涨率 | 对应阶段 |
| :-- | :--: | :--: | :--: | :-- |
| 需求高 \| 剪刀负 \| 库存低 | 258 | +5.2% | 66% | 2021/2025/2026 扩张 |
| 需求低 \| 剪刀负 \| 库存高 | 261 | +0.3% | 51% | 2022/2023 去库 |
| 需求低 \| 剪刀正 \| 库存高 | 650 | +1.2% | 54% | 2017-2023 混合 |
| 需求高 \| 剪刀负 \| 库存中 | 75 | +1.3% | 51% | 2022/2026 |

**诚实标注（三维的边界）**：
- 样本稀疏（多数格子 n<100），早期（2014-2017）inventory_score 缺失/平台，颗粒度有限；
- 库存只在贴顶区有预测力（IC +0.309，`mechanism_factor_saturation.md`），低/中区间无区分度；
- 因此**库存适合做"定位层"辅助理解（库存贴顶=过热末端、低库存=复苏确认），
  不适合强行并入剪刀差做"操作层"信号**。

## 四、一句话收束

**剪刀差方法论是交易逻辑（操作层），周期状态是更宏观的定位（状态层）——但它们不是微观/宏观
两个并列层次，而是"定位→操作"的传导：剪刀差本身就是周期状态在供需维度上的量化切片，只是被
操作化了；加库存是补全定位维度（尤其库存贴顶=过热末端、低库存=复苏确认），让交易逻辑有更完整
的上下文。框架已经这么分层了，缺的是把"周期状态"显式表达出来，而不是再造一个交易信号。**
