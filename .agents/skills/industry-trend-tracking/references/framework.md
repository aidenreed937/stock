# 产业趋势量化框架（深研线簇·产业腿激活 × 财报滞后验证 × 动量兜底）

选景气行业 = **深研线簇（产业腿激活）**：每个有产业供需腿的行业（半导体 270100 / 计算机设备 710100 / 化工 220200·220400·220800，
逐步扩至电池/乘用车/航运/金属）**独立建供需剪刀差深研线**，产业腿信号激活（剪刀差 LONG + 供给端确认 DOI）即入选并可择时；
**无产业腿的行业暂走通用动量 Top3 + 估值/组合防守门（滞后兜底，不宣称前瞻）**。
**现实景气（业绩预告/快报）仅作面板列与事后确认，不参与实盘选股**——公司经营与财报是滞后数据，只能解释/验证行情起落原因，
**不能作前瞻选股**；**真前瞻只有产业供需剪刀差**（demand−supply 领先 1-3 月/1-2 年，半导体方法论见 `semiconductor/archive/framework_semiconductor.md`）。
财报层（量价齐升/毛利率扩张）只作**事后滞后验证**；「全球方向」仅作可选关注加权，**不作判定层**。
当前框架落到申万二级行业（全球共振方向池 16 个二级行业，其中 5 个有产业腿进深研线簇）。

顶层树（**选行业前瞻信号** vs **财报滞后验证**分界）：

| 信号 | 前瞻性 | 回答的问题 | 用途 | 对应因子 |
| :--- | :--- | :--- | :--- | :--- |
| 产业供需剪刀差（demand − supply，产业数据腿） | **前瞻** | 有产业腿的行业真景气激活了吗 | **选行业核心**：深研线簇入口（剪刀差 LONG + DOI 确认才入选） | `scissors` / `demand_score` / `supply_score` / DOI |
| 动量 Top3 + 估值/组合防守门（`return_60d`） | **滞后**（行情类） | 无产业腿行业当前该持有吗 | **兜底排序**（无腿行业右侧确认，不宣称前瞻） | `return_60d` / `pe_ttm_ew_percentile_5y` |
| 现实景气（业绩预告/快报，财报） | **滞后** | 财报兑现了吗（事后） | 仅面板列与事后确认，**不参与实盘选股** | `prosperity_score` |

## 0. 体系职责边界（与行业轮动 / 半导体深研线无重叠）

> 本技能与 [`industry-rotation-strategy`](../../industry-rotation-strategy/SKILL.md) 是**两套独立体系**（SKILL.md 已声明），
> 半导体深研线（270100 供需剪刀差 + crowd_val80/defense_crowd/offense_defcrowd）则是本框架内的**单行业深度子线**。
> **rotation 覆盖已迁移**：原申万 31 **一级**行业轮动无法落地实盘（一级指数无直接可交易标的），
> 现已为**申万二级行业全池**；且 `config/strategy/industry_rotation.yaml`（:91-94）已**停用四大 L1 轮动策略**
> （样本外 Sharpe 0.02-0.13 远低于趋势跟踪池），"后续轮动能力以 industry-trend-tracking（L2 方向池 + 组合防守门）为准"。
> 三层是**递进的漏斗**，不是并列选项：轮动选二级全池 → 趋势跟踪选二级方向池（16）→ 深研线簇管有腿行业前瞻交易。
> 每层信号源、池、尺度不同（信号源无重叠）；但职责上有重叠：①状态性排雷与③择时是同一决策的两面，②选景气与③深研线都含估值/拥挤防守（见下方三级定位表）。
> **方向（2026-09 已决策 B 深研线簇）**：② 的核心职责收敛为「有产业腿行业进深研线簇（前瞻），无腿行业动量兜底（滞后）」。

**四个"同名不同义"（无重叠的关键，名词务必按正式全名区分）**：

1. **动量**（rotation `ind_momentum` vs trend `return_60d`）：
   rotation = **景气动量因子** `ind_momentum`（0.35·Rank(Ret20d) + 0.35·Rank(Ret60d) + 0.30·Rank(MA20偏离) 复合）× 二级行业全池；
   trend-tracking = **60 日收益动量** `return_60d`（单一指标）× 16 二级方向池 + 估值防守——因子定义不同、池不同，两套独立排序。
2. **剪刀差**（rotation `ind_scissors` vs 深研 `scissors`）：
   rotation = **毛利率剪刀差** `ind_scissors`（ProfitGrowth − RevenueGrowth 排名，盈利质量/定价权）；
   深研线 = **供需剪刀差** `scissors`（demand=TSMC+SIA 需求 − supply=SEAJ 供给，供需周期）——虽然都叫"剪刀差"，
   前者是财务盈利指标、后者是产业供需指标，同名不同物，无重叠。
3. **拥挤度**（rotation `ind_crowding` vs 深研 `share_pct_250`）：
   rotation = **拥挤过热因子** `ind_crowding`（TCR=行业成交额占全市场比重 的 5Y 滚动分位，横截面时序量，服务行业选择）；
   深研线 = **成交占比时序分位** `share_pct_250`（270100 占全市场比重的 250 日滚动分位，单行业时序量）+ pe5y 组合成 crowd_val80（服务持仓降仓）——
   一个横截面量、一个单行业时序量，层级不同。
4. **估值**（rotation `ind_valuation` vs 深研 `pe5y`）：
   rotation = **估值赔率因子** `ind_valuation`（100 − ½(PE_Pct5Y + PB_Pct5Y) 排名，**高=低估**=安全边际，用于逆向买入）；
   深研线 = **估值水平分位** `pe5y`（PE 5Y 分位，**高=透支**，用于疯狂牛末端降仓）——方向相反，一个买低、一个避高，职责互补不冲突。

**三级定位（排雷 → 选景气 → 交易择时，一条流水线不是三选一）**：

| 环节 | 回答的问题 | 现有工具 | 对应体系 | 前瞻性/证据 |
| :--- | :--- | :--- | :--- | :--- |
| ① **初级排雷** | 哪些行业不能碰（过滤，不产生正持仓）| 估值防守（pe5y≤90）、拥挤度一票否决（crowd_max）、象限过滤（需求低×供给扩张剔除）| ② trend-tracking 防守门/方向门 | 状态性排雷（拥挤/估值/动量极端）**本质即择时**（时间相关，与③择时操作层不可区分）；结构性排雷（造假/ST）才是永久质量门 |
| ② **选景气行业** | 有腿行业真景气激活了吗（前瞻）/ 无腿行业当前该持有吗（兜底）| 有腿→产业腿激活（剪刀差 LONG + DOI 确认）；无腿→动量 Top3 + 估值/组合防守门（`return_60d`，pe5y≤90 + capex/拥挤/象限/恐慌）；现实景气仅面板列/事后确认 | ② trend-tracking 主流程 | 有腿行业**前瞻**（产业供需剪刀差，领先 1-3 月/1-2 年）；无腿行业**滞后**（动量/估值右侧确认，`industry_l2_direction.py` 无 prosperity 接线，横截面无前瞻因子）|
| ③ **运用景气特点交易** | 选中后怎么买卖、何时降仓（择时/风控）| 供需剪刀差定位 + 进攻脚（博涨）× 防守门（控回撤）× crowd_val80（疯狂牛末端）| ③ 深研线簇（各腿行业自建）| **前瞻**：demand−supply 剪刀差（半导体=TSMC+SIA−SEAJ）领先 1-3 月/1-2 年，已是前瞻数据提前交易；化工/计算机有腿但 LONG 判定待通用化 |

- **排雷 ≠ 选行业**：排雷是剔除层（否决性信号），选行业是选择层（从排雷后池子选 Top3）。但排雷里**状态性**（拥挤/估值/动量极端）与择时是同一决策的两面，职责标签不改变其时间相关性。
- **深研线簇属 ③**：输入（demand=产业实物流量、supply=产能/设备出货/开工率、拥挤、估值）即"行业景气和特点"的量化；输出是仓位（满仓/降 0.3/空仓）——
  回答"既然选中了这个景气行业，现在该满仓博涨还是降仓避险"，是景气确认后的交易执行，不是排雷也不是跨行业选股。它是框架中**唯一用前瞻数据驱动**的一层。
- **断层（2026-09 复核，已决策 B 深研线簇）**：三层不是并列独立环节——①状态性排雷≈择时、③择时与①重叠；②选景气**无横截面前瞻因子**（动量 Top3 + 防守门，现实景气不参与选股）。**已决策：B 深研线簇——把③模式推广到每个有产业腿行业（半导体/计算机设备/化工，逐步扩电池/乘用车/航运/金属），用产业腿激活统一选行业，各行业自带剪刀差择时；无腿行业暂走动量兜底（滞后，不宣称前瞻）**。实施见 research_roadmap 优先级 1。
- 三层体系 × 三环节：rotation 可覆盖排雷/选择（全池维度），trend-tracking 主做 ①②（二级方向池），深研线簇示范 ③（各腿行业）。

**生效日语义（无前视）**：月频/季频信号腿（变压器出口/光伏装机/新能源车销量/创新药 BD/挖机产销/
云 Capex 等）按 **`release_date`（官方发布日期或保守代理生效日）** 生效并前向填充——有官方逐条发布日期时
按官方日期；无法逐条核验时按保守代理日，不能把代理日当作精确披露时点。方向分呈"月度滞后确认"阶梯；
日频信号腿（SOX/铜价/黄金/运价）逐日更新。因此"提前读出拐点"仅对日频腿成立，月频腿是滞后确认。

**方向分计算机制**（`scripts/industry_direction_map.py`）：方向分看的是**扩张斜率（增速）的滚动
历史分位**，而非绝对量——绝对值创新高但同比增速回落时，分位会同步大幅回落。

- 月频/季频腿（出口/装机/销量/BD/Capex）：`pct_change(12)` 同比（YoY）→ 过去 36 个月频点
  的滚动经验分位（季频 12 个季频点）：
  ```
  yoy = (value − value_12m_ago) / value_12m_ago
  direction_score = 当前 yoy 在近 36 个月窗口内 ≤ 当前值的比例 × 100
  ```
- 日频腿（SOX/铜价/黄金/运价）：`log` 20 日动量、60 日变化、200MA 偏离度三因子各自
  756 日滚动分位后取均值：
  ```
  mom20 = log(price).diff(20); chg60 = log(price).diff(60)
  ma_bias = (price / ma200 − 1) × 100
  direction_score = mean(rolling_pct(ma_bias), rolling_pct(mom20), rolling_pct(chg60))
  ```

**需求周期四阶段解读**（描述性分段，代码无显式状态机；唯一硬阈值为方向防守门的
`direction_score > 66`）：

| 阶段 | 典型特征 | 方向分区间 | 系统解读 |
| :--- | :--- | :---: | :--- |
| ① 景气启动 | 同比由负转正、加速扩张 | 50 ↗ 80 | 真景气主升段候选 |
| ② 狂热高潮 | 增速处于 3 年历史极值 | 80 ~ 100 | 追高风险区（方向分对未来收益无显著预测力） |
| ③ 扩张放缓 | **绝对值仍增、增速骤降** | 80 ↘ 40 | 拐点预警窗口：分位随增速回落而跳水 |
| ④ 需求萎缩 | 同比转负、周期出清 | 0 ~ 30 | 景气消退（如光伏设备当前 2.8 分） |

**修复后实证与定位（2026-08，无前视口径，15 行业方向池；2026-09 纳入消费电子后为 16 行业，
基线回测 +5.42% / guarded +12.71%，见仓库策略列表口径）**：

| 检验 | 结果 | 含义 |
| :--- | :--- | :--- |
| direction_score vs 未来 20 日收益截面 IC | 全周期 **+0.99%**，样本外 +1.42% | 几乎无横截面预测力 |
| 分位未来 20 日收益 | 中 40-60 **+2.43%** > 高 ≥60 +1.12% > 低 ≤40 +0.22% | 倒 U 型；低分组最弱 |
| 高位（≥60）内部分组 | 非量价齐升 **+0.51%** < 量价齐升 +1.05% | 高位 × 非量价齐升是最差象限 |
| 防守变体：高位×非量价齐升剔除（direction_gate） | 全周期 **8.34%** / MaxDD 55.56%（baseline 12.50%/54.07%） | 作选股门纯劣 |
| 防守变体：持仓方向分 <40 剔除（low_exit） | 与 baseline 相同（零触发） | 持仓方向分罕见 <40 |
| 防守变体：组合方向分均值 <40 清仓（low_all） | 12.17% / MaxDD 49.29%（样本外 16.72%/41.14%） | 降回撤但牺牲收益，Calmar 无改善 |

**定位结论**：方向分是**拐点预警信号**（全球景气位置的展示与人工参考），**不作策略门/自动防守
规则**——IC 弱、防守变体均不优于 baseline（或仅以收益换回撤），与 `industry_rotation-strategy`
拥挤度防守（tcr 高位一票否决，回撤 42% → 26%）形成对比：真正有效的自动防守是拥挤度，不是方向分。

**因子落地**：`direction_score`（0-100 横截面方向分），数据缺口时中性 50；由
`global_resonance_l2_map.parquet`（理杏仁码）提供，列为 `trade_date` / `industry_code` /
`direction_score`。

**产业数据腿构建原则（2026-09 实证，避免重蹈 direction_score 覆辙）**：方向分与新增产业腿
必须遵循以下四条，否则会重蹈「整体 direction_score IC≈0」的覆辙（好腿被坏腿中和）：

1. **只用实物流量/库存/产能利用率类，不用价格类**。实证（全行业截面 IC）：demand 腿
   （出货/销量/装机/BD 等实物流量）fwd60 IC **+0.116** / ICIR 0.35（真前瞻）；price 腿
   （铜价/运价/金价）fwd60 IC **-0.09**、past IC +0.16（跟随指标，无领先性）。
2. **按领先链条排权重**：设备订单/产能建设（领先 1-2 年）> 产能利用率（领先 2-3 季度）>
   库存（领先 1-2 季度）> 价格（同步，不用）。实证：capex 先导（资本开支高增速）与未来
   收益显著负相关，IC60 **-8.62%**（样本外 -5.05%），见 `scripts/industry_capex_leading.py`。
3. **与需求端产业腿配对成剪刀差**：信号 = 供给增速（产业口径）− 需求增速（产业口径），
   不单边看供给。实证 2×2：需求高 × capex 高（需求旺盛但供给狂扩）未来 60 日中位 **-4.33%**、
   下跌概率 59.4%（最差组合）；需求高 × capex 低 **+0.03%** / 49.9%（最优）——需求高不是护身符。
4. **新腿与 demand 腿分开、不混入 price 腿合成总分**：整体 direction_score IC≈0 的元凶正是
   demand（+0.116）与 price（-0.09）合成互相抵消，叠加覆盖不足（124 个 L2 行业仅 22 个有产业腿，
   其余 88.9% 回退中性 50）。新增供给端腿按 leg_type 独立分组评估，禁止与 price 腿合并。
5. **代理指标的引用与生效日期必须可追溯**：跨源代理只在分析/对账层计算，不回写某一来源的黄金事实表；
   每次引用应同时注明本地数据集、字段、报告期、`release_date`（官方发布日期或保守代理生效日）和源链接。
   半导体 SEAJ 设备出货的供给腿
   使用日元原始序列同比及滚动分位，美元换算和 SEAJ/SEMI 比值只作量级对账，不能进入剪刀差信号。

现状与缺口（2026-09 更新）：产业口径供需腿已落地部分——
- 化工系：化学原料（220200）需求=MDI/钛白粉出口、供给=MDI/纯碱/烧碱/钛白粉开工率+库存；
  化学纤维（220400）需求=江浙织机负荷、供给=PTA/聚酯开工+库存；农化制品（220800）

  scissors=demand−supply。

航运新船交付/在手订单（Clarksons）、金属 LME 库存/TC。

**半导体（270100）剪刀差方法论 → 已拆分**：剪刀差极值信号形态、当前截面、用途界定、
双轨用法、有效性总账、供给端确认腿（产能利用率 + IDM 存货 DOI）、财报传导链、

**价格驱动板块的波动率意识（2026-09 建议，未落地）**：贵金属/工业金属/航运港口（price 腿板块）
驱动是突发价格/地缘事件（金价/铜价/运价），趋势持续性差、反转急——贵金属年化波动 55.3%
（池内第 2）、工业金属 43.4%，与成长型行业（半导体/通信设备）不同。两个低成本改进方向
（均在策略参数层内、无需新数据源，落地前需单独回测）：

1. **波动率缩放（vol targeting）**：按行业年化波动倒数分配仓位——贵金属（55% 波动）自动降权，
   替代等权 Top3，缓解"突发反转"冲击。
2. **分板块拥挤度阈值**：对价格驱动板块（贵金属/工业金属/航运）把拥挤度门限从 85 收紧到 80——
   它们过热更快、反转更急，需要更早刹车。

当前状态（2026-08-28 截面）：工业金属拥挤度 95.9 已超门限被拦截、贵金属 84.6 临界——框架对这类
板块已处于防守状态；贵金属动量池内第 2，若入选 Top3 需依赖 vol targeting 或更严阈值控制尾部。

**选行业方法论：产业资格 × 动量强度（2026-09 提出，未落地）**：目标形态是让产业领先信号与
动量各司其职：

1. **资格层（全球景气确认，决定"能不能买"）**：产业领先信号（demand 腿，fwd60 IC +0.116）
   确认全球景气方向 + 防守门（估值/拥挤/象限/恐慌）过滤——不满足即出局；
2. **强度/时机层（趋势延续，决定"买哪些、何时调仓"）**：动量 return_60d 排序 Top3——在合格者
   中按趋势强度排名，季度调仓。

理论依据（信号时间线）：产业实物流量（领先 1-3 个月）→ 股价动量（行为滞后：反应不足/羊群，
领先财报但滞后产业）→ 财报确认（最滞后，有漂移效应）。动量"滞后但有效"（Top3 候选未来 60 日
中位 +0.52%）；产业信号"领先但未进排序"（当前仅作门/加分/预警）。

当前状态：未落地。现状为"动量排序 + 门过滤"——动量定排序、产业信号当门，但最强的产业领先信号
（demand 腿）未参与资格判断。

落地候选（需回测验证）：
- 方案 A：先产业过滤再动量排序——demand 腿方向分过低（<40）行业先出局，合格者内按动量排名；
- 方案 B：动量 × 产业信号复合排序——rank(return_60d) + 权重 × rank(demand 腿)。

验证要求：与 baseline 回测对比；检验 demand 腿是否被动量隐含（象限加分前车之鉴：IC 强但 Top3
内边际 +0.27pp，因为动量已隐含供需）。

## 2. 财报滞后验证 · 量价齐升 > 供给收缩（L2 财务黄金表）

**定位：滞后验证层，不作前瞻选股**——营收/净利同比是财报滞后数据，只能事后验证供需逻辑
是否兑现，不能预先指导行情（信号时间线：财报确认最滞后，见 §1 理论依据）。此处仅作
持有观察与拐点预警信号（实测：16 行业方向池内量价齐升硬门/加分均不优于 baseline）。

需求驱动（量价齐升）优于供给收缩（营收负、净利正）。供给收缩是「假繁荣」——净利增长来自
压缩成本而非需求扩张，不可持续。实证：未来 20 日收益，需求驱动 +0.74% vs 供给收缩 +0.29%
（供给收缩是最差象限）。

| 象限 | 营收增速 | 净利增速 | 含义 | 质量分 |
| :--- | :--- | :--- | :--- | :--- |
| 量价齐升 | >0 | >0 | 真需求驱动 | 双增速之和的横截面分位 |
| 供给收缩 | ≤0 | >0 | 假繁荣（压缩成本） | 惩罚分 20 |
| 双负 | ≤0 | ≤0 | 需求 + 盈利双弱 | 惩罚分 10 |

数据来源：理杏仁 L2 财务黄金表 `sw_2021_l2_fs_non_financial`（124 个非金融二级行业，
2020Q1 ~ 2026Q1 共 25 个报告期），字段 `q.ps.toi.ttm_y2y`（营收 TTM 同比）/ `q.ps.np.ttm_y2y`
（净利 TTM 同比）；银行/证券/保险分别取 `sw_2021_l2_fs_bank` / `_security` / `_insurance`。

## 3. 财报滞后验证 · 毛利率扩张（微笑曲线偏上）

**定位：滞后验证层，不作前瞻选股**——毛利率扩张源自财报盈利（净利 > 营收增速），是滞后数据，
仅事后验证定价权/盈利质量，不具前瞻指导力（前瞻确认应依赖 §1 产业数据腿；半导体深研线剪刀差方法论见 `semiconductor/archive/framework_semiconductor.md`）。

只有「量价齐升」的行业才谈得上议价权。议价权 = 净利增速 > 营收增速（毛利率扩张），
表示这个制造环节在微笑曲线偏上、有定价权，而非代工环节。

- 量价齐升门内：议价权 = `profit_growth_ttm − revenue_growth_ttm` 的横截面分位；
- 量价齐升门外：议价权取中性分 30（不参与评分）。

**毛利率前瞻确认腿（2026-09 实证，Stage 2 已接入第一步）**：设备龙头 GM 前瞻腿（下季 GM 指引 /
服务 mix / 扩张幅度）把"毛利率扩张"从**滞后验证升级为前瞻确认**（财报前即可获得，release_date 无前视）：

- 数据：`data/curated/mart/semiconductor_gm_confirm_legs.parquet`（`gm_cross`，270100，
  ASML/AMAT/LRCX/KLAC 四家前瞻信号等权合成，leg_type 独立分组、不入剪刀差）；
- 实证：跨公司 gm_cross 对 270100 fwd60 偏 IC **0.26**（控剪刀差后 0.19~0.26、控 ASML 后仍 0.244/0.320）、
  门槛 3/4 通过；组合确认 `scissors_confirm_cross` 样本外 Sharpe **0.664 > 剪刀差主信号 0.652**；
- 用法：**前瞻确认腿，挂靠剪刀差 LONG 主信号**（LONG 时按 gm_cross 高分加成 ×1.2 / 低分逆证 ×0.5），
  不作独立择时（单独外 Sharpe 0.582 < 主信号 0.652）；
- 覆盖限制：AMAT 不指引 GM（仅服务腿）、KLAC 不分服务（仅指引腿）、KLAC 缺财年末 Q4 GM、
  LRCX 服务占比 2021 起；TEL（日本 IR）仅 GM 实际值水平腿、实证滞后（偏 IC -0.091）→ **未接入前瞻复合**；
- 详证见 [`gm_leading_leg_stage2.md`](semiconductor/archive/gm_leading_leg_stage2.md)（已归档）。

## 反例警示：光伏

光伏承接了全球碳中和资本开支（方向 ✅），但产能大规模落地后过剩、价格战（产业供需 ❌），
且组件环节缺乏定价权（财报滞后验证 ❌）→ 前瞻确认与滞后验证都不通过，不是真 alpha。
2025-2026 光伏设备（630500）营收同比转正但净利同比仍大幅为负（量价齐升不成立），
即属于此类——方向池内也必须经产业供需前瞻确认（而非只看财报滞后验证）与财报滞后验证双重把关。

**630500 前瞻定稿（2026-09 实证细化，详见 `docs/research/photovoltaic/00_study_overview.md`）**：
- **fwd60 尺度无前瞻腿**：需求/供给腿样本外 2022+ 全部失效（贴顶反身），fwd60 择时不可行；
- **季度尺度（fwd2q/4q）存在唯一前瞻信号——产业层产能周期状态门**：过剩 vs 上行 fwd4q
  -31.5%/胜率 3% vs +82.9%/83%（扩产潮 cap_yoy≥30% 及其 24 个月余波是核心开关），
  样本外 MaxDD 71.9→**30.6**（cycle+fin 两源）为所有防守方案最优；但规则为历史反推（事后拟合
  风险），定位「组合防守门一层 + 拐点预警」，不宣称独立择时；
- **状态门稳健性审计（2026-09）**：阈值扰动下区分度稳定（**非参数拟合**），但样本仅含
  一次产能循环实现（上行 2019-2021、过剩 2022-2024 时间完全分离）、跨相位 IS/OOS 无法同截面
  验证——结论成立但置信度受限于单次实现，需 2026+ 第二轮循环数据二次确认（见
  `docs/research/photovoltaic/12_cycle_robustness.md`）；
- **季度防守形态定稿（三源预警卡，2026-09）**：最优 = **产业层产能周期状态 + 财报 TTM 两源门**
  （样本外 -6.47%、外MaxDD 30.6）；**需求分位贴顶不重用**——加入贴顶会劣化防守（三源降至
  外 -12.8%、外MaxDD 46.8），贴顶在季度层无危险区分度（见
  `docs/research/photovoltaic/11_warning_card.md`）；
- **财报层（含 capex/在建工程）不新增前瞻能力**：capex 先导检验证实"首次触发=数据截断假象"
  （cip_yoy/capex_growth_ttm 起点即触发）、可证部分滞后于产业层 244 天 vs 124 天；
  仅作防守滞后确认（高扩张区 fwd4q -22~-26%），强化「财报层滞后验证、不作前瞻选股」定稿；
- **630500 不在方向池（与电池相关 0.77）**：放回 17 池动量 Top3 为净拖累（样本外转负），
  维持动量兜底外身份。
- **光伏确定规律清单**：`references/photovoltaic/established_laws.md`——按 A(机制确定)/B(单次循环
  内成立、未证实可重复)/C(证伪) 分级收录光伏产业能确定的规律；一句话：确定性在结构层面
  （低壁垒→产能周期定价、财报滞后、短尺度失效、只能看季度以上产能周期状态），
  时序上「涨→过剩→跌」仅一次实现可证、待 2026+ 二轮循环二次确认。
