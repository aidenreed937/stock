# 光伏价格补丁定义（方向 A 收尾产物）

> 研究基准：2026-09。承接 `established_laws.md`（Part A 机制）、`part_a_method_selection.md`（方法取舍）与 `price_chain_mechanism.md`（价格链机制与物理折算）。
> 本文把「价格补丁」的完整定义、数据链路、触发规则、证据与局限落成可复用说明，
> 供组合防守门（`cycle + fin + price` 三源）实现与维护时直接引用。
> 分级沿用 `established_laws.md`：〔A〕机制/结构确定 ·〔B〕单次循环内成立未证重复 ·〔C〕证伪。

---

## 一、一句话定义

**价格补丁 = 光伏组件价相对过去 52 周最高点的回撤深度 ≥ 20% 时，把仓位压到 0（空仓）。**
它是「确认恶化后」的尾部防守补丁，**不是前瞻信号**。

---

## 二、完整数据链路（4 步，全部无前视、T+1）

### 1. 数据源

| 项 | 值 |
| :-- | :-- |
| 表 | `data/curated/industry/solar_price_chain.parquet`（光伏价格链黄金表） |
| 字段 | `module_price_cny_watt`（组件价，元/瓦） |
| 来源 | InfoLink Consulting，`data_status=actual` |
| 覆盖 | 2020-01 ~ 2026-08（347 行，周频 7 天间隔） |
| 对照（未用于补丁） | `polysilicon_price_cny_kg`（硅料价）——仅在分层验证里作上游领先对照 |

### 2. 信号公式（回撤深度）

```
dd = 组件价 / 过去52周滚动最高价 − 1      （周频计算）
```

- 滚动窗口 = 52 周（约 1 年）：`price.rolling_max(52)`
- dd 为负值：`0` = 价格在 52 周高点；`-20%` = 比一年内最高点跌了 20%
- 时序：2022 开始转负（价格掉头）→ 2023-2024 深跌（组件 -46%）→ 2026 反弹回 0

### 3. 时序对齐（无前视）

- 周频 dd 通过 `trade_date` 左连到 630500 日频面板，`release_date` 生效，前向填充到每个交易日
- **T+1 出仓**（`shift(1)`）：信号当日收盘生成，次日开盘执行

### 4. 触发规则（组合防守门）

```
if dd ≤ -20%（组件价回撤超20%）:                    仓位 = 0.0（空仓）
else if cycle 触发 或 fin 触发:                      仓位 = 0.25
else:                                                仓位 = 1.0
```

## 三、为什么用组件价（而非硅料价）

| 价格档 | 特点 | 分层 fwd4q（≤-40% 档） |
| :-- | :-- | :-- |
| **组件价 module** | 贴近终端需求变现、覆盖全期、最稳 | **-17.98% / 胜率1%** |
| 硅料价 polysilicon | 上游领先但波动更极端（最深 -69%） | -15.18% / 胜率28% |

组件价回撤时序与 630500 走势最吻合（2022 转负 → 2023-2024 深跌 → 2026 反弹回 0），作为主信号。

## 四、证据（2026-09 实跑）

### 4.1 分层验证（`industry_solar_price_chain_layering`）

> 口径：分层统计的是各回撤分档的**未来收益分布**（均值/胜率），非策略回测组合，故不设 Sharpe；
> 策略级指标（CAGR/Sharpe/MaxDD）见 4.2 组合验证。

| 组件价回撤分档 | fwd4q 全体 | fwd4q 样本外 |
| :-- | :-- | :-- |
| ≤-40%（深跌） | -17.98% / 胜率1% | -17.98% / 1% |
| -40~-20%（中跌） | -0.48% / 56% | -0.48% / 56% |
| -20~-5%（浅跌） | -8.02% / 43% | -8.02% / 43% |
| -5~0%（高位/贴顶） | +43.27% / 61% | **-20.41% / 13%** |

**关键证伪（〔C〕）**：样本外高位区（-5~0%）fwd4q **-20.41%/13%**——价格还贴着 52 周高点时
630500 已开始崩（2022 顶部）。**价格是同步/滞后指标，不是前瞻指标**，掉头确认时已晚。
这与 `A3`（财报滞后）、`04`（贴顶反身）结论一致：过剩只能用产业层产能周期状态机识别。

### 4.2 组合验证（`industry_solar_price_gate_combo`，三源防守）

| 变体 | 全CAGR | 全Sharpe | 全MaxDD | 外CAGR | 外Sharpe | 外MaxDD |
| :-- | --: | --: | --: | --: | --: | --: |
| 纯买入 | 6.00 | 0.343 | 72.76 | -18.09 | -0.342 | 71.93 |
| cycle+fin 两源（基准门） | 13.06 | 0.596 | 50.38 | -6.47 | -0.552 | 30.56 |
| **cycfn+price（回撤≥20%空仓）** | **15.85** | **0.696** | **50.38** | **-2.23** | **-0.208** | **19.66** |

- **叠加有效（验收通过）**：外 MaxDD 30.56→19.66（≤30.56 ✓）、外 CAGR -6.47%→-2.23%（减亏）、
  外 Sharpe -0.552→-0.208（改善）、全 Sharpe 0.596→0.696（改善）。
- **OR≡AND（机制）**：price 触发 489 天中 price_only=0——价格触发**完全是 cyc/fin 触发的子集**，
  补丁只是把 cyc/fin 已降到的 0.25 在深跌确认后再压到 0（"确认后加深"），非独立/前瞻信号。
- **阈值稳健**：回撤 15/20/25% 三档外 MaxDD 19.66/19.66/21.63、外 CAGR -2.60/-2.23/-4.08、
  外 Sharpe -0.257/-0.208/-0.401，方向一致，20% 较优。
- **逐年 MaxDD**：2023 16.4→4.2、2024 10.3→0.0、2025 5.6→4.0（深跌段大幅砍回撤）。

### 4.3 兜底机制：它凭什么兜、兜住的是什么

"兜底"不是套话，它靠一个**明确且无观点的执行机制**运作：

- **触发用得是独立基本面价格，不是自己账面亏损**。信号是组件价相对一年（52 周）最高点的回撤 `dd≤-20%`，
  与"我这笔赚还是亏"无关。**只要深跌真发生，不管你对生命周期/周期状态判得对不对，次日（T+1）先撤**。
- **它是"无观点防守"**：不猜测方向、不预测拐点，只认"价格已从一年高点下跌超 20%"这个客观事实。
  ——这正好补上"需求/右侧确认判断不了"（见 `core_proposition.md` 六、生命周期文档）的认知空白：
  你判断不了周期，就用价格深跌这个已确认事实来兜。
- **"兜"的是过剩主跌段的系统性回撤**：实证外 MaxDD 71.93（纯买入）→ 30.56（cycle+fin）→ 19.66（+price），
  逐年看深跌段 2023/2024/2025 从 16.4/10.3/5.6 压到 4.2/0.0/4.0——**最后这道护栏砍掉的是"确认后深跌"的尾部**。
- **绝非抄底信号**：因为它滞后（价格掉头确认时已晚），它**只做空仓、绝不做"跌够就买"**；
  反向用它抄底正是 4.1 已被证伪的高位区教训。

> 一句话：**价格补丁兜底 = 某日组件价相对一年最高点跌 ≥20%，次日就空仓避险**，它不预测、此刻
> 不依赖任何周期判断，纯粹用"深跌已发生"这个客观事实，在防守门可能误判/滞后的末端兜住深跌回撤。

## 五、定位与局限（不得隐去）

1. **〔C〕前瞻：证伪**。价格是滞后腿，不能提前预警过剩（高位区样本外 fwd 反而最差）。
2. **〔B〕防守：有效但减亏**。外 CAGR 未转正（最好 -2.23%），价格补丁只压低回撤，
   不改变「样本外负收益」本质。
3. **〔B〕单次循环实现**。样本只有本轮一次过剩（2022-2024），IS/OOS 跨相位无法同截面验证；
   二轮数据前不宣称可重复。
4. **触发时点滞后**：回撤≥20% 首次触发在 2022-10，已接近顶部确认（防不住顶部下杀，只防尾部）。

## 七、推荐用途

作为**三源防守门**（`产能周期 + 财报 TTM（降 0.25）+ 价格回撤≥20%（空仓）`）的第三源挂载到
B 形态（动量选中才持有 + 组合防守门）。前瞻仍靠产业层产能周期状态门。

**极端情形验证**：见 `high_entry_survival.md`——即使高位/顶部介入，三源把 MaxDD 72.8→33.7%、
亏损 64%→21%（精确顶日仍未回本）；非精确顶日介入多数可回本（顶部后 6-9 个月介入 nav 102.9%~104.1%、
MaxDD 10.8%）。防守门是「减亏 + 提高存活概率」工具。
