# 光伏周期一阶导与二阶导信号框架（Cycle Derivative Framework）

> **研究基准**: 2026-09。承接 `established_laws.md`（机制总纲）、`lifecycle_position.md`（生命周期指导）与 `docs/research/customs_export_forward/archive/11_cycle_derivative_framework.md`。
> **核心命题**: 回答光伏产业周期分析中，**“如何使用零阶导（水平）、一阶导（速度）与二阶导（加速度/拐点）实现超越滞后财报的前瞻投研与择时定位？”**
> **分级口径**: 严格遵循本库证据分层规范：〔A〕机制/结构确定 ·〔B〕单次循环内成立未证重复 ·〔C〕证伪。

## 一、为什么光伏必须看二阶导（机制本源）

**〔A〕财报（零阶导）永远追不上光伏产能周期**：
1. **重资产扩产滞后性**: 光伏硅料建设周期约 1.5~2 年，硅片/电池片 6~9 个月，组件 3~6 个月。当全行业单季度财报利润创历史新高时，背后往往是过去两年巨额资本开支集中投放的高峰期，行业瞬间进入供给过剩暴风雨前夜；
2. **钝化与反向陷阱**:
   - 顶部：财报利润冲顶（零阶导极好），往往对应周期大顶（2021-2022 年组件放量时股价见顶，财报在股价暴跌 40%+ 后的 2023 年仍显示高增长）；
   - 底部：全行业巨额亏损、价格跌破现金成本（零阶导极差），往往孕育着产能出清与股价反转的曙光。
3. **资金交易的定价对象**: 资金交易的不是“当期盈利绝对值”，而是**“单瓦盈利的边际方向（一阶导）与供需恶化/改善的加速度（二阶导）”**。

> **核心原则（Golden Rule）**:
> **择时看二阶导（方向变化），阶段确认看一阶导（水平），财报（零阶导）仅作事后验证。**

## 二、三阶导数体系与物理量映射

| 阶数 | 数学定义 | 光伏产业物理量映射 | 典型度量指标 | 投研与市场心理特征 |
| :--- | :--- | :--- | :--- | :--- |
| **零阶导 $f(t)$**<br>(Level，绝对水平) | 变量当前绝对值 | • 组件绝对价格（0.69 元/W）<br>• 多晶硅库存量（52.2 万吨）<br>• 单季度归母净利润（全行业 -80 亿） | 现货绝对价、库存绝对量、财报 TTM 利润 | **最滞后、钝化严重**。<br>反映“现状有多好/多差”，无法用于拐点择时。 |
| **一阶导 $f'(t)$**<br>(Velocity，速度/斜率) | 变动速度与方向<br>$\frac{df}{dt}$ | • 组件价格周环比 $P_{mom}$、年同比 $P_{yoy}$<br>• 供需剪刀差 $\text{Scissors} = g_{\text{供}} - g_{\text{需}}$<br>• 净利润同比增速 | 价格同比/环比、出口金额同比、装机同比 | **趋势确认器（阶段归属）**。<br>确认是处于景气扩张期（$f'>0$）还是衰退期（$f'<0$）。 |
| **二阶导 $f''(t)$**<br>(Acceleration，加速度/曲率) | 变动速率的变化<br>$\frac{d^2f}{dt^2}$ 或 $\Delta f'(t)$ | • 价格跌幅是否在收窄？<br>• 供需剪刀差是否在加速收敛？<br>• 需求量增速是否见顶回落？ | 价格同比差额 $\Delta P_{yoy}$、剪刀差变化量 $\Delta \text{Scissors}$、3MMA 斜率 | **择时雷达（领先 4~11 个月）**。<br>寻找“恶化放缓（边际改善）”与“繁荣减速（顶部前兆）”。 |

## 三、四大核心变量的导数结构与实证规律

```
           ┌────────────────────────────────────────────────────────┐
           │                光伏中观产业链导数观测矩阵               │
           └───────────────────────────┬────────────────────────────┘
                                       │
         ┌──────────────────┬──────────┴─────────┬──────────────────┐
         ▼                  ▼                    ▼                  ▼
  【1. 价格与利润链】  【2. 供需剪刀差】    【3. 库存蓄水池】     【4. 消纳需求端】
   弹性确认腿 (周度)    景气领先雷达(月度)   供需失衡时间积分     量的敏感度最高 (海关/装机)
```

### 1. 价格链与环节毛利（周度高频，弹性确认腿）
- **零阶导 $P$**: 现货价格绝对值（组件 0.690 元/W、硅料 43 元/kg）。
- **一阶导 $P' = \text{YoY}(P)$**: 价格同比变动率。$P' > 0$ 为价格右侧确认（价格底确立）。
- **二阶导 $P'' = \Delta \text{YoY}(P)$**: 价格下跌/上涨速度是否发生变化。
  - **〔A〕底部二阶导（跌幅收窄）**: $P' < 0$（仍在跌价），但 $P'' > 0$（跌幅从 -30% 收窄至 -1.8%），说明杀价动能衰竭、恶化放缓，是**左侧最重要的企稳信号**；
  - **〔A〕顶部二阶导（滞胀）**: $P' > 0$（价格仍在涨），但 $P'' < 0$（周涨幅停滞），进入滞胀末段。

### 2. 供需剪刀差（中观景气最强领先指标）
设电池片供给增速为 $g_S$，国内装机需求增速为 $g_D$：
- **一阶导（剪刀差读数）**:
  $$\text{Scissors} = g_S - g_D$$
  - $\text{Scissors} > 0$：供给增速超过需求，处于**绝对过剩**；
  - $\text{Scissors} < 0$：需求增速超过供给，处于**供不应求**。
- **二阶导（剪刀差边际收敛速度）**:
  $$\Delta \text{Scissors} = \text{Scissors}_t - \text{Scissors}_{t-1}$$
  - **〔B〕过剩收窄**: 当 $\text{Scissors} > 0$ 且 $\Delta \text{Scissors} < 0$（如由 +35.6pct 连续降至 +17.9pct），供给自律减产见效，过剩幅度边际收敛（**二阶导改善**）；
  - **〔B〕过剩走阔**: 当 $\Delta \text{Scissors} > 0$，扩产潮释放，供需恶化。

### 3. 库存蓄水池（供需失衡的时间积分）
库存是供给与需求差额在时间上的累积积分：$I(t) = \int (S - D) dt$。
- **零阶导 $I(t)$**: 行业总库存（如多晶硅 52.2 万吨，库存可用天数 19.95 周）。
- **一阶导 $I'(t) = \frac{dI}{dt}$**: 单月库存净变动（$\Delta \text{Inv}$，正数为累库，负数为去库）。
- **二阶导 $I''(t) = \frac{d^2I}{dt^2}$**: 累库/去库加速度。
  - **筑底前兆**: $I' > 0$ 但 $I'' < 0$（虽在累库，但月增量从 20 万吨降到 3 万吨，接近去库临界）；
  - **右侧弹性**: $I' < 0$ 且 $|I'|$ 放大（实质性去库，二阶导爆发）。

### 4. 终端需求与出口（量的敏感度最高）
- **〔A〕量永远领先价与财报**:
  5 个行业跨周期验证表明，**顶部的第一预警全部是“量先歇”（量增速见顶回落），无一例外**；底部领先信号同样是量（量增速率先转正，领先价格 6~10 个月）。
- **〔A〕量见顶 × 财报加速 = 最危险离场信号**:
  当装机/出口量增速见顶回落（$Q'' < 0$），而财报净利润仍在加速（$NP' > 0$）时，是周期顶部最具杀伤力的结构（历史 6m 中位收益 **-7.9%**，见 `11_cycle_derivative_framework.md` §1）。

## 四、最新周期实证诊断（2026-09 真实数据对账）

以基准日 2026-09-04 本地 Curated 黄金事实为准进行全阶导数对账：

| 观测维度 | 零阶导 (Level) | 一阶导 (1st Deriv) | 二阶导 (2nd Deriv) | 综合状态定性 |
| :--- | :--- | :--- | :--- | :--- |
| **组件价格** | 0.690 元/W (现金成本下) | 周环比 -4.56%, 同比 -1.85% | 同比由 +2.8% 再度转负至 -1.8% | 一阶导仍负，二阶导在零轴震荡磨底 |
| **供需剪刀差** | 绝对产能过剩 | +17.9pct (>0, 供给快于需求) | 连续 4 个月收窄: 35.6%→17.9% | **二阶导正向改善显著 ($\Delta < 0$)** |
| **多晶硅库存** | 52.2 万吨 (近 20 周极值) | 单月累库 +22.1 万吨 | 累库由缓增变骤增 ($I'' > 0$) | 一阶导与二阶导双重恶化 |
| **国内装机** | 7 月 12.0 GW | 环比连续 4 个月负增长 | 减速斜率趋缓但未拐头 | 处于平台减速磨底期 |

### 实证诊断结论：
1. **零阶导视角**: 行业处于全链条亏损、52 万吨库存堰塞湖的极度悲观期；
2. **二阶导视角**: 供需剪刀差持续 4 个月收窄，供给收缩初显成效；
3. **当前周期阶段**: **“二阶导微露曙光，但一阶导全负，库存二阶导严重恶化”**。
   - 处于**典型的第四象限（左侧磨底与拉锯期）**；
   - 绝非主升浪，亦非右侧反转点，过早重仓博弈反转极易被高库存与价格二次探底反噬。

## 五、四象限周期状态机与操作指南

```
                    二阶导 f''(t) [加速度 / 变动方向]
                               ▲
                               │
               第四象限         │         第一象限
          【左侧磨底 / 减速衰退】 │    【主升浪 / 加速繁荣】
          f' < 0, f'' > 0      │    f' > 0, f'' > 0
          价格跌幅收窄          │    量价齐升，业绩爆发
          剪刀差持续缩窄        │    持股加仓，享受戴维斯双击
         (★ 当前光伏所处阶段)   │
                               │
 ──────────────────────────────┼──────────────────────────────► 一阶导 f'(t)
                               │                           [速度 / 景气水平]
               第三象限         │         第二象限
          【主跌浪 / 加速衰退】 │    【顶部前兆 / 减速繁荣】
          f' < 0, f'' < 0      │    f' > 0, f'' < 0
          降价踩踏，库存暴增    │    量增速见顶回落，剪刀差走阔
          坚决空仓防守          │    财报虽好，坚决离场 (量跌×财报冲高)
                               │
                               ▼
```

### 操作指南：
- **象限一（主升浪）**: 组件同比站稳正增长，出口量增速加速。策略：**满仓持股**。
- **象限二（逃顶防守）**: 财报利润高增，但装机/出口量增速见顶回落（二阶导恶化）。策略：**知足离场，坚决减仓**。
- **象限三（主跌浪）**: 价格破位暴跌，累库加速。策略：**空仓规避，不接飞刀**。
- **象限四（左侧磨底，当前阶段）**: 价格跌幅收窄，剪刀差由 35% 收敛至 10% 附近。
  - **策略**: 底仓观察，防守为主；
  - **右侧跃迁条件（进入第一象限）**: 必须满足 **多晶硅月度库存环比去化 $> 5$ 万吨（去库二阶导）** 叠加 **组件周价同比连续 4 周 $> 0$（价格一阶导确认）**。
