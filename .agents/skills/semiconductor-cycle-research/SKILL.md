# 半导体产业周期快速研究 (Semiconductor Cycle Research)

本技能提供半导体产业周期的**方法论引导与工作流程**：如何用本地垂直产业黄金表定位周期相位、识别拐点、推演未来。只讲方法与流程，不复述数据结论。

遵循**渐进式披露**原则，本入口聚合高频原则与标准 SOP；具体数据口径以代码、配置与运行产物 Manifest 为准。

---

## 1. 核心原则 (Golden Rules)

1. **Ground Truth First**：所有点位、增速、价格、利用率、库存必须来自本地 Curated 黄金表（`data/curated/industry/`）；本地缺失必须披露，不得用记忆或外部印象补造。
2. **周期框架优先，严禁孤立看单指标**：半导体是强周期产业，任何单一指标的涨跌都要放回「需求-供给传导链」与「库存周期」里解读，避免用绝对量当信号。
3. **一阶导定方向，二阶导定拐点**：增速（同比 yoy）只回答"现在朝哪走"，加速度（Δyoy）才回答"拐点是否临近"。周期定位必须同时看两者。
4. **无量纲化 (去体量通胀)**：跨期比较一律用增速（yoy/mom）、占比、比率或历史分位，严禁直接比较绝对销售额、绝对价格、绝对资本开支。半导体为 3~5 年强周期产业，分位与时间窗口仅保留 **5Y 可行性门槛**（月频 60 期 / 季频 20 期，有效样本 ≥80%），不强制要求 10Y；无法满足 5Y 门槛的数据集严禁套用滚动分位。
5. **信息分级**：区分「已验证事实」（黄金表数值）、「机制推断」（传导顺序、拐点判据）、「外部背景」（联网核验，标注信源与时效）。

## 2. 本地数据资产与 5 大产研分类

半导体垂直产业事实表规范物理归属于 `data/curated/industry/semiconductor/<category>/`，按 5 大产研分类维度组织：

1. **`sales` (销售与产出 - 同步)**：WSTS/SIA 全球与中国区销售额、台积电月度营收。
2. **`inventory` (库存与出清 - 同步/滞后)**：全球 7 大 IDM DOI 存货周转天数、全球通路商（Arrow/Avnet）渠道库存。
3. **`equipment` (设备与资本开支 - 领先)**：SEAJ/SEMI 全球设备出货、ASML/AMAT/LRCX/TEL 核心设备商毛利率。
4. **`capacity` (供给约束与先进制造 - 领先/同步)**：晶圆代工产能利用率、芯片交期周数、TSMC 先进封装与 CoWoS 产能测算。
5. **`price` (价格与存储基准 - 高敏同步/滞后)**：DRAM/NAND 现货与合约价格、模组与存储标杆企业月度营收。

> - **投研消费指南（只读黄金表 / 极速查询）**：完整 16 张表字段字典、主键时钟、DataCatalog / Polars / DuckDB 读取代码模版与下游特征工程避坑规范详见 [`references/golden_tables_guide.md`](references/golden_tables_guide.md)；

## 3. 周期分析框架

### 3.1 需求-供给传导链（配置驱动：领先 → 资本开支 → 产出流水 → 价格出清）

半导体每一轮周期的主导需求各不相同（PC → 功能机 → 智能手机 → 汽车缺芯 → AI/HPC），**严禁全历史硬编码单一领先指标**。传导链由 `config/industry/semiconductor/demand_drivers.yaml` 按目标研究年份配置驱动：

```
[时代主导需求(领先)] → 设备出货(资本开支,领先) → 销售额/产能利用率(产出,同步) → 内存/芯片价格(价格与出清,滞后)
```

历史各时期需求驱动路由（详见配置 YAML）：
- **1990~2001 (PC时代)**：PC 季度出货与企业 IT 硬件支出（领先）→ 设备出货 → CPU/DRAM 销售额 → 标准内存价格。
- **2002~2008 (功能机/消费电子时代)**：功能机与数码产品出货（领先）→ 硅片/封测 → 晶圆代工与 IDM 销售额 → NAND Flash/MCU 价格。
- **2009~2019 (智能手机时代)**：智能手机出货与台积电月营收（领先）→ SEMI/SEAJ 设备 → 全球销售额/利用率 → 移动存储价格与渠道 DOI。
- **2020~2022 (疫情宅经济与汽车缺芯)**：泛终端重复下单与芯片交期拉长（情绪与交期领先）→ 设备积压 → 成熟/先进制程利用率打满（100% 同步）→ 功率/MCU/存储全面暴涨。
- **2023~至今 (AI/HPC时代)**：北美四大云厂商 AI CapEx（需求领先）→ 先进封装/设备扩产 → 台积电 HPC 营收/先进制程利用率 → HBM/高速内存价格。
- **跨周期兜底**：采用 `config/analytics/semiconductor_legs.yaml` 供需剪刀差（TSMC 月营收领先 + 全球销售额同步 − 设备出货供给释放）。

传导规律通用机制：
- **需求端最领先**：主导终端/资本开支决策先于芯片采购，其增速是周期发动机；需求增速见顶通常领先半导体销售额见顶 1~2 季。
- **设备是资本开支的物化**：设备出货滞后需求约 1~2 季，设备高增 = 未来 1~2 年产能释放（下一轮供给过剩的种子）。
- **价格弹性最大、最极端**：内存价格（DRAM/NAND/HBM）是周期最敏锐的价格信号，增速先于销售额见顶。

### 3.2 库存周期四相位

用「销售额 yoy」+「库存 DOI」+「产能利用率」三组联合定位：

| 相位 | 销售额 yoy | 库存 DOI | 产能利用率 | 特征 |
| :--- | :--- | :--- | :--- | :--- |
| 被动去库（复苏起点） | 触底转正 | 高位回落 | 底部回升 | 需求回暖，先清旧库存 |
| 主动补库（扩张） | 加速上行 | 低位回升 | 上冲 90%+ | 供不应求，补库+扩产 |
| 被动补库（过热/顶部） | 见顶回落 | 高位堆积 | 95%+ 钝化 | 需求放缓，库存被动上升 |
| 主动去库（衰退） | 深度转负 | 高位去化 | 跌破 75% | 主动减产去库存 |

### 3.3 内部结构分化视角

周期定位必须叠加结构分化，避免用总量掩盖内部错位：
- **内存 vs 逻辑 / 模拟**：内存（HBM/DRAM/NAND）弹性最大、波动最烈；逻辑（TSMC/代工）与模拟（TI/ADI/ST/NXP）更稳健。直接对比 `memory_weighted_doi_days`（存储三巨头加权）与 `analog_weighted_doi_days`（模拟四巨头加权）的剪刀差：存储 DOI 爆发式累库（如 2022Q4 飙升至 168.7 天）通常是全产业链见顶的最前瞻预警。
- **IDM 库存 vs 渠道库存**：渠道去化快于 IDM = 终端需求强、上游备货仍高；两者背离是"需求强但上游高库存"的顶部特征。
- **区域**：美洲（AI 需求）+ 亚太（中国国产替代）通常是本轮驱动；分区域 yoy 分化揭示结构性需求。

### 3.4 宏观大周期 vs 细分品种结构性极端错配 (Structural Squeeze)

必须将“全行业半导体宏观周期 Beta”与“窄品种极端供需错配 Alpha”解耦。历史上跑出数倍甚至十倍行情的品种（如 2017–18 高容 MLCC、2020–21 车规 MCU、2021–22 光伏 IGBT、2025–26 传统 DRAM/DDR4）通常遵循经典的 **9 步传导模板**：

```
① 行业总体供需改善 → ② 产能迁移/供给退出 → ③ 原厂与渠道库存见底 → ④ Spot 率先跳涨 → ⑤ 渠道恐慌抢货 → ⑥ Spot 进入非线性加速 → ⑦ 合同价 (Contract) 大幅跟涨 → ⑧ 承接龙头与低价库存商利润爆发 → ⑨ 替代倒逼与需求破坏/新增产能释放 → 价格崩盘
```

**区分"10× 错配"与"大宗阶段性挤压"的 5 大判据雷达**：
1. **整机 BOM 成本占比**：几分钱到数美元的短板小件（MCU/MLCC 占整机 <2%）下游对涨价高度钝化，易出 10× 极端溢价；大宗存储（DRAM/NAND 占整机 10%~25%）成本墙极厚，下游承受力有限。
2. **替代代际比价硬约束 (Price Parity Ratio)**：大宗成熟品上方存在新一代规格价格锚点。如 $\text{Price Parity Ratio} = \text{ASP(DDR4 16Gb)} / \text{ASP(DDR5 16Gb)}$：
   - $< 0.70$：存量需求稳定，成本优势显著；
   - $0.70 \sim 0.90$：下游 OEM 停止新增立项，加速向新一代主板方案迁移；
   - $> 0.90$（或倒挂）：引发剧烈**需求破坏 (Demand Destruction)**，存量采购断崖式萎缩。
3. **供给退出可逆性与二线/本土承接力**：原厂物理退出是否伴随二线或本土代工（如合肥长鑫 CXMT 688825.SH、台湾南亚科 2408.TW）的有效产能爬坡。
4. **现货 (Spot) 与合约 (Contract) 二元结构**：现货盘（占 5%~10% 流通盘）易被炒作逼空，但难以长期脱离占 90% 的 OEM 季度合约基本盘。
5. **方案重构与重新认证周期**：车规/工控软硬件重写认证需 12~18 个月（长短缺）；通用标准内存插拔切换仅需数周至数月（短脉冲）。

## 4. 量化工具：一阶导 / 二阶导

### 4.1 定义（无量纲）

| 阶数 | 定义 | 含义 | 拐点判据 |
| :--- | :--- | :--- | :--- |
| 水平 Level | 绝对额（销售额、价格、CapEx） | 体量 | 不直接跨期比较 |
| 一阶导 f' | 同比 `yoy = level_t / level_{t-12} - 1`（消除季节性） | 方向 | f' > 0 扩张，f' < 0 收缩 |
| 二阶导 f'' | 加速度 `Δyoy = yoy_t - yoy_{t-1}` | 拐点 | **f'' 由正转负 = 增速见顶；f'' 由负转正 = 降速收窄（触底）** |

环比 mom 与 Δmom 用于季频/月频内部节奏；跨年比较优先用 yoy 系列。

### 4.2 用法

1. **一阶导定相位**：销售额 yoy 正且加速 → 扩张；yoy 见顶回落 → 顶部。
2. **二阶导找拐点**：领先指标（NAND 价格、时代主导需求如云 CapEx / 手机出货 / 芯片交期）的 f'' 先转负，是周期顶部的最早预警；滞后指标（设备）f'' 仍正，说明下行未启动。
3. **全链条共振 vs 分化**：所有环节 f'' 同向为正 = 顶部区域共振；领先环节 f'' 已衰减、滞后环节仍加速 = 顶部传导前夜。

## 5. 标准工作流程 (SOP)

### Step 1: 读取黄金表最新状态与时代需求路由
先根据分析目标时间段，读取 `config/industry/semiconductor/demand_drivers.yaml` 获取对应历史时代的主导需求配置与领先指标；再用 `uv run python`（Polars）读取 `data/curated/industry/` 各表最新行，确认数据截止时点与各指标当前值。先核对口径（主键、单位、regime 阈值、foundry 加权方式），再分析。

### Step 2: 计算一阶导/二阶导
对关键指标（时代领先需求指标、销售额、内存价格、TSMC 营收、设备、CapEx、产能利用率）用 `pct_change(12)` 算 yoy、`pct_change(1)` 算 mom，再对 yoy 做一阶差分得 Δyoy（季频用 shift(4)/shift(1)）。

### Step 3: 周期定位
联合「销售额 yoy + 库存 DOI + 产能利用率 + 内存价格」定位四相位；再用「领先指标 f'' 是否转负」判断是否接近拐点。输出明确的相位结论（如"过热扩张中后段，价格增速已见顶、销售额增速仍加速"）。

### Step 4: 内部结构分化与极端错配监测
1. **宏观分化**：对比存储 vs 模拟（提取 `memory_weighted_doi_days` vs `analog_weighted_doi_days`）、内存 vs 逻辑、IDM vs 渠道库存、分区域 yoy。
2. **错配物料比价系数**：计算 $\text{Price Parity Ratio} = \text{P}_{61050} / \text{P}_{6105}$（DDR4 16Gb / DDR5 16Gb），监测是否越过 0.85~0.90 需求破坏红线。
3. **现货-合约剪刀差**：跟踪现货一阶导是否衰减（f'' < 0），若现货停涨而合约补涨，提示进入第 ⑦~⑧ 步冲顶区间。
4. **渠道库存反转**：Arrow/Avnet 渠道 DOI 是否连续 2 个月回升，排查“有价无市”虚假繁荣。
5. **本土与二线产能释放**：跟踪合肥长鑫（CXMT，688825.SH）、南亚科（2408.TW）等承接主体的出货节奏。

### Step 5: 外部高频事实核验
用 GrokSearch-rs MCP 检索内存现货/合约价、HBM 供需、云厂商 CapEx 指引等最新事实，与本地数据交叉印证方向；对极端量级（如内存价格数十倍涨幅）标注"趋势可信、价位需原始报价核验"。联网不可用时如实披露，不虚构信源。

### Step 6: 未来 1-3 年推演
给出多情景（基准/乐观/悲观），每个情景绑定**可观测的拐点触发条件**（如"时代主导需求增速 yoy 见顶回落"→ 需求端见顶；"设备 f'' 转负"→ 资本开支见顶；"价格 f'' 转负"→ 价格见顶；"代际比价倒挂"→ 结构错配终结），而非无条件的单点预测。
