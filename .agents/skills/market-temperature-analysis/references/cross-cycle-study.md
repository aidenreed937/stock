# 跨周期研究工作流

## 适用场景

当用户要求比较一段交易日区间的市场环境、行业结构、资金运动、重要信号日或简报变化时，使用本工作流。

## 执行顺序

1. 以本地已落盘交易日确定区间，不用自然日补齐。
2. 先运行区间一致性校验：

   ~~~bash
   make report-consistency START=YYYY-MM-DD END=YYYY-MM-DD
   ~~~

3. 校验通过后生成跨周期复盘：

   ~~~bash
   make market-cycle-review START=YYYY-MM-DD END=YYYY-MM-DD
   ~~~

4. 读取复盘产物及其引用的上游 Manifest；不要从 latest 或目录修改时间推断观测日。

## 解读顺序

- 市场环境：综合温度、系统风险和六维变化；
- 结构确认：短期与中期行业扩散、结构健康度和领先行业的持续性；
- 行业方向：领先、改善、拥挤、落后和资金确认的变化；
- 驱动拆解：使用产物已生成的跨期变化和事实日期，不重新发明一套变化口径。

## 核心判断

- 综合温度说明风险环境，行业结构说明方向，两个结论不能互相替代。
- 短期扩散强而中期确认弱，只能称为修复或短线占优。
- 价格上涨但资金事实未同步时，应写成价格先行、资金待确认。
- 单日资金脉冲不能替代窗口趋势；资金事实日期可能晚于行情观测日，必须单独披露。
- 低频基本面和宏观数据说明底座状态，不解释区间内每个交易日的波动。

## 输出约束

跨周期结论必须注明起止日期、交易日数和一致性校验状态。若某些日期缺少上游产物、驱动不可比或出现情绪/质量降级，应把它们作为可比性限制，而不是强行生成完整排名。
