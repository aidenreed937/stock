# 综合市场温度解读框架

## 用途

本文件提供市场温度结果的阅读顺序和常见背离解释，不定义评分公式、温度阈值、仓位比例或硬闸门。具体分档和风险字段以当前配置及运行产物为准。

## 六个问题

阅读六维结果时，可以把各维度理解为六个互补问题：

- 估值：当前安全边际和赔率如何？
- 资金：价格变化是否得到资金事实确认？
- 情绪：市场活跃度和拥挤程度是否在放大波动？
- 技术：价格和广度是否形成趋势确认？
- 基本面：盈利底座是否支持当前定价？
- 宏观流动性：利率、信用和外部环境是否提供顺风或逆风？

这些是解释问题，不是固定指标清单。实际使用哪些事实由当前配置和管线决定。

## 推荐阅读顺序

1. 先看综合温度、系统风险和质量状态，判断结果是否适合进一步解释。
2. 再看六维结果，找出推动或拖累综合状态的主要维度。
3. 再看行业结构，判断资金和价格正在向哪些方向集中。
4. 最后看短线窗口、外部冲击和数据水位，区分快变量与慢变量。

## 常见背离

- 价格和技术走强，但资金或中期广度没有同步：描述为价格先行或短线修复，等待确认。
- 短期广度改善，但中期广度仍弱：描述为修复未确认，不直接称为趋势反转。
- 综合温度偏高，同时拥挤或资金确认转弱：提高回撤和追高风险表述。
- 估值偏低但技术和资金仍弱：描述为赔率改善，不等同于短期已经见底。
- 多个维度缺失或质量状态较差：降低结论强度，不强行补全市场状态。

## 风险表达

市场温度是风险环境摘要，不是自动交易指令。仓位、止损和参与方式必须结合当前产物的风险字段与用户自身风险约束，不能从本文件推导固定比例。

外部市场的隔夜冲击在下一交易日 A 股数据确认前，只能写成待确认观察；不能把外部事实直接写成 A 股已经发生的风险。

## 事实层级

输出时区分：

1. 已验证事实：运行产物中的日期、数值、状态和水位；
2. 机制判断：由多个事实组合得到的市场状态解释；
3. 数据限制：缺失、滞后、低频、口径不明或覆盖不足。

不得使用新闻、政策或模型记忆填补本地没有的事实。
