# 极端状态与复盘纪律工作流（Extreme-State Playbook）

## 适用场景

当用户要求复盘（每日盘后、阶段/跨周期复盘、区间参与评估、信号一致性检查）时，在既有"投研实操四步交付规范"基础上，优先读取 `quant_brief` 产物的 `extreme_state` 与 `cross_cycle` 字段并按本工作流组织解读。

详细设计与校准依据（两份定稿设计文档）：
- `docs/research/extreme_state_route_design.md`：四层执行链与窗口原语。
- `docs/research/cross_cycle_odds_matrix_design.md`：胜率/赔率矩阵与 61/502/745 天校准记录（§11、§11.4）。

## 复盘执行链（L1-L4，顺序执行）

| 层 | 内容 | 产物字段 |
|---|---|---|
| L1 风控裁剪 | 五道闸门；高温 >60 只减不加；拥挤一票否决 | `risk_gates`、`extreme_state.hot_window` |
| L2 极端状态定位 | 高温/冰点/拥挤三类窗口，窗口可并存；hot 优先于 frozen；crowded 不改总仓 | `extreme_state` |
| L3 档位纪律 | composite 温度带为仓位唯一信任源；只允许偏置下调，不因看好上调 | `position_policy` |
| L4 方向约束 | priority 方向分两类角色：防御底仓（低波）/ 条件弹性（周期波段），不当作买入预测 | `sector.priority` |

## 已定稿核心纪律（745 天实证，§12 分层复核后）

| # | 纪律 | 745 天证据 | 层级 |
|---|---|---|---|
| 1 | 高温只减不加 | hot fwd5 −5.56、正占比 17%（n=52）；仅强资金段有样本，冷年无触发 | L1/L2 |
| 2 | **冰点左侧分批，须叠加 3 日加速下探确认** | frozen 全样本 fwd3 +2.61（64%）；冷年平缓低温 fwd3 −0.18（50%）失效，加速下探组 +3.35（64%） | L2/L3 |
| 3 | **系统性风险升档（≥中等）= 独立降温信号** | 冷年 −5.82（18%）/ 强资金段 −4.35（26%）；两段同强，与温度独立（重叠 16%） | L1/L3 |
| 4 | 拥挤一票否决（回避波动而非方向） | crowded 为常态（46% 天数），回避拥挤=卖出波动 | L1 |
| 5 | 温度修复 ≠ 价格修复 | 复核窗口内温度上行而申万Ａ指下跌，解读须同时看价格序列 | 全局 |

冲突检查（hot 日不得加仓）0/52 保持；hot/frozen 两窗口定义互斥自洽。
冰点执行细则："低温 + 3 日降幅 ≤ −3"才触发左侧分批；强资金段可放宽为 frozen 窗口，冷年/弱市必须等加速确认（详见设计文档 §12.3）。

## 候选增强规律（745 天分半通过；未并入执行链前只观察、不执行）

下列候选在 745 天样本中"前/后半方向一致 + 正占比偏离 50% 显著"，且经控制变量检验有独立增量；
待扩大历史复核（2022-08 前深熊与 2021 慢牛）后决定是否升级为执行规则。

| 候选 | 证据摘要 | 潜在用法 |
|---|---|---|
| 温度单调轴：两端强、中段（40-55）噪声 | comp<30 fwd5 +8.33 (86%)；comp≥65 fwd5 −4.98 (16%)；中段几无预测力 | 冰点/高温阈值可按此轴细化（比现有 45/60 更苛端） |

已知弱候选（方向对但与其他信号高度重叠，Jaccard≥0.5，不作独立信号）：
快温<35/>55 极端（与温度水平重叠 0.51）；背离±15 极值（部分重叠 hot/frozen 定义，非冰点背离仅 n=31）。

## 参考项（745 天未现方向性，仅作语境）

- 轨迹修正项：收敛（fwd1 +1.71、58%）、恶化（fwd1 −1.29、43%；fwd3 −2.47、34%）——无"恶化后反弹"证据，不作信号。
- left 象限（O高S低）：fwd1 −0.52、42%（n=59）——失效，复盘优先用 frozen 窗口而非象限。
- avoid 象限：fwd3 +4.47、74%（n=31）——仅"低温修复"参考，非高位回避证据。

## 每日复盘检查单

`make daily-review DATE=YYYY-MM-DD` 已内嵌 "量化风控闸门与极端状态执行链 (L1-L4)" 小节，自动输出下列检查项；运行后直接核对报告即可：

1. **窗口状态**：`extreme_state` 当前窗口、仓位偏置、crowded 名单（与昨日对比，名单扩大/收缩）。
2. **矩阵状态**：`cross_cycle` 的 S/O 档位、象限、轨迹事件（背离迁移/温度方向，仅语境）。
3. **风险档位**：`systemic_risk` 档位是否升档（≥中等）——已定稿独立降温信号（纪律 #3）；升档时即使温度未到 hot 也执行减仓审查。
4. **触发线检查**：60 日扩散回升至配置线以上（赔率打开）、冰点 + 3 日加速下探确认（高赔率窗口，纪律 #2 的买入触发条件）。
5. **输出顺序**：先闸门 → 再温度截面 → 后轨迹语境 → 最后结构确认，区分已验证事实与机制推断。

## 阶段复盘检查单（10 交易日）

1. 引用 `market_cycle_review` 的 `phase_summary` / `signal_days` 确定阶段归属。
2. **窗口命中回顾**：frozen 日是否执行左侧分批（并检查是否满足 3 日加速下探条件）、hot 日是否有追高、crowded 日是否执行行业否决、升档日是否执行独立减仓审查。
3. 用诊断输出 `data/analytics/diagnostics/temperature_odds_matrix.json` 对照各窗口的前向统计（fwd1/3/5 均值与正占比）。
4. **候选规律回放**：温度是否处于两端（<30 / ≥65）——记录命中但按"观察不执行"处理，留给校准节累计。
5. 输出阶段画像：温度区间、扩散、资金、窗口分布（参考分段画像的做法）。

## 校准复盘（数据窗口累计 +60 个交易日后）

1. 重放 `scripts/diagnose_temperature_odds_matrix.py`（只读上游，安全）。
2. 复核已定稿纪律是否维持：高温窗口 fwd 显著为负；冰点窗口 fwd 正占比 >= 60%；冰点 + 加速下探优于平缓冰点；risk 升档两段负向；冲突检查 0。
3. **候选规律复核**：对"候选增强规律"节剩余候选（温度单调轴）重算分半方向 + 控制变量，确认是否维持；维持则写入设计文档（§12 后续节）并升级为执行规则，否则移入参考项。
4. 阈值漂移处理：改 `config/analytics/quant_brief.yaml` 的 `extreme_state` / `cross_cycle` 段（全部配置化）→ 重放诊断 → 重跑 quant_brief → 更新设计文档校准记录（`rules_version` 变化留痕）。

## 实证规律（745 天复核样本，2023-08-01..2026-08-26；数值随窗口变化——以诊断 JSON 为准，重放获取最新）

- 高温（composite > 60）后回调：745 天样本（n=52）温度 fwd5 −5.56、正占比 17%，方向一致性强（样本全部集中在强资金段，冷年无新增验证）。
- 冰点背离窗口（背离达配置极值阈值且快温达冰点阈值）后温度回归：745 天样本（n=340）fwd3 +2.61、正占比 64%。方向仍正、幅度较 502 天（+4.26 @74%）再收敛，左侧分批保留动作、不过度期待幅度。
- **温度修复不等于价格修复**：复核窗口内温度上行而申万Ａ指下跌，解读需同时看价格序列。
- 行业轮动服从"风险偏好钟摆"：下跌段防御抗跌、资金强段科技高弹性、回落段高波品种先杀跌。
- 拥挤行业 = 高波动资产：回避拥挤是"卖出波动"而非"卖方向"，与风险控制优先一致。
- 轨迹修正项（收敛/恶化）经 745 天仍未现方向性：不作强信号，仅作语境（详见设计文档 §11.2/11.4）。

## 限制

- 规律来自单窗口样本（hot 子样本 52 天偏小，且集中于 2024-09 后强资金段），方向一致但需窗口扩大复核（上游数据下限 2014-08）。
- 全部 fwd 统计度量温度惯性而非价格收益；候选增强规律（温度单调轴）尚未写回设计文档，复盘时按"观察不执行"对待。
- 复盘输出必须区分本地验证事实 / 机制推断，注明观测日与样本窗口。
- 本工作流是解读纪律，不是收益保证，不构成个性化投资建议。
