# 化工周期与化工产品量化投研 (Chemical Cycle & Product Research)

本技能提供化工大宗品、中间体、精细品及配额制化工品的**双轨量化投研方法论与实操工作流**：
- **阶段一 (Phase 1) - 全板块横向截面扫描雷达**：一键聚合 8 大化工核心品种，在同一基准日对齐价差、边际成本击穿、库存时钟、外需象限与 EPS 弹性，生成 0~100 分综合景气度排序与配置定调；
- **阶段二 (Phase 2) - 细分品种垂直深度爆破**：深入目标细分品类，结合多工艺成本曲线、供需剪刀差与声明式交易门禁，识别周期拐点并输出量化决策。

## 1. 核心定位与适用边界 (Applicability & Archetypes)

> [!IMPORTANT]
> **强通用性边界铁律**：本技能面向**“大宗与周期型化工品”**，严禁套用于技术驱动的精细化工与特种化学品。

| 品类属性 | 核心代表品种 | 核心驱动矛盾与传导机制 | 适用性与边界 |
| :--- | :--- | :--- | :--- |
| **A 类: 大宗标准化/期货品种** | 纯碱、PTA、乙二醇、甲醇、PVC | 完全竞争、边际现金成本出清、交割仓单与工厂库存蓄水池。期货领先现货 1~2 周，价差领先报表 1~2 季度 | **强通用 (100%)** |
| **B 类: 寡头垄断壁垒型品种** | 聚氨酯 (MDI/TDI)、钛白粉 | 全球寡头协同控盘、月度挂牌价指导、海关出口缓冲。平滑周期底部，弱化完全竞争出清 | **强通用 (85%)** |
| **C 类: 行政配额管制型品种** | 三代氟制冷剂 (R32/R125/R134a) | 法定生产配额冻结永久切断 Capex 扩产负反馈，供给刚性，下游空调排产与出口直驱 | **强通用 (80%)** |
| **失效边界 (严禁盲目套用)** | 半导体光刻胶、电子特气、新材料、大炼化一体化集团 | 以专利壁垒、纯度认证、全厂裂解价差或技术渗透率主导，脱离单品种大宗加工差逻辑 | **不适用** |

## 2. 核心因果机制与投研铁律 (Golden Rules)

1. **真实数据第一 (Ground Truth First)**：
   - 点位、指标与分位必须来自本地 Curated 事实表或已校验的 Mart，不得人为臆测或用记忆补造。
2. **边际成本定价与出清底线 (Marginal Cash Cost Floor)**：
   - 价格中枢由边际高成本装置的完全成本决定；
   - 周期底部支撑是**边际高成本装置的现金保本成本线（剔除折旧的现金加工费）**。跌穿现金流是倒逼冷修减产乃至产能出清的唯一物理推手。
3. **供需剪刀差与四阶段库存时钟**：
   - 剪刀差（$\text{Demand\_Score} - \text{Supply\_Score}$）先于价格拐折 1~2 个月显现；
   - 顺次经历**主动去库**（减产出清）、**被动去库**（需求回暖现货升水）、**主动补库**（量价齐升投机囤货）、**被动累库**（需求钝化现货贴水）。
4. **周期股估值反向时钟 (Valuation Counter-Clock)**：
   - 景气顶部警惕静态个位数低 PE（TTM）估值陷阱；
   - 周期底部安全边际看 **PB 历史极值分位（<15%）** 与市值/重置成本折价。

## 4. 双轨标准投研作业流程 (Dual-Track SOP)

### 阶段一：全板块横向截面扫描雷达 (Cross-Sectional Radar)

当用户询问**化工大盘扫描、板块轮动、哪个化工品性价比高、周期拐点排行**时，优先执行阶段一：

```bash
make chemical-cross-section [DATE=YYYY-MM-DD]
```

1. **运行截面 Mart**：自动对齐 8 大品种各项指标并输出 ASCII 综合雷达大表；
2. **解读综合评分与配置定调**：
   - `OVERWEIGHT_LEFT`（击穿边际现金成本，极值赔率大底，逢低布局抗亏龙头，如纯碱·远兴能源、PVC·中泰化学）；
   - `OVERWEIGHT_RIGHT`（配额刚性或海外量价齐升，右侧共振进攻高弹性标的，如制冷剂·巨化股份、钛白粉·龙佰集团）；
   - `NEUTRAL_WATCH`（供需弱平衡或被动累库初显，中性跟踪）；
   - `UNDERWEIGHT_TRIM`（暴利高位钝化，警惕产能投放与低 PE 陷阱，逢高止盈）。
3. **典型大盘截面形态定性（两极哑铃结构）**：
   截面常呈现高度极化的**两极哑铃结构**，投研研判应严格遵循三层分区定位：
   - **底端极值赔率区 (SA / V)**：边际现金成本被深度击穿（覆盖率 19%~41%），依靠出清机制筑底，处于左侧布局阿尔法抗亏龙头（如远兴能源、新疆天业）的观察期；
   - **中端寡头/防御区 (TiO2 / MDI)**：依托寡头自律控盘与外需韧性维持盈利，处于右侧温和修复区；
   - **顶端高位警惕区 (TA / MEG / MA)**：当前纸面利润和开工率偏高，处于高位钝化与被动累库前夕，量化评分均被压制在 38 分防守线。
4. **圈定重点品种**：挑选排名靠前（Top 3）或处于关键拐点的品种进入阶段二。

---

### 阶段二：细分品种垂直深度爆破 (Vertical Deep Dive)

当用户指定**具体化工品**或从阶段一筛选出核心标的时，执行阶段二：

1. **调取本地多工艺成本与价差**：核验市价与边际现金保本线的覆盖率；
2. **校验周度库存与仓单蓄水池**：确认处于四阶段库存时钟的哪一阶段；
3. **核查海关出口与外需韧性**：判断出口量价象限（Q1 量价齐升 / Q2 量增价跌 / Q3 双弱 / Q4 价增量跌）；
4. **加载交易门禁配置 (`trading_gates.yaml`)**：
   - **左侧赔率门禁 (`left_side_odds`)**：市价跌破现金保本线 + 深度破净/低PB分位 $\rightarrow$ 建立基础底仓，配置 `alpha_leader`；
   - **右侧胜率确认门禁 (`right_side_confirmation`)**：装置实质性降负 + 连续去库 + 基差修复 + 放量突破均线 $\rightarrow$ 加码重仓，切换至 `beta_elastic`；
   - **逃顶一票否决门禁 (`top_escape`)**：开工打满钝化 + 超额暴利 + 逆势被动累库 + 静态低PE陷阱 $\rightarrow$ 清仓离场；
5. **联网微观核验 (GrokSearch-rs)**：核验大厂检修/不可抗力、下游排产与现货成交均价；
6. **输出量化投研报告**。
