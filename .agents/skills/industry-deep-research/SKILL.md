# Industry Deep Research (中观产业量化深度投研技能)

## 核心原则

1. **真实数据第一 (Ground Truth First)**：
   - 严禁虚构行业整体 PE/PB 估值与历史分位数；
   - 必须通过运行 `stock_cli.industry_diagnose` 读取本地申万黄金表真实计算结果。
2. **中观产业视角 (Macro to Industry to Micro)**：
   - 聚焦于**行业供需周期、库存周转、产业链上下游传导与竞争格局 (CR3/CR5)**，而非单一公司细节。
3. **高频微观数据印证 (GrokSearch-rs MCP)**：
   - 结合 `grok-search-rs` MCP 检索该产业最新的核心微观高频事实（如原料报价、出货量、渠道库存与政策催化），填补季频财报时滞。

---

## 标准执行 SOP (5 步工作流)

### Step 1: 提取行业量化体检数据
执行本地中观产业诊断命令：

```bash
UV_CACHE_DIR=.uv_cache UV_PYTHON_INSTALL_DIR=.uv_python uv run python -m stock_cli.industry_diagnose --industry <INDUSTRY_NAME_OR_CODE> --format json
```

### Step 2: 行业估值水位与股息利差评估
- 检视行业整体 PE/PB 历史分位数（近 5Y / 10Y）；
- 评估当前估值是否处于历史极端低位、合理中枢还是过热泡沫区间。

### Step 3: 产业链上下游价格与毛利敏感性分析
- 对照 `config/industry/value_chain_map.yaml` 中的上下游图谱；
- 分析上游原材料成本波动对中游加工制造环节毛利率的传导影响；
- 梳理下游终端需求的核心驱动变量（渗透率、资本开支、出口等）。

### Step 4: 垂直产业高频微观事实联网核验 (GrokSearch-rs MCP)
- 直接调用原生 MCP 工具 `mcp__grok_search__web_search`（或 `web_search`）检索该行业的关键高频微观指标：
  - 白酒：检索今日酒价批价走势、中秋国庆动销与渠道库存；
  - 新能源/锂电：检索 SMM 碳酸锂现货价、动力电池月度装车量；
  - 电子/半导体：检索存储器价格指数、晶圆代工产能利用率；
- 在研报中以【高频产业微观事实（明确注明信源与日期）】呈现。

### Step 5: 竞争格局、龙头梯队与行业配置结论
- 分析行业成份股市值 Top 5 龙头梯队（马太效应与龙头壁垒）；
- 输出行业中观配置评级：【超配 (Overweight) / 标配 (Neutral) / 低配 (Underweight)】；
- 给出优选细分赛道与核心关注标的池。
