# 商品景气周期规律（本地实证）

> **性质**：skill 的补充性实证参考（非权威口径文档）；权威口径以 `methodology.md` 和
> `docs/research/customs_export_forward/METHODOLOGY_FINAL.md` 为准。
> **数据口径**：GACC `data/analytics/industry/customs_product_volume_price.parquet`，
> 商品段（product_key×unit_segment）2018-01~2026-07；全历史 156 段、最新月 152 段；
> 3MMA yoy、拐点/二阶导判定与 METHODOLOGY_FINAL §2.3、product_panel.py 同口径。
> **事件统计**：本会话临时分析（uv run python 片段，定义见 §7），样本相邻月有重叠、
> 未做行业/宏观/价格水平控制，属描述性实证——支持机制判断，不直接外推为策略参数。

## 1. 景气是循环，节奏可计量

| 指标 | 结果 | n |
| :-- | :-- | --: |
| 启动拐点 / 见顶拐点总数 | 774 / 756 次 | — |
| 上升期（启动 → 见顶）中位 | 6 个月 | 658 |
| 下行期（见顶 → 再启动）中位 | 4 个月 | 720 |
| 启动后金额 yoy 正增长持续中位 | **5 个月** | 774 |
| ≥2 轮循环的段 | 149 / 156 | — |

```text
启动 →(约6个月)→ 见顶 →(约4个月)→ 再启动：循环常态
```

## 2. 量先行体现在「二阶导」，不是「量转负」

| 事件 | 占比 | n |
| :-- | :-- | --: |
| 启动拐点前一个月量 yoy 已 >0 | 52% | 771 |
| 见顶拐点前一个月量 yoy 已 ≤0 | 29% | 754 |
| 量增速回落（二阶导）后 3 个月金额 yoy 下降 | 56%，中位 **−2.7pp** | 4718 |
| 量增速回落（二阶导）后 6 个月金额 yoy 下降 | 59%，中位 **−5.3pp** | 4529 |

**结论**：管用的是「量增速见顶回落」（二阶导），不是「量转负」——印证方法论
「择时看二阶导、确认看一阶导」。

## 3. 自身 36m 分位是强均值回归指标

| 事件 | 3 个月后金额 yoy 中位变化 | 方向确认占比 | n |
| :-- | :-- | :-- | --: |
| 自身分位 ≥ 90 | **−4.1pp** | 56% 回落 | 1972 |
| 自身分位 ≤ 20 | **+6.3pp** | 65% 回升 | 2278 |

**结论**：「高分位别追高、低分位进观察」有统计基础；回归对象是**金额增速本身**，
不是股价收益——与 12 号文档「分位高 ≠ 未来好（对未来收益无预测力）」不冲突。

## 4. 高位价驱动：钝化滞后，不是立即反转

| 事件 | 3 个月后 | 6 个月后 | n(3m) |
| :-- | :-- | :-- | --: |
| 价驱动 × 自身分位≥80 | 中位 **+3.1pp**，46% 回落 | 中位 **+7.3pp**，42% 回落 | 371 |

**结论**：价驱动的金额高增有价格惯性/供给收缩支撑，见顶是**滞后确认**；
「高位 × 价驱动」不能当立即离场信号，真正要盯量能否跟上（二阶导），否则是虚火。
样本较小（371），未做行业控制。

## 5. 当前结构（2026-07）

- **② 狂热高潮集中**：元件（6）、汽车零部件（5）、电池（5）、工业金属（5）、半导体（3）
  —— AI 算力链 + 出海链 + 新能源中游；
- **④ 萎缩/见顶集中**：专用设备（4）、农化制品（4）、化学制药（3）、普钢（3）、装修建材（2）；
- **③ 扩张放缓**：化学纤维、光伏设备、电网设备、通信设备；
- **① 景气扩张/启动**：乘用车、工程机械、自动化设备、医疗器械。
- **关键提示**：42 个②狂热段中 **33 个（79%）已出现「量增速回落」**——狂热区普遍
  「金额还高、量能先歇」，纪律上是持有但停止追加、等二阶导或财报确认。

## 6. 与既有锚点的一致性

- 「启动后金额正增长持续中位 5 个月」与 SKILL.md 行业层锚点（238 次启动，
  中位 5 个月）**完全一致**（本表为商品段 774 次独立重算）；
- 「量增速回落 → 金额 yoy 回落」方向与 methodology 锚点（315 episodes，+3m −1.7pp、
  +6m −4.0pp，行业层 2019~2026）一致；本表为商品段池（4718 事件），样本粒度更细、
  未控制重叠与行业，量级仅方向可比；
- 「分位回归增速、不预测收益」与 12 号文档、references/methodology.md 报告格式
  「分位高 ≠ 未来好」一致。

事件统计为本会话临时 uv run python 片段（未入库为脚本），口径定义：

- 上升期 = 启动拐点月 → 下个见顶拐点月（含首尾）的月数；下行期同理反向；
- 启动后持续 = 启动月起金额 yoy>0 的连续月数；
- 二阶导事件 = 「二阶导=量增速回落」月，取 t+3 / t+6 金额 yoy 变化；
- 价驱动高位 = 驱动类型=价驱动 且 pct_self_36m ≥ 80；
- 分位事件 = pct_self_36m ≥ 90（高位）/ ≤ 20（低位）；
- pct_self_36m 为近 36 频点内 ≤ 当前值的有效样本占比 × 100（≥12 样本），
  与 L2/L3 观察表 yoy_pct_36m 同口径。
