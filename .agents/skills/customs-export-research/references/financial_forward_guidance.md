# 出口数据 → 财报前瞻指引（Export-to-Financials Forward Guidance）

> **依据**：`METHODOLOGY_FINAL.md` §2/§7（3MMA yoy 四象限、GACC T+20 发布、桥接规则）、
> 27 号文档（出口与财报水平同步、拐点领先 7~10.5 月）、`METHODOLOGY_COMPANY_FINAL.md` §5（三层信号、f3 财报后视）。
> 本文件把"出口数据如何在财报披露前给出前瞻指导"固化为可执行口径，不重复行业方法论正文。
> **适用范围**：申万行业层（L2/L3）与公司层（H8 暴露 Mart）；数据全部来自本地黄金表（Ground Truth First）。

## 1. 一句话口径

海关出口为**月频、T+20 发布**，同季度出口数据在对应财报披露前即可全部可见，因此
**出口数据对财报是前瞻指引**（领先约 1 周到 4 个月）；财报披露后，出口数据再用于
**单季归因校验**。前瞻的对象是"营收方向与利润弹性"，不是股价。

## 2. 核心时序表（GACC T+20 → 财报披露）

| 出口月份 | 出口数据全可见 | 所在财报期末 | 财报披露 | 领先关系 |
| :-- | :-- | :-- | :-- | :-- |
| 1-3 月 | 4 月 20 日 | Q1（3/31） | 4 月底 | 与 Q1 财报几乎同步；对中报领先约 4 个月 |
| 4-6 月 | 7 月 20 日 | 中报（6/30） | 8 月底 | **领先中报约 1 个月（前瞻）** |
| 7-9 月 | 10 月 20 日 | 三季报（9/30） | 10 月底 | 领先三季报约 1-2 周起（7 月数据 8/20 已可见） |
| 10-12 月 | 次年 1 月 20 日 | 年报（12/31） | 次年 4 月底 | 领先年报约 3 个月 |

规则：**出口 M 月数据约 M+1 月 20 日发布**。季度窗口"全部可见"时点 = 该季最后一个月数据发布日。
数据"已进报表"（内容层面）与"先于披露可见"（信息层面）是两回事——**前瞻指引成立靠的是后者**。

## 3. 机制：为什么出口能前瞻财报

1. **传导链**：出口（当期发货/订单）→ 收入确认（同期或次季）→ 利润（量增摊薄固定成本、出口端毛利通常更高）。
   财报披露晚于出口数据是**信息披露制度造成的时滞**，不是机制时滞；
2. **量最领先、价确认、金额合成**：量拐点最先见，价确认，金额综合反映；
3. **实证锚点（27 号）**：出口与财报**水平同步**、出口**拐点领先财报 7~10.5 个月**——水平同季、拐点领先；
4. **财报 TTM 是后视腿**：f3 只做验证、不参与前瞻排序——出口数据是财报披露前的**先行变量**，不是替代财报验证。

## 4. 前瞻指引三步法

### 4.1 算出口读数

- 主读数：**金额 3MMA yoy**；辅助：四象限驱动（量价齐升/量驱动/价驱动/双弱）、二阶导、36 月经验分位；
- **刻度避坑（必读）**：parquet 面板（`customs_l2_volume_price_monthly` / `customs_product_volume_price` /
  `customs_forward_watch_l2/l3` / H8 公司面板与信号）的 `*_yoy_3mma` / `yoy_growth_3mma` 列存**小数**（1.0 = +100%）；
  观察报告与 `_latest.csv` 已展示百分数。二次加工必须乘 100 或核对口径；
- **反算校验法**：用黄金表 hs8 原始逐月金额重算 3MMA 同比并与面板 raw 列对账（示例：煤化工 2026-05~07
  合计 4.1197 亿美元 vs 基期 0.4004 亿 → **+928.9%**，与面板 raw `9.289` 一致；误读为 +9.3% 是 100 倍错误）。

### 4.2 对照披露窗口

按 §2 表定位"本次出口窗口领先哪份财报"：

| 当前可见出口 | 前瞻标的 | 落地校验 |
| :-- | :-- | :-- |
| Q1（1-3 月，4/20 可见） | 中报（8 月底）的一部分 | 中报披露后拆 Q1 单季 |
| **Q2（4-6 月，7/20 可见）** | **中报（8 月底）** | 中报披露后拆 Q2 单季 |
| Q2+Q3（10/20 可见） | 三季报（10 月底） | 三季报披露后拆 Q3 单季 |
| Q4（次年 1/20 可见） | 年报（次年 4 月底） | 年报披露后拆 Q4 单季 |

### 4.3 生成指引与形态分类

对每个行业 L2/L3（或商品）：

- **兑现中（出口正 × 财报正）**：出口放量已在最近财报部分兑现 → 保持跟踪，校验弹性；
- **前瞻窗口（出口正 × 财报负）**：出口已先行、财报未兑现 → 下一份财报的验证候选
  （若出口延续则财报大概率转正/加速，若出口回落则确认未传导）；
- **背离（出口负 × 财报正等）**：出口领先转弱，财报仍高 → 警惕"利好兑现后回落"，按 k = 出口二阶导处理。

## 5. 财报口径（怎么读）

- **三种口径**：
  - YTD 累计：`q.ps.toi.t / q.ps.np.t`（按 `standardDate` 排序）；
  - TTM yoy：官方 `ttm_y2y` 优先，`ttm_y2y_derived` 仅补官方缺失且四季度数据足够者；
  - 单季：本期 YTD − 上期 YTD，同比与上年同期单季比；
- **单位**：Curated 金额为元/USD 原币，展示亿元直接 /1e8；
- **同口径提醒**：行业合并财报与海关 L3 **不是严格同口径**（覆盖公司/税号不同），只能方向互证、不对数额；
- **增量贡献算法**（判断出口对财报增长的边际拉动）：
  `出口增量（美元）× 汇率 ÷ 行业营收增量`——存量占比小（<5%）≠ 边际拉动小。

## 6. 公司层应用（H8）

- **公司序列 = 出口额 × 暴露度**（`company_h8_export_value_usd = export_value_usd × product_exposure`）；
  暴露度来自 `fina_mainbz(P)` 自动映射 + `company_segment_binding.csv` 人工修正单表；
- **公司级 yoy ≠ 商品级 yoy**：低暴露/报告期切换会让公司级 3MMA yoy 爆表——**选池以商品级景气 × 暴露度 ×
  质量层为准，不按公司 yoy 排序**；
- **f3 财报真扩张仅作后视验证**：出口正×财报双正 = 真扩张；营收正净利负 = 增收不增利降级；
- 财报前瞻对公司的落点：先在行业层确定"前瞻窗口/兑现中"行业，再映射到 exp 高、质量层正常的 A/B 公司作为跟踪名单。

## 7. 判读纪律与限制

1. 前瞻的是**财报方向与利润弹性**，不是股价 alpha（评级是板块贝塔代理，池内精化靠 quality_filter 与价格位置）；
2. 快周期商品（锂/铜/银）**交易信号排除**（GACC 口径轮次少、月度确认滞后于商品脉冲），行业观察保留；
3. 低基数警惕：极端净利 yoy 多为低基数读数，不当作趋势强度；
4. 数据限制：数据水印与 catalog 规模以最新产物为准——快照月见 `customs_prosperity_manifest.json` watermarks、
   税号行数见 `uv run python scripts/check_catalog.py`、待补采清单见 `data/analytics/industry/customs_export_backlog.csv`
   （行数随采集变化，不在此固化）；个别产品采集缺口以 golden 实测为准；价 yoy 极端值可能是 ASP 单位/基数伪影；
5. 一致率 C 级行业（通信/消费电子/家居/特钢/风电/工业金属）出口只覆盖行业收入一部分，
   出口读数不能推断财报方向——这类行业的前瞻指引降级为"仅参考"。

## 8. 复现

```bash
# 行业管线（金额 → 量价 → 商品拐点 → 观察表）
uv run python -m stock_cli.customs_prosperity

# 公司层（H8 暴露 Mart + 三层信号）
uv run python -m stock_cli.customs_company_h8 --as-of-period <报告期> --with-signal

# 指引表生成（Q2 出口同比 × 观察表财报形态，polars 片段）：
# 1) customs_l2_volume_price_monthly（粒度=L3）按 code 汇总当季与上年同季金额，相除-1 得季 yoy（小数刻度）；
# 2) 与 customs_forward_watch_l3 按 idx_code join；
# 3) 形态列：q2_yoy>0 & revenue_y2y>0 → 兑现中；q2_yoy>0 → 前瞻窗口；否则 → 背离；
# 4) 公司映射：good_h8_codes.target_l3_codes 含 idx_code 的产品 → H8 信号 A/B 公司（exposure≥0.2、非顶背离、非亏损型）。
```

## 9. 附录：大宗商品研究法 —— 出口量价 ↔ 期货/现货 ↔ 财报

**定位**：对大宗商品（甲醇/乙二醇/纯碱/PTA/尿素/MDI/钛白粉等），三表对账比单纯看行业面板或财报更清晰——
海关出口 ASP 是**外盘价格锚**，国内期货/现货验证内盘，财报单季验证利润弹性。

**价格源**：

| 商品 | 期货（交易所/主力） | 现货源 | 外盘参考 | 仓库内价格代理 |
| :-- | :-- | :-- | :-- | :-- |
| 甲醇 | 郑商所 MA（CMAc1） | 生意社/隆众（华东港口、地区价） | CFR 东南亚 / FOB 鹿特丹 | 出口 ASP（`customs_product_volume_price`） |
| 乙二醇 | 大商所 EG（egm） | 隆众/生意社（华东主港） | CFR 中国 | 出口 ASP |
| 可扩展 | 纯碱/PTA/尿素/MDI/钛白粉对应品种 | 生意社 `spot_*_cny`（`chemical_market`） | 视品种 | 出口 ASP + `chemical_market` 现货价 |

**研究流程（五步）**：
1. 出口量价读数：`customs_product_volume_price` / `customs_l2_volume_price_monthly` 的量 yoy、ASP、价格 yoy、驱动、分位；
2. 外部价格互证：期货主力 + 现货（生意社/隆众/卓创）+ CFR/FOB 外盘，确认方向与量级；
3. 库存/进口侧：港口库存、到港量、进口依存（外部数据），判断紧张度与价格弹性；
4. 财报单季验证：行业/公司财报单季营收/净利 + 增量贡献算法（见 §5）；
5. 三表对账结论：出口价 ≈ 外盘价 → 国内价传导 → 利润弹性，逐项标注数据源与时效。

**纪律**：
- 外部价格数据**只作参考与互证，不写入黄金表**（Ground Truth First：标注来源与时效）；
- 地缘/事件驱动的价格暴涨有快速回吐风险，结合"分位 + 二阶导"纪律不追高；
- 该法适用于**大宗商品**（价格全球联动、出口占比或进口依存高者）；对中高端制造（变压器/半导体等）价格互证意义弱，仍以量价与财报为主。

## 10. 研究文档写作规范（数据质量闸门，2026-10 审计后固化）

> 来源：`35_export_industry_historical_2026_10.md` 审计实证 → 固化为四条强制规则，适用于 customs 系列所有研究文档。

1. **数值溯源**：表格中每个数字必须能在脚本输出/复现命令中找到出处；找不到出处一律标 `-`，禁止按印象补格；
2. **断言先查证**：公司/行业个性断言必须先查询该数据行再落字，禁止从聚合统计反推个体（Ground Truth First）；
   尤其警惕"mapping selected 缺失 → 信号层无该公司"类盲区；
3. **统一覆盖检查**：涉及多行业的历史表，动笔前先对全部行业扫描覆盖/断裂（财报覆盖断裂、价 yoy 伪影、公司映射盲区）；
4. **定点修改优先**：修正用 `edit` 定点替换受影响的格与句，避免整表人工重写搬运（搬运层是幻觉值高发区）。
