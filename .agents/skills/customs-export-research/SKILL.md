# Customs Export Research (海关出口全景投研：行业景气与受益公司交易)

以海关商品量价拐点（月频 T+20 前瞻）为源头，自上而下贯穿中观行业景气与微观受益公司交易，财报只作后视验证。

```
[第一层：数据底座] GACC 海关原始明细 (8位税号月度序列，月频 T+20 发布，无前视对齐)
       │
       ▼
[第二层：中观行业] 申万 L2/L3 量价四象限 (选景气 Beta / 判驱动类型 / 财报前瞻观察)
       │ 产出：customs_forward_watch_l2.parquet、商品拐点二阶导、月度观察报告
       ▼
[第三层：微观公司] H8 主营暴露度 × 三层信号评级 (定受益标的 / 定纯金额分批择时)
       │ 产出：customs_company_h8_signal.parquet (A/B/C/D/顶背离)、买卖计划
```

## 第一层：GACC 海关数据底座（标准化与防前视）

- **数据底座**：`data/curated/industry/customs_trade_gacc.parquet`（海关黄金事实表，纳入产品与 8 位税号范围由 `config/data/customs/` 配置驱动并动态维护）。
- **发布日历与时序规则**：
  - **常规月（3~11 月）**：次月 20 日（T+20）在线发布；
  - **1~2 月特例**：因春节合并统计，1 月不单发，1~2 月数据统一于 **3 月 20 日**公布；
  - **12 月份**：次年 **1 月 20 日**公布。

- **季度出口与定期财报前瞻窗口对照**：

| 季度出口 | 海关数据全部可见时点 | 对应定期财报披露期 | 披露前瞻窗口 | 前瞻核心用途 |
| :--- | :--- | :--- | :--- | :--- |
| **Q1（1~3 月）** | 4 月 20 日（3 月数据落地） | 一季报（4 月 30 日截止） | 领先约 1~2 周 | 预判一季报外需开局与供需动能 |
| **Q2（4~6 月）** | 7 月 20 日（6 月数据落地） | 半年报/中报（8 月 31 日截止） | **领先约 1 个月** | **最核心前瞻窗口**，前瞻中报业绩兑现 |
| **Q3（7~9 月）** | 10 月 20 日（9 月数据落地） | 三季报（10 月 31 日截止） | 领先约 1~2 周 | 预判下半年外需韧性与预期差 |
| **Q4（10~12 月）** | 次年 1 月 20 日（12 月数据落地） | 年报（次年 4 月 30 日截止） | 领先约 3 个月 | 全年外需收官，大幅领先年报披露 |

- **严格防前视铁律**：
  - 缺失月份置 `null` 区分真实缺失，严禁补 0；
  - 统一按发布时滞（`release_date`）严格对齐，禁止将当月出口与当月交易日直接拼接；
  - 公司映射过滤上市日前视（`report_date >= list_date`）。

## 第二层：中观行业景气判断（选 Beta / 判驱动类型）

出口前瞻的是**行业营收方向与供需拐点**（方向/拐点可前瞻，水平值同步不领先，见 40 号文档），不预测短期盈利，更不直接预测个股短期涨跌。核心抓住**三条序列**与**二阶导拐点**：

> **商品量价机制（景气周期变化的驱动逻辑）**
> - **出口金额 = 数量 × 均价（P×Q）**：量、价是两个基本自由度，金额是合成指标——只能判方向/拐点，不能单独判健康度；
> - **量是先行腿**：需求变化先体现为订单量，价格是供需缺口的滞后均衡，故量增速最先拐头（二阶导最早转弱）；
> - **价是确认腿**：ASP = 金额/数量；价上行要么来自需求扩张（量价齐升=真繁荣），要么来自供给收缩/成本推升（量歇价升=价驱动虚火）；价→毛利率→净利，故价确认利润弹性；
> - **四象限 = 商品周期四阶段**：底部（量先转正/价跌幅收窄）→ 主升（量价齐升）→ 顶部前兆（量增速见顶回落）→ 衰退（量价双弱）；
> - **二阶导 = 加速度**：周期拐点最先体现在量的加速度而非水平值，故“择时看二阶导、确认看一阶导”；
> - **边界**：出口量价是行业外需的前瞻代理，只前瞻营收方向/拐点，不预测盈利与股价。

### 1. 三条序列（全部 3MMA YoY，hs8 同码对齐，研究口径只消费 GACC 官方数据）

定性描述（方向/拐点语义，数字见下方定量验证）：
- **金额 YoY**：`v3mma / v3mma_lag12 - 1`，主口径（量价合成）；
- **数量 YoY**：`q3mma / q3mma_lag12 - 1`，拐点层最领先变量——量增速见顶/转负是最早的拐点信号，水平值不领先财报（见 40 号文档）；
- **均价 ASP YoY**：`asp3mma / asp3mma_lag12 - 1`，价格弹性确认腿——价确认景气健康度并领先利润弹性（见 40 号文档）。

> **定量验证（2026-10，GACC 段重算）**：
> - 价 yoy 领先净利：`price_vs_profit` k=+3 中位相关 **0.295**（40 号锚点复现，48 行业）；
> - 量 yoy 领先营收：`volume_vs_revenue` k=-4 峰值 **0.250**（量最领先，领先约 3~4 个月）；
> - 拐点领先：出口金额转正领先营收转正 **中位 10 个月**（83% 先转正）。

### 2. 四象限驱动类型（判景气健康度）

| 驱动类型 | 量 YoY | 价 YoY | 业务含义与应对 |
| :--- | :---: | :---: | :--- |
| **量价齐升** | >0 | >0 | 量价双扩，最健康真繁荣，重点持有 |
| **量驱动** | >0 | ≤0 | 降价放量，需求扩张或以价换量，次优配置 |
| **价驱动** | ≤0 | >0 | 量歇价升，供给收缩或成本推升；短期利润弹性为正（价→毛利率→净利约 3 个月领先），风险在量能否跟上与持续性，警惕虚火与见顶前兆 |
| **双弱** | ≤0 | ≤0 | 量价齐跌，出清衰退，坚决回避 |

### 3. 关键拐点与二阶导

**观点结论（定性）**
1. **拐点 = 金额 yoy 一阶导符号翻转**：负转正 = 景气启动；正转负 = 见顶/退出。
2. **二阶导 = 量增速方向**：择时看二阶导（量增速见顶回落是最早的转弱信号）、确认看一阶导。
3. **财报前瞻窗口**：出口金额大幅转正（3MMA YoY > 0）而财报仍为负 = 供需景气启动、预期差修复窗口。
4. **最危险组合（利好出尽）**：量增速回落 × 财报仍在加速 = 滞后财报落地常是主升浪终点，触发减仓/离场（全口径 6m 中位 −7.9%，待 GACC 段重跑）。
5. **二阶导判节奏**：底部量先转正/价跌幅收窄（建观察仓）→ 主升量价齐升持续（持仓）→ 量增速见顶回落（减半观察）。

**实现边界（与面板对应）**
- 「拐点」列 = 金额 yoy 符号翻转（`启动拐点` / `见顶拐点`）；
- 「二阶导」列 = 仅「量增速回落」（顶部侧标记）；底部/主升为组合判读（金额启动拐点 + 驱动类型），非面板独立列；
- 最危险组合在 L2 观察表无现成列：量回落腿用商品面板「二阶导=量增速回落」× 财报加速自行交叉。

**定量验证与稳定性（GACC 段，2026-10 重算）**
- 启动拐点 238 次 / 见顶拐点 232 次（2019~2026 每年都有），启动后金额正增长持续中位 5 个月；
- 量增速回落 episodes 315 次，启动后金额 yoy +3m 中位 −1.7pp、+6m −4.0pp（全样本基准 +0.4pp / +1.1pp）；
- 财报前瞻窗口 166 个行业-季度（2020~2026 每年出现），下一季度金额仍为正占比 74%。

**行业层局限与何时下钻公司层**
- **行业层局限**：出口只前瞻行业营收方向/拐点，不预测盈利弹性与股价；行业聚合抹平内部结构分化（用 L3 作分化观察，L3 不作入场信号）；外需占比低/国内供需定价行业（光伏/电池/乘用车）出口回升 ≠ 盈利回升；价格主导行业（21 个 corr<0.5）金额上涨可能纯由价格驱动；C 级一致率行业不作前瞻判断；炼化/航空量价缺腿只能看金额腿。
- **钻入微观公司观察的场景**：行业 Beta 已定后定受益标的（H8 暴露度 exp ≥ 0.2）；过滤公司质量（亏损型/低竞争力在景气下行受损最深，财报真扩张+毛利率+估值/位置硬门）；执行个股择时（价格位置 + 纯金额 yoy 纪律）；排顶背离（出口高位/见顶 × 资金净流出 × 财报滞后仍好）；判资金腿（主力资金/两融仅公司层有）。
- **微观层不做什么**：不按公司出口增速排序选股（评级=板块 Beta 代理，横截面 corr ≈ -0.02~0.09）；微观作用是质量硬门+估值/位置+择时执行，不是找个股 alpha。

## 第三层：微观公司交易与择时（定标的 / 定买卖动作）

### 1. 标的选池：H8 暴露度与三层信号评级

> **实证定论**：公司评级本质是**“板块贝塔代理”（Beta Proxy）**。超额收益主要由其所处的景气板块贡献；同一评级池内，个股出口增速横截面预测力极弱（corr ≈ -0.02~0.09）。池内标的选择重点看**基本面质量硬门与估值/价格位置**。

**量驱动期的公司筛选（降价放量 ≠ 人人受益）**
- 核心：谁能「以价换量还赚钱」= **成本领先 × 量弹性 × 质量硬门**；
- 五步：
  ① L2 确认量驱动（量 yoy>0、价 yoy≤0、金额拐点/持续正）；
  ② H8 暴露度 exp≥0.2 锁定真实产品段；
  ③ **公司段量弹性验证**：量 yoy>0 且金额 yoy>0（真实放量降价），排除「量负价涨」的伪量驱动；
  ④ **质量硬门（量驱动特化）**：营收+扣非净利双正、毛利率不被价格战打穿，剔除亏损型/低竞争力；
  ⑤ 三腿评级 + 顶背离排雷；产品金额 yoy 连续 2 个月>0 分批建仓，价格位置硬门（长牛高位不追）。
- 实证（2024 变压器量驱动段）：三变/扬电/新特真实放量（量 +133%~+424%、价 −38%~−57%），
  三变增收不增利→剔除、扬电 A 但低竞争力→小仓位、金盘 2024-02 转价驱动→降级、
  保变全程价驱动（量负价涨）→非量驱动受益者。
- **为什么放量名单偏“差公司”（口径 + 规律）**：① 价格战期好公司保利润不跟跌，放量抢单的多是二线；
  ② 公司段 yoy 是「全国段 yoy × 暴露度」代理而非真实报关，暴露度季度更新会制造与全国段的偏差
  （如三变 2024-01 量 +240% vs 全国段 +118%）；小公司主营单一、单段暴露高，天然更容易进放量名单。
  因此量驱动期筛后样本小是常态：优先「质量正常且放量」的好公司，不硬凑仓位。

- **业务暴露度**：通过 `fina_mainbz` 主营拆解 + `company_segment_binding.csv` 人工修正，锁定对景气税号段有真实业务暴露（exp ≥ 0.2）的标的。
- **三层信号（评级用于选池，不用于择时）**：
  - **腿 1 出口前瞻**：段级金额 3MMA YoY ≥ 30% 且量价齐升/量驱动；
  - **腿 2 资金确认**：近 20 日主力资金净流入强度 >0 或融资余额扩张率 >0；
  - **腿 3 财报真扩张**：最新财报营收与扣非净利润双正（后视验证，增收不增利则降级）。
- **评级操作定义**：
  - **A 强机会**：三腿共振 → 重点跟踪，回调分批上车；
  - **B 确认中**：出口+资金启动、财报未出 → 前瞻仓位，等待财报验证；
  - **C 兑现中**：出口+财报双正、资金未跟 → 警惕已透支，不追高；
  - **D 前瞻观察**：仅出口正 → 纳入观察池跟踪；
  - **回避·顶背离⚠**：出口高位/见顶 + 资金净流出/两融撤退 + 财报滞后仍好 → **最危险杀跌陷阱，坚决减仓回避**。

### 2. 极简实战择时纪律（只看产品出口金额 3MMA YoY）

经跨产品历史样本回测验证，最优稳健策略为**纯金额 YoY 择时**（平均超额 +7.9pp，正超额胜率 81%）：

| 交易动作 | 触发规则 | 仓位管理 |
| :--- | :--- | :--- |
| **分批建仓** | 产品出口金额 3MMA YoY **连续 2 个月 > 0** | 分 3 个月等额建仓（每月 1/3） |
| **景气减仓** | 满仓后，出口金额 YoY **连续 2 个月环比下降（见顶回落）** | 仓位减半 |
| **彻底清仓** | 出口金额 YoY **≤ 0** | 全部清仓离场 |

## 月度实战执行 SOP（每月 20 日海关数据发布后）

1. **更新数据**：确认 GACC 当月数据入库 (`customs_trade_gacc.parquet`)；
2. **中观审视**：运行 `uv run python -m stock_cli.customs_prosperity`，查看 L2/L3 行业量价四象限与前瞻观察表，锁定处于“量价齐升/量驱动”的景气行业；
3. **微观筛选**：运行 `uv run python -m stock_cli.customs_company_h8 --with-signal`，按评级筛出 A强机会 与 B确认中 标的；
4. **硬门过滤**：剔除亏损型与低竞争力标的，排查并坚决剔除“顶背离⚠”标的；
5. **执行择时**：对照相关产品出口金额 YoY 连续月数，执行“分批建仓”或“减半/清仓”操作；建仓前核实个股价格位置（长牛高位不追，底部反弹顺势）。

## 避坑铁律与证伪清单

1. **不可按公司出口增速在池内排序选股**：个股出口增速是贝塔代理，池内超额主要取决于公司质量硬门（亏损型/低竞争力标的在景气下行期受损最深）；
2. **排除快周期大宗品**：铜、锂、银等大宗品受期货金融定价主导，出口量价不具备先行预测力，全体系强制剔除；
3. **出场不设数量门槛**：强制数量负增长才出场会导致假摔频繁震荡（whipsaw），离场以金额回落为准；
4. **彻底弃用方向分与多因子合成**：旧体系探索的 `direction_score`、资金吸筹单腿策略已被实证证伪（IC ≈ 0 甚至为负），严禁回退。
