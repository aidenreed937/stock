# 创业板指 / 中证红利 相对强度监测面板

> 独立市场强弱观察指标，**不是 v5 策略交易信号**（v5 的红利↔创业板切换由宏观状态机
> `panic/overheat/bias/smart_money` 驱动，不读取相对强度）。本面板用于宏观日报之外的
> 趋势观察与投研参考。

## 用途

观察创业板指 (`399006.SZ`) 相对中证红利 (`000922.CSI`) 的中长期相对强弱剪刀差，
辅助判断「进攻腿 vs 防守腿」的相对趋势状态，与 v5 当前持仓（满仓红利/空仓创业板）互为印证。

## 运行

```bash
uv run python scripts/index_relative_strength_panel.py            # 最新交易日
uv run python scripts/index_relative_strength_panel.py --as-of 2026-06-30   # 历史日复算
```

## 指标口径（Ground Truth First）

- 数据完全来自本地 Curated `index_daily_bar`（2008 起，不臆造点位）；
- **相对强度 ratio** = 创业板累计收益 / 红利累计收益（自窗口起点归一）；
  ratio > 1 表示窗口内创业板跑赢红利；
- **各期剪刀差**：近1月 / 近3月（含前3月边际）/ 近6月 / 近1年的 ratio 变化；
- **250日动量**：log-ratio 差分（年化），刻画中期方向；
- **历史分位**：当前 ratio 在全样本（2010 起共同交易日）中的位置；
- **年线相对位置**：各指数现价相对 250 日均线；
- **拐点解读**：基于 1 年扩张/收缩段 + 3 月 vs 前 3 月边际变化 + 近 1 月收敛警示。

## 当前读数（2026-09-02）

- ratio = 1.648，位于历史 **83%** 分位（中长期创业板仍相对红利偏强）；
- 剪刀差：近1月 -8.0%、近3月 -18.3%（前3月 +33.5%，边际 -52%）、近6月 +9.0%、近1年 +25.1%；
- 解读：**中长期扩张、短期明显退潮**——创业板相对红利强势正在收敛，红利重新相对占优，
  与当前 v5「满仓红利、空仓创业板」自洽。
