## 一句话结论

- **方向正确、条件区分强，但跨周期不稳**：score 与 fwd60 全周期 IC -0.221（显著），
  加息期 fwd60 中位 -3.0%/胜率 32% vs 降息期 +3.0%/73% vs 中性 +0.9%/54%。
- **加息周期不是简单的「前紧后松」**：A 股呈现「首冲下跌 → 中段蜜月/脱钩 → 尾部最痛」，
  两个大周期最痛段都在尾部（2018、2023H2-2024 初）。
- **降息周期确认「前松后弱」边际递减**（2019 周期 76%→60%→66% 胜率）；
  **停降 = 宽松利多出尽**，停降后 60 日普遍弱于降息实行期。
- **市场交易的是边际方向变化而非方向本身** → 幅度特征 `ffr_chg_6m` 在拐点处恰好归零，
  丢失最强信号；升级方向是「拐点/位置」事件特征（待决策，未实施）。

## 4. 周期内部结构检验（大周期切分：允许走平、方向反转才切换）

识别出 4 个大周期：加息 2015-12~2019-07、2022-03~2024-08；降息 2019-08~2022-02、2024-09~2026-08。

**加息：不是「前紧后松」，是「首冲 → 中段蜜月 → 尾部最痛」**

| 加息周期 | 第 1-6 月 | 第 7-12 月 | 第 13-18 月 | 第 19 月+ |
| :--- | :---: | :---: | :---: | :---: |
| 2015-12 起 | -3.52% / 42% | **+4.38% / 86%**（2017 慢牛） | -0.93% / 43% | -2.99% / 37%（2018） |
| 2022-03 起 | -5.51% / 41% | -1.99% / 35% | -2.67% / 31% | **-5.25% / 17%**（2023H2-24初） |

首冲（2016 初首加+熔断、2022 暴力加息启动）确有压制，但最痛都在**尾部**；
2017 年 A 股由国内流动性主导，与美联储加息脱钩走出蜜月。

**降息：确认「前松后弱」边际递减**

| 降息周期 | 第 1-6 月 | 第 7-12 月 | 第 13 月+ |
| :--- | :---: | :---: | :---: |
| 2019-08 起 | +2.49% / **76%** | +2.27% / 60% | +1.54% / 66% |
| 2024-09 起 | **+12.26% / 63%**（924 行情） | +0.92% / 66%（暂停期） | +4.06% / 73% |

2019 周期是干净的递减（76%→60%→66%）；2024 周期的最大脉冲也发生在降息重启首段
（叠加国内政策组合拳）。

## 5. 拐点效应：停加 / 停降（幅度归零处的信号）

**停加（加息结束）= 紧缩到头，拐点后普遍修复**：

```
2016-02: +14.1%  |  2017-08: +4.5%  |  2019-01: +38.1%（2019 春季行情）  |  2023-08: -8.8%（例外）
```

**停降（降息结束）= 宽松利多出尽，拐点后偏弱**：

```
2019-11: -2.7%  |  2025-01: -5.6%  |  2026-01: +0.4%
```

停加/停降事件正是 `ffr_chg_6m`（diff(6) 幅度）接近 0 的时刻——**最强信号出现在
幅度特征最弱处**，这是幅度型慢变量在拐点处的结构性盲区。

## 6. 机制解读与对特征设计的推论

1. **市场交易边际方向变化，不是方向本身**：首次降息 = 最大「方向确认」脉冲（2019、
   2024-09 均如此），后续同向重复递减 → 印证「降息后期边界效应减弱」。
2. **加息对 A 股是间接传导**（美元流动性/汇率/情绪），国内流动性主导时中段可脱钩（2017）；
   真正的痛点在尾部——停加前的经济恶化与流动性风险集中释放。
3. **`ffr_chg_6m` 作为幅度因子方向正确、条件区分强（§2/§3），但丢失位置与拐点信息，
   分年 IC 必然漂移（§2）**——维持「独立观测、不入维度/双轨指数」的现状判断成立。
4. **可选升级（未实施，仅提议）**：补两个独立观测事件/位置特征——
   - 自最近方向反转（停加/停降）以来的月数 → 捕获「利多/利空出尽」阶段；
   - 方向反转事件标签（hiking / cutting / hike_end / cut_end）→ 停加后 60 日
     +14%~+38% vs 停降后 -5.6%~+0.4%，是现有证据中最强的条件信号。
   两者仍保持独立观测，不污染维度与双轨指数；如需落地走因子接入流程
   （skill §1.1：register_fetcher → yaml → 刷新 → 验证）并另行回测评估。

### 6.1 传导链实证：加息 → 资本开支 → 供给滞后兑现（2026-09-04 补充）

> 承接 §6 机制解读，用本地供给/资本开支数据验证「加息收紧资本开支 → 供需数据收缩」的传导链
> （数据：SEAJ 设备出货 `semiconductor_equipment`、ai_capex 结构性腿、270100 剪刀差，均为本地 Curated/Mart）。

**结论：方向对、时序反直觉——供给数据不是跟着加息"慢慢收缩"，而是先扩张（兑现旧订单）后收缩（新决策被压制），中间隔 1.5-2 年。**

1. **资本开支确实随加息收紧**（直觉成立）：`ai_capex_score` 与 FFR 6 个月变化 **r=-0.616（p<0.001）**；
   2022-2023 加息期分位中位 17（低位）vs 2024-2026 降息期 92（高位）。
2. **但供给腿（SEAJ 设备出货）在加息期反而高增长**：2015-2017 加息期 YoY 中位 +19.9%、2018 尾部
   +26.8%、**2022 暴力加息期 +29.2%**——设备出货是 1-2 年前资本开支决策的滞后兑现，2022 年的货是
   2020-2021 繁荣期下的订单；加息收紧的是新决策，传导到出货要 6-18 个月。
3. **时滞实证**：加息幅度（ffr 6m 变化）与 SEAJ YoY 同期 r≈-0.05（无关）→ 滞后 6 个月 -0.25
   → 滞后 9 个月 -0.30（显著负相关，p<0.01）——供给收缩出现在加息启动 6-18 个月后。
4. **剪刀差转负领先加息 3-12 个月**：2015-2019 轮首次转负 2015-09（加息启动 2015-12，领先 3 个月）；
   2021-2024 轮首次转负 **2021-03**（加息启动 2022-03，领先整整 1 年）。

**修正后的传导链**：

```
需求繁荣(2020-21) → 资本开支决策高峰(2021)
  → 加息启动(2022-03) → 设备出货洪峰兑现(2021-22, YoY +29%)   ← 供给腿此时"反而扩张"
  → 剪刀差转负(2021-03, 先于加息) → 新 capex 决策被压制(2022-23, ai_capex 分位 17)
  → 滞后 6-18 个月出货增速放缓(2023-24) → 供给收缩 → 剪刀差修复
```

**对因子设计的两条含义**：

- **半导体深研线加息腿正交性否决的机制解释**：防守门（剪刀差<0/DOI≥70）捕获的是产业供需周期
  本身，剪刀差转负领先加息启动；加息只是同一轮周期的宏观背景板，加息腿 = 滞后版的重叠信息
  （实测 hike 触发 722 天中 714 天与 defense 同时触发，独有 8 天无贡献，见
  `data/analytics/industry_strategy/semi_ffr_defense_leg.md`）。
- **方向池 guarded_hike 有增量的机制解释**：16 行业方向池中部分行业（贵金属/医药等）剪刀差腿缺失
  （回退中性 50），加息腿在那里提供了防守门没有的信息；半导体/化工等有真实供给腿的行业已被内化。
  跨行业推广时，加息腿的价值取决于该行业供给腿是否真实存在。

### 8.5 门激活统计与两处「异常」的机制说明

- 全样本 2836 交易日 ON 1357（47.8%）/ OFF 1479。按年 ON 占比：2015 年 185/244
  （p50=89）→ 2016-2018 各约 100%（243-244/年）→ 2019 年 58/244（p50=1.68）→
  2022 年 184/242（p50=98.6）→ 2023 年 199/242（p50=78.7）→ 2024-2026 年 0。
- 最长连续 ON：2015-12-01~2019-03-29（812 天）、2022-04-01~2023-10-31（383 天）。
- **「异常」一：2015H1 门提前激活**（2015-01-05~05-29 ON 98 天、股灾段 ON 41/52）。
  零利率平台 diff(6)≈0 的微正漂移（有效 FFR 0.09→0.13）在 1250 日窗口（几乎全 0）内排高分位，
  属**滚动分位口径产物，不是「加息防守」逻辑**；股灾段 -7.47pp 减损应归因于此口径巧合，
  不能外推为门的稳定能力（2015H2 的 64 天 ON 段同理）。
- **「异常」二：门提前解除**（2019-03-29、2023-10-31，均为停加后 diff(6)→0 分位自然回落，
  滞后约 6 个月的加息检测器）→ 平台期/加息尾部门 OFF。实测代价：
  - 2019Q1 春季行情（门 ON 58 天）基线 +14.73% vs 门 +7.45%（**直接差 7.28pp**，
    中证全指同期 +32.01%）；叠加门 2018 年多赚形成的净值基数差（起点 1.2266 vs 1.2170），
    基数效应放大至范式四的 13.45pp —— **2019Q1 误伤是最大牺牲段主因**。
