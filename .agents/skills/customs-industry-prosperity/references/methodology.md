# 核心方法论与信号口径

> 本文件按需加载，内容提取自唯一权威 [`METHODOLOGY_FINAL.md`](../../../../docs/research/customs_export_forward/METHODOLOGY_FINAL.md)，
> 口径冲突时以 METHODOLOGY_FINAL.md 为准；实证数字出处见文末「关键实证锚点」。

## 核心方法论（一句话）

**研究商品量价拐点（量最领先、价确认、金额合成），量价驱动申万 L2/L3 行业景气度变化，
财报 TTM 只作后视验证。**

三大正确原则（强制）：① 数据无前视；② 量化无过拟合；③ 量价关系优先（量领先、价确认、
金额合成，三序列分开研究）。其余一律从简。

**排除（不实现，避免旧思路干扰）**：`direction_score` / `global_resonance_l2_map`
方向分（fwd20 IC +0.99%，无横截面预测力）、price 腿合成总分（fwd60 IC −0.09）、
方向防守门（8.34% vs baseline 12.50%）、单腿资金吸筹（2020 后超额 −1.2%，突破越高越差：60日高 −1.2% → 250日高 −3.4%）。

## 信号定义（METHODOLOGY_FINAL §2 唯一口径）

```
金额 yoy = v3mma / v3mma_lag12 − 1
量   yoy = q3mma / q3mma_lag12 − 1     # 仅 volume_aggregable=True 产品参与
价   yoy = asp3mma / asp3mma_lag12 − 1  # asp3mma = v3mma / q3mma
```

无前视要点：按 hs8 码补全完整月序后统一重算（缺月置 null 不填 0）；跨源
（Comtrade 2024 → GACC 2025）不做分源分段计算，避免 2025 全年同比缺失；
数量跨 HS 混用单位的产品置空，不得参与行业聚合。

### 驱动类型四象限（当前状态分类）

| 驱动类型 | 量 yoy | 价 yoy | 含义 |
| :--- | :--- | :--- | :--- |
| 量价齐升 | >0 | >0 | 量价双扩，最健康 |
| 量驱动 | >0 | ≤0 | 放量降价（需求启动/价格战） |
| 价驱动 | ≤0 | >0 | 量歇价升（顶部前兆/供给收缩涨价） |
| 双弱 | ≤0 | ≤0 | 量价齐跌（衰退/出清） |

### 拐点与二阶导（研究重心）

- **拐点（一阶导符号翻转）**：金额 3MMA yoy 由负转正 = 景气启动；由正转负 = 见顶/退出。
- **二阶导 = 量增速方向**（择时看二阶导、确认看一阶导）：

| 结构 | 判定 | 处置 |
| :--- | :--- | :--- |
| 底部 | 量先转正、价跌幅收窄 | 前瞻候选池 |
| 主升 | 量价齐升持续（一阶导水平） | 持有，二阶导定节奏 |
| 顶部前兆 | 量增速见顶回落 / 量转负 | 减仓观察 |
| 最危险组合 | 量回落 × 财报仍加速 | 历史 6m 中位 −7.9%、>0 仅 38%，离场触发 |
| 衰退 | 金额转负 + 量价双弱 | 回避 |

### 方向一致率分级（出口→财报方向可预测性，02 文档口径）

| 分级 | 一致率 | 行业数 | 用途 |
| :--- | :--- | :--- | :--- |
| A 可靠前瞻 | ≥0.85 | 6（电网设备/炼化/光伏/焦炭/电池/半导体） | 出口读数可直接推断财报方向 |
| B 可用参考 | 0.62-0.77 | 22 | 出口有参考价值，需结合其他信号 |
| C 弱/无效 | ≤0.58 | 12（通信/消费电子/家居/特钢/风电等） | 映射代表性不足，出口不作前瞻判断 |

> 2026-09 审计勘误：行业数由旧口径"B 19 / C 15"更正为 **B 22 / C 12**（共 40 行业）；
> 厨卫电器（0.38，C 级）在 catalog 无产品映射，观察表不出现该行。

## 财报后视验证规则（§4）

```
量价齐升型（需求驱动）: 营收 TTM 转正 AND 净利 TTM 转正 → 适用出口框架，三腿验证合格
毛利率扩张型（成本/价差驱动）: 营收未转正 + 净利转正 + 毛利率抬升 → 不适用出口框架
```

- **价格主导行业（21 个，金额yoy×量yoy corr<0.5）**：金额上涨可能纯由价格驱动，不构成需求拐点；
- **国内供需定价行业（光伏/电池/乘用车）**：出口只有"量"的语义，出口回升 ≠ 盈利回升，兑现另看产能利用率与价格企稳；
- **机制校验优先于统计**：炼化一致率 1.0 是油价周期伪相关，正确信号是裂解价差，不是海关出口。

## 量化纪律（§5.1 + §6 强制）

**无过拟合 6 条**：① 新信号必须 2022-01 后样本外验证；② 有效性 = 超越基线
（16 行业方向池裸动量全周期 +5.42%、样本外 Sharpe 0.18）的增量；③ 单次循环不宣称规律
（光伏产能周期标注"待 2026+ 二轮循环二次确认"）；④ 事件收益对照同期市场行业中位（超额口径），
小样本标注置信区间；⑤ 最小参数（阈值来自机制/官方口径，不从历史反推）；⑥ 跨年度结论列分年度表现。

**无前视铁律 5 条**：① 腿1 拐点有效窗口 [T+1, T+3]（GACC 月度 T+20 发布）；② 腿2 当日收盘判定，
收益自次日起算（T+1 执行）；③ 腿3 财报只可见已披露报告期（`eff_date`/`reportDate` 前向填充 join_asof）；
④ 假拐点过滤：信号月 yoy ≥ 0（拐点后再次转负的行业剔除）；⑤ 拐点判定只用历史
（3MMA yoy 由负转正 prev<0 且 ≥0，不依赖未来值）。

## 层级分工（§3）

| 粒度 | 分工 | 实证依据 |
| :--- | :--- | :--- |
| **L2（申万二级）** | 行业景气主判 + 三腿 AND 入场前置 | 27 事件超额 120 日 +4.33% / 胜率 66.7% |
| **L3（申万三级）** | 出口景气/量价分化观察（如半导体：封测价驱动 vs 设备量价齐升） | L3 三腿超额 −1.80%（负），不作入场信号 |

三腿 AND（仅 L2 有效）：腿1 出口拐点（±3 月窗口，锚） × 腿2 资金吸筹+突破60日高（时机） ×
腿3 财报量价齐升（验证）。单腿/两腿在 2020 后均无效或为负。

## 月度报告格式（12 样例结构）

报告 `12_forward_watch_<yyyy_mm>.md` 必含要素（样例 `12_forward_watch_2026_07.md`）：

1. **头部**：分析基准日（出口月 + 发布说明）、数据底座版本说明（税则对齐/修复说明）、财报对照期；
2. **一句话结论**；
3. **全景分层**（出口 yoy 3MMA × 财报 TTM 营收 yoy 四象限）：双正共振 / 前瞻窗口
   （出口正×财报负）/ 出口负×财报正（拐点预警候选）/ 双弱；每行业列出口yoy/量yoy/价yoy/驱动/36m分位/财报yoy/一致率；
4. **四阶段定位**（36 月经验分位 + 量价驱动）：景气启动（分位 50-85 量价齐升）/ 狂热高潮
   （分位 ≥85）/ 扩张放缓（金额仍正、分位大幅回落、量转弱）/ 需求萎缩（金额负、分位低）；
   **注意分位高 ≠ 未来好**，需配合量价驱动结构与二阶导判断；
5. **重点行业前瞻解读**（每个重点行业：量价结构 + 二阶导 + 一致率 + 财报对照 + 处置）；
6. **拐点预警决策卡**（最危险组合 / 扩张放缓 / 金额高增×量停滞 / 出口转弱×财报未破位 / 双弱）；
7. **限制与边界**（C 级行业出口仅供参考、单码行业量价失真、价 yoy 极端值、纯本地数据无联网核验、
   出口前瞻的是营收方向不是盈利/股价）；
8. **复现**（4 个 build 脚本命令）。
