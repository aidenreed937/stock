# 聚丙烯 (Polypropylene, PP) 产业周期投研体系

## 1. 产业定位与经济学特征
- **基础定位**：聚丙烯是五大通用塑料中产量最大、应用最广的品种之一（编织袋、包装膜、注塑汽配、家电外壳、BOPP），全国有效年产能超 3800 万吨；
- **工艺三元格局**：
  1. 油制石脑油裂解（占比约 55%）：紧跟国际原油与炼厂综合裂解毛利；
  2. 煤制烯烃 CTO（占比约 25%）：国内特有低成本 Alpha，以宝丰能源为代表；
  3. 丙烷脱氢 PDH（占比约 20%）：轻烃路线，以东华能源为代表，构成行业边际高成本出清线；
- **衍生品市场**：大连商品交易所上市主力期货品种 `PP`，流动性极高。

## 2. 成本阶梯与边际出清
- **出清锚点**：当国际丙烷高位震荡且 PP 现货跌破 7500~8100 元/吨时，PDH 与高成本外采丙烯企业全面失血降负，成为周期见底反转信号。
