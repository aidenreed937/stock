## 核心投研逻辑与因果链闭环

1. **多工艺供给曲线阶梯 (Merit Order)**：
   - **油制路线 (Oil-based MEG, ~62%)**：依托 2000~4000 万吨大炼化一体化乙烯装置，现金成本约 4300 元/吨，完全成本约 4900 元/吨，具备极高规模壁垒与抗亏阿尔法；
   - **煤制路线 (Coal-based MEG, ~38%)**：以煤炭气化制合成气、草酸二甲酯 (DMO) 加氢为代表，现金保本底线约 4700 元/吨，完全成本约 5400 元/吨。当现货价格跌破 4700 元/吨时，全行业高成本煤制装置普遍陷入负现金流失血，触发左侧出清大底（`deep_cash_drain_bottom`）。
2. **显性库存锚点**：
   - 乙二醇由于进口依存度（历史约 30%~40%，当前逐步进口替代至约 19%），**华东主港（张家港、太仓、宁波等）商业库存**是现货价格与期现基差的最敏感领先风向标；库存持续去化至 70 万吨以下通常伴随反弹，累库超过 110~120 万吨则施压下行。
3. **下游需求承接**：
   - 90% 以上需求流向聚酯涤纶（长丝、短纤、瓶片），与 PTA 按照 $1 : 0.335$ 的物质摩尔守恒比例共同合成 PET。
