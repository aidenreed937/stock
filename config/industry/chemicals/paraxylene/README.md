# 对二甲苯 (Paraxylene, PX) 产业周期投研体系

## 1. 产业定位与经济学特征
- **基础定位**：对二甲苯是大炼化芳烃产业链的核心咽喉节点，下游 99% 用于生产精对苯二甲酸 (PTA) 并进一步纺丝为涤纶长丝，全国有效年产能超 4200 万吨；
- **行业格局**：由民营大炼化四小龙（荣盛石化、恒力石化、东方盛虹、恒逸石化）及中石化、中石油主导，呈现高度集中与装置大型化特征；
- **核心价差锚**：国际通用的 **PX-石脑油裂解价差 (PX Crack Spread)**，通常以 300~350 美元/吨为全行业完全成本分水岭，250~280 美元/吨为边际现金保本底线。

## 2. 成本与供需平衡
- **上游传导**：原油 $\to$ 石脑油 $\to$ 重整抽提 $\to$ PX；
- **下游传导**：$0.655\,\text{吨 PX} \to 1\,\text{吨 PTA}$；PX 利润与 PTA 利润经常呈现“跷跷板”博弈（芳烃紧平衡时利润留在 PX，PTA 端被压缩加工费至 300 元/吨失血线）。
