# 三代氟制冷剂 (Refrigerant, HFCs) 产业投研与量化配置目录

本目录集中归档和维护三代氟制冷剂产业链相关的核心配置文件，涵盖上市公司画像及法定配额映射。

---

## 目录文件一览

| 配置文件名 | 职责定位 | 核心覆盖维度 | 消费方与关联代码 |
| :--- | :--- | :--- | :--- |
| **`companies.yaml`** | 核心上市公司画像配置库 | 巨化股份、三美股份等三代制冷剂法定配额头部标的的配额规模、外销占比与业绩弹性 | `src/stock_analytics/marts/chemical_elasticity_mart.py` |
| **`trading_gates.yaml`** | 周期股分阶段量化交易门禁 | 三代制冷剂专用 C 类行政配额管制型门禁（配额锁定、下游空调排产旺季、外销单价暴涨）与标的映射 | 周期策略回测与实时报单引擎 |

---

## 规范与维护准则

1. **行政法定配额管制型特征 (C 类品种)**：
   - 生态环境部冻结基准年配额，严禁新增 Capex 扩产，切断高利润诱发盲目扩产的周期负反馈。
2. **单一信任源 (Single Source of Truth)**：
   - 法定配额规模折算的有效产能、权益比例与自销参数以本目录为准。
