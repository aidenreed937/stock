# 聚氨酯 (Polyurethane, MDI/TDI) 产业投研与量化配置目录

本目录集中归档和维护聚氨酯产业链相关的核心配置文件，涵盖上市公司画像及工艺成本映射。

---

## 目录文件一览

| 配置文件名 | 职责定位 | 核心覆盖维度 | 消费方与关联代码 |
| :--- | :--- | :--- | :--- |
| **`companies.yaml`** | 核心上市公司画像配置库 | 万华化学等聚氨酯龙头的光气化工艺路线、MDI/TDI 产能阶梯、成本曲线定位与业绩弹性 | `src/stock_analytics/marts/chemical_elasticity_mart.py` |
| **`trading_gates.yaml`** | 周期股分阶段量化交易门禁 | 聚氨酯专用 B 类周期性中游寡头门禁（挂牌价止跌/提价、协同检修、海外气头边际失血）与万华化学标的映射 | 周期策略回测与实时报单引擎 |

---

## 规范与维护准则

1. **寡头协同与挂牌价定价机制**：
   - 聚氨酯行业属于典型周期性中游寡头品种 (CR5 > 75%)，以万华化学、巴斯夫、科思创等龙头的月度挂牌价和装置协同检修为关键驱动。
2. **单一信任源 (Single Source of Truth)**：
   - 装置物理产能、权益比例与自用扣减比例以本目录为准。
