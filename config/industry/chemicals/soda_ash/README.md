# 纯碱 (Soda Ash / SA) 产业投研与量化配置标杆规范

本目录集中归档和维护纯碱产业链的四支柱核心规范配置文件，涵盖物理装置重大产能日历、上市公司画像与 Point-in-Time 产能时间轴、多工艺理论物料衡算模型及周期股分阶段量化交易门禁。

作为 A 类大宗标准化与期货品种（完全竞争、多工艺成本阶梯出清、库存双轨蓄水池与交割仓单支配），本目录与下游管线 `stock_analytics.pipelines.soda_ash` 共同构成本仓库**大宗化工品垂直深度研究（Vertical Deep-Dive）的标准范式标杆**。

## 二、 产业链全景与物理化学传导机制

### 1. 物理工艺流程与三大路线经济学比较

```text
【天然碱法 (Natural Alkali)】: 最低成本阿尔法颠覆者
  天然碱矿卤水 ──(机械采矿/卤水开采)──→ 蒸发结晶 ──(动力煤驱动)──→ 纯碱 (Na2CO3)
  - 核心壁垒: 稀缺优质矿藏 (内蒙古阿拉善、河南桐柏)
  - 成本特征: 完全成本 700~800 元/吨，付现加工费 160~180 元/吨；无合成氨与原盐化学消耗

【侯氏联碱法 (Hou Process)】: 联合制碱副产化肥 (双吨综合模型)
  原盐 (NaCl) + 氨 (NH3) + CO2 + 水 ──→ 碳酸氢钠沉淀 (煅烧得纯碱) + 滤液
  母液加原盐并通氨降温结晶 ─────────→ 氯化铵 (NH4Cl，农用化肥)
  - 核心特征: 1.0 吨纯碱联产 1.0 吨氯化铵 (1:1 双吨产出)
  - 净成本折算: 纯碱单吨完全成本 = 双吨生产总成本 - 1.0 × 氯化铵销售市价 (Byproduct Credit)
  - 成本特征: 副产抵扣后完全成本约 950~1100 元/吨，处于行业中间成本档 (Middle Hou)

【索尔维氨碱法 (Solvay Process)】: 高能耗高排污边际出清线
  原盐 (NaCl) + 石灰石 (CaCO3) + 动力煤 + 焦炭/无烟块煤 ──→ 纯碱 + 废渣废液 (CaCl2)
  - 核心特征: 无法联产高价值副产，产生大量废液废渣，环保与能耗成本高企
  - 成本特征: 完全成本 1500~1650 元/吨，现金保本线 1350~1450 元/吨 (行业边际出清支撑底线)
```

### 2. 供给成本曲线阶梯 (Merit Order)

根据物料衡算与当前行业原料价格中枢（原盐 320 元/吨、合成氨 2600 元/吨、动力煤 850 元/吨、氯化铵 650 元/吨），全行业形成极其鲜明的三级成本阶梯：

$$\text{天然碱 (700\sim 800元)} < \text{联碱法 (950\sim 1100元)} < \text{氨碱法 (1500\sim 1650元)}$$

> 成本口径的唯一信任源为 `cost_models.yaml` 的工艺单耗 + `regime_thresholds`，
> 结合原料现货基准价动态求解；`companies.yaml` / `trading_gates.yaml` 的 `cost_notes`
> 仅作定性描述，数值必须与模型实算结果保持同口径。

- **出清底线定价法则**：当纯碱现货市价跌穿氨碱法的**现金保本成本线（1400 元/吨左右）**时，边际高成本装置（山东海化、沿海老氨碱厂）陷入严重付现失血，被迫安排停产检修或实质性冷修减产，触发全行业供给端出清大底。

## 三、 下游需求因果链与供需剪刀差机制

### 1. 终端消费结构分布
- **建筑与汽车平板玻璃 (浮法玻璃)**：占比约 **40%**，为纯碱第一大传统刚需。
- **光伏压延玻璃**：占比约 **12%~15%**，新能源装机驱动的高成长增量引擎（单 GW 光伏组件拉动约 0.9 万吨光伏玻璃，消耗约 1800 吨轻/重碱）。
- **碳酸锂、两钠、洗涤剂与日用玻璃**：合计占比约 **45%**，支撑基础内需与海外出口。

### 2. 需求传导特征与供需剪刀差
1. **下游窑炉连续生产的物理刚性**：
   - 浮法玻璃与光伏压延玻璃窑炉一旦点火，必须维持 **8~10 年** 连续运转，极难中途降负；
   - 窑炉停产冷修需耗费数百至上千万元资金，重开成本极其高昂。因此，在利润转负初期，玻璃厂仍会维持纯碱刚性采购，需求体现出强惯性与抗跌性；
2. **供需剪刀差公式**：
   $$\text{供需剪刀差 (Scissors Spread YoY)} = \text{下游平板玻璃产量增速 (YoY)} - \text{纯碱实物产量增速 (YoY)}$$
   - 剪刀差 > 0%：下游需求增速快于上游供给释放，行业进入主动/被动去库通道；
   - 剪刀差 < 0%：供给增速显著超前于下游消化能力，库存蓄水池承压累积。

## 五、 四大配置文件 Schema 规范与字段契约

### 1. `capacity_projects.yaml`（产能事件种子库）
- 必须遵循的枚举：
  - `technology`: `natural_alkali` \| `hou_process` \| `solvay_process`
  - `status`: `operating`（已正式投料达产）\| `under_construction`（在建/试车中）\| `shutdown`（停工/淘汰退出）
  - `confidence`: `A`（上市公司公告 / 政府主管部门正式文件）\| `B`（行业协会、环评公示或券商产业调研披露）
- 铁律一：未获得官方正式投料成功或达产公报的项目，`status` 必须维持 `under_construction`，`actual_start` 必须为 `null`，严禁预先标记为 `operating`。
- 铁律二：产能增量只采信 `actual_start`（既成事实）。在建项目的 `expected_start` 是计划而非事实，**不得**计入 `cum_cap_expansion_w_tons` 等累计有效产能口径，否则会把规划产能当作 Ground Truth 并引入前视。
- 退出/淘汰事件以负 `capacity_w_tons` 表示（如 `-130.0`），由聚合层做净额累加。

### 2. `companies.yaml`（上市公司画像与时间轴）
- 顶层维护当前最新静态快照（用于无需时间轴的快速横向截面扫描）；
- `timeline` 列表维护完整的 Point-in-Time 历史生效时间轴（`effective_date`、`annual_capacity_w_tons`、`equity_ratio`、`cost_tier`、`event`），供跨周期回测零前视提取；
- 铁律：`timeline` 各节点的 `effective_date` 与产能数值必须与 `capacity_projects.yaml` 的 `actual_start` 逐线对齐，且同一公司相邻节点的产能口径（是否含老基地/联营权益）必须保持一致，严禁跨口径跳变；
- 纯碱主营营收暴露度 `soda_revenue_share` 100% 由本地 `fina_mainbz` 表动态提取，禁止在 YAML 中硬编码财务常量。

### 3. `cost_models.yaml`（工艺理论物料衡算）
- 顶层必须声明各工艺最新的默认财务参数（`fixed_cost`、`cash_fixed_cost`、`freight_cost`），保证向下兼容与基础测试通过；
- `timeline` 切片支持不同历史发展阶段（如天然碱投产前、一期投产、一期达产、二期重塑）参数的动态继承与覆写；
- 联碱法必须在 `coefficients` 中显式声明 `byproduct_ammonium_chloride: 1.0`，使成本曲线求解器自动完成单吨纯碱的副产品收益抵扣。

### 4. `trading_gates.yaml`（量化交易门禁）
- 顶层扁平化维护三大门禁：
  - `left_side_odds`：左侧赔率建仓门禁（毛利进入亏损/微利 + PB 处于历史 15% 极低分位或绝对破净 <0.85）。估值条件按「个股或行业」口径取**全标的池最小值**判定，`preferred_target_role` 仅指定建仓首选标的；报告会额外对账该角色自身估值，避免出现「低 PB 标的触发、却建议买入高估值龙头」的口径矛盾；
  - `right_side_confirmation`：右侧胜率确认门禁（周开工跌破 78% 警戒线 + 连续去库期数达标 + 基差转正 + MA20 突破 + 供需剪刀差或海关出口共振）。全景表为月频，`destocking_weeks_min` 按期（月）计数并强制校验，接入周度序列后可平滑切换为周频口径；
  - `top_escape`：逃顶门禁，**多因子投票制**（`trigger_match_count_min` 命中即清仓、`warning_match_count_min` 命中仅预警），并非单条件一票否决；命中条件为开工率 >88% 高位钝化 + 超额暴利 + 被动累库 + 静态低 PE 陷阱 <=8x + 高估值与内外需背离。
- 门禁评估结果的每一条条件对账（是/否 + 实际取值）必须由评估层输出并由报告直接渲染，禁止在渲染层硬编码。

## 六、 大宗化工品垂直深度研究可复制标准 SOP

当需要将本套研究范式拓展复制至其他大宗化工品（如 PVC、甲醇、乙二醇、PTA、钛白粉）时，遵循以下 4 步标准化作业流程：

1. **第一步：建立品种专用配置目录 (`config/industry/chemicals/{product}/`)**
   - 仿照纯碱建立 4 大规范 YAML 文件：梳理其工艺物料衡算单耗与副产抵扣关系、核心标的 PIT 产能时间轴、重大在建工程与三门禁画像映射；
2. **第二步：接入中观高频事实表**
   - 对齐现货出厂基准（`chemical_spot_price` 100ppi）、交易所期货连续与交割仓单（`futures_daily` / `futures_inventory`）、行业周度开工率与企业厂库（`chemical_weekly_survey`）；
3. **第三步：装配中游蓄水池状态机与供需剪刀差**
   - 选取该品种下游核心刚需大宗品（如纯碱-玻璃、PTA-化纤长丝、PVC-管材型材地产、钛白粉-涂料），计算供需剪刀差与出货率；
4. **第四步：跑通数据驱动研报与 Manifest 归档**
   - 调用 `ArtifactStore` 生成 `runs/as_of=...` 与 `latest/` 产物，确保报告 100% 数据驱动，机制解读严格标注为推断；
   - 报告基准月取「最近一个核心产量非空的月份」：NBS 存在「月份已建行、值待发布」的尾行（如 2026-08 仅有仓单与厂库），该行不得作为报告基准月，避免核心诊断与门禁评估落在空值行上。
