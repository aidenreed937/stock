# 烧碱 (Caustic Soda / SH) 与 ECU 联产配置规范

本目录维护烧碱（郑商所期货合约 `SH`）与氯碱电化学单元（ECU）综合平衡的品种级唯一信任源配置。

## 文件组成
- `cost_models.yaml`: 离子膜电解法（折百 100% NaOH，现金保本 1700 / 完全成本 2100）与 ECU 联产综合理论利润模型（1.0 NaOH + 0.886 Cl2）；
- `companies.yaml`: 中盐化工、三友化工、氯碱化工、新疆天业、中泰化学等氯碱龙头的自备电、产能与主营暴露度；
- `trading_gates.yaml`: 折百出厂价门禁与基差条件。
