## 核心投研逻辑与因果链闭环

1. **电石法边际成本出清底线**：
   - 我国 PVC 约 78% 为电石法工艺，高能耗与高耗电特性决定了其边际完全成本（约 5800 元/吨）与现金保本底线（约 5100 元/吨）；
   - 当现货价格深度跌破 5100 元/吨时（如当前 4710 元/吨），全行业电石法装置大面积陷入负现金流失血，触发左侧出清见底信号（`deep_cash_drain_bottom`）。
2. **两碱平衡与氯气蓄水池**：
   - PVC 是氯碱工业中“消纳副产氯气”的最核心大宗品种（1 吨 PVC 消耗约 0.57 吨氯气）；
   - 烧碱的高暴利往往会导致副产氯气过剩，促使氯碱企业即便在 PVC 亏损的情况下仍维持一定负荷，因此必须结合“氯碱综合毛利 (ECU)”研判。
3. **下游地产与外需泄洪双轨**：
   - 国内需求约 60% 集中于建筑地产链（管材、管件、型材、门窗、地板等）；
   - 在国内地产调整期，**海关出口（主要面向印度及东南亚基建需求）**成为行业消化过剩产能、缓解库存压力的核心泄洪通道。
