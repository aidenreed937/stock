# 苯乙烯 (Styrene, EB) 产业周期投研体系

## 1. 产业定位与经济学特征
- **基础定位**：苯乙烯是大宗芳烃与烯烃向下游合成树脂（PS、EPS、ABS、SBR）延伸的核心桥梁，全国有效年产能超 2000 万吨；
- **工艺格局**：乙苯脱氢法为主流（占比约 85%），PO/SM 联产共氧化法为先进低成本补充（占比约 15%）；
- **衍生品市场**：大连商品交易所上市主力期货品种 `EB`，期现联动极其紧密。

## 2. 成本与供需传导
- **原料单耗**：$1\,\text{吨 EB} \approx 0.79\,\text{吨纯苯} + 0.29\,\text{吨乙烯} + 900\,\text{元加工费}$；
- **边际出清机制**：当纯苯与乙烯原料高企且苯乙烯现货跌破 8100 元/吨（乙苯脱氢现金保本线）时，中小民营脱氢装置陷入深度亏损冷修，形成左侧拐点。
