## 产业链全景与量化传导机制

### 1. 物理工艺流程图谱

```text
原油 (Crude Oil)
  ↓
石脑油 (Naphtha)
  ↓
PX (对二甲苯)
  ↓
PTA (精对苯二甲酸) ──┐ (单耗 0.855 吨)
                     ├──→ PET (聚酯切片/熔体)
MEG (乙二醇) ────────┘ (单耗 0.335 吨)
  ↑                        │
乙烯 / 煤制气              ├─→ 涤纶长丝 (POY / FDY / DTY) ──→ 织机纺织服装 (化纤占比 >70%)
                           ├─→ 涤纶短纤 (PSF) ────────────→ 针刺水刺/无纺布
                           ├─→ 聚酯瓶片 (Bottle Chip) ────→ 软饮料包装
                           └─→ 聚酯薄膜 (BOPET) ──────────→ 光伏背板/电子包装
```

**核心链路**：`原油 → PX → PTA + MEG → 聚酯 (PET) → 涤纶长丝/短纤 → 终端纺织服装`。

---

### 2. PTA 在产业链中的核心定位与利润传导本质

PTA 本身**不是化纤**，而是生产聚酯（PET）最为核心的**上游大宗原料**（单吨 PET 消耗约 0.855 吨 PTA 与 0.335 吨 MEG）。

#### ① PTA 涨价 ≠ 化纤企业一定赚钱
企业真实经营利润取决于**产品售价与原料成本的剪刀差（加工差）**，而非原料的单边绝对点位：
- **PTA 生产企业利润**：$\text{PTA 现货价} - 0.655 \times \text{PX 现货价} - \text{PTA 综合加工成本}$
- **聚酯长丝企业利润**：$\text{涤纶产品售价} - (0.855 \times \text{PTA 成本} + 0.335 \times \text{MEG 成本}) - \text{聚酯加工费}$

**因果传导场景**：
- **成本推升但需求疲软（两头受挤）**：若上游原油/PX 推升 PTA 暴涨，但终端织造需求不振导致涤纶长丝无法顺利提价，聚酯化纤企业利润空间反而被上游大幅压缩失血；
- **终端需求爆发（顺利顺价）**：若终端纺织出口旺盛、长丝涨幅超过 PTA 原料涨幅，聚酯企业加工差与 ROE 迎来双击扩张。

### 3. 统计口径辨析：“化学纤维” 与 “PTA-聚酯产业链”

在量化投研与官方统计数据对账时，必须严格区分口径边界：
1. **国家统计局（NBS）“化学纤维产量”**：
   - 包含**涤纶（聚酯纤维）**、**锦纶（尼龙，PA6/PA66）**、**粘胶纤维（人造棉）**、**氨纶（聚氨酯）**、**腈纶**等所有化学纤维品种；
   - **核心对应度**：在我国化纤产业结构中，**涤纶（聚酯化纤）占全部化纤总产量的 80% 以上**。因此，宏观化纤产量增速与聚酯涤纶趋势在方向与一阶导上高度共振；
2. **PTA 的直接对应度**：
   - PTA 终端消费的 **90% 以上流向聚酯（PET）**，聚酯中又有近 80% 用于生产涤纶长丝与短纤；
   - 因此，**PTA 供求是聚酯化纤产业链（涤纶）的专用晴雨表**，而非锦纶（己内酰胺链）、粘胶（木浆链）或氨纶（PTMEG-MDI 链）的原料。

## 规范与维护准则

1. **Point-in-Time 原则**：
   - 财务指标与估值指标由本地 Curated 黄金事实表动态自适应装配；
   - 本目录配置文件仅维护装置物理产能、技术路线与产业画像，避免硬编码时效性财务指标。
2. **单一信任源 (Single Source of Truth)**：
   - 本目录下维护 `capacity_projects.yaml`、`companies.yaml`、`cost_models.yaml`、`trading_gates.yaml` 与 `company_projections.yaml` 五大高内聚规范文件；
   - 杜绝引入冗余重复文件或软链接，新增标的或产能变动必须严格核验官方公报与上市公司年报后幂等入库。

## 二阶导数三大量化交易判据 (纯逻辑规则)

大宗周期投研中，零阶绝对量（现货价格/报表利润）严重滞后 3~6 个月，一阶导数（同比增速）反映趋势方向，**二阶导数（速度的加速度与边际斜率）则是领先拐点 1~2 个月的前瞻刹车灯与方向盘**。

```text
【判据 1：左侧减速见底买入信号 (冲底减速)】
触发条件：
  1. 供需剪刀差 < 0 (当前供求关系依然过剩，市场情绪极度悲观)
  2. 剪刀差加速度 ΔScissors > 0 (二阶导向上翘头，过剩恶化速度停滞收窄)
  3. 贴水修复加速度 ΔBasis > 0 (现货贴水快速收敛，抛压被产业资金暗中承接)
  4. 龙头估值 PB ≤ 历史 P10 分位 (股价跌入重置成本防御线，恒力 ≤ 1.05x, 桐昆 ≤ 0.85x)
执行动作：
  --> 触发左侧建仓门禁，建立 30% 底仓 (首选抗亏 Alpha 标的恒力石化)

----------------------------------------------------------------------

【判据 2：右侧加速主升重仓信号 (趋势爆发)】
触发条件：
  1. 供需剪刀差 > 0 且 剪刀差加速度 ΔScissors > 0 (一阶导与二阶导同向加速上行)
  2. 现货基差 Basis > 0 (现货转为升水 Back 结构，实体产业链真实缺货抢购)
  3. 仓单月变动 ΔWarehouse_Receipt < 0 (郑商所交割库仓单被动注销提货，真实去库)
执行动作：
  --> 触发右侧胜率门禁，仓位加码至 60%~80% (切换至高弹性 Beta 标的桐昆股份)

----------------------------------------------------------------------

【判据 3：顶部失速衰竭逃顶信号 (冲顶失速)】
触发条件：
  1. 单吨加工费 > 600 元/吨 (超额暴利高潮，静态 PE 降至个位数诱多)
  2. 剪刀差加速度 ΔScissors < 0 (二阶导由正转负断崖跳水，下游需求增速衰竭)
  3. 仓单累积加速度 Δ²Receipt > 0 (交割库仓单加速堆积，现货甩卖至期货盘面)
执行动作：
  --> 触发一票否决门禁，坚决止盈清仓 (仓位降至 0%~20%，防范产能反噬与双杀)
```
