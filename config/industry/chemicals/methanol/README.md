## 核心投研逻辑与因果链闭环

1. **供给成本锚点与出清分位**：
   - 国内甲醇超 75% 依赖烟煤与无烟煤气化制取，**西北坑口原料煤价与运费**决定了行业边际完全成本（约 2250 元/吨）与现金保本底线（约 1850 元/吨）；
   - 当现货跌破 1850 元/吨时，西北外购煤装置大面积失血检修，供应端强制收缩。
2. **需求双轨驱动**：
   - **MTO (煤/甲醇制烯烃, 约占 50%~55% 需求)**：聚乙烯与聚丙烯价格决定了 MTO 工厂的最高甲醇原料承受力（平衡公式：$1 \text{吨烯烃} \approx 3 \text{吨甲醇}$）；
   - **传统下游 (约占 45%)**：甲醛（板材与地产链）、醋酸（纺织聚酯与胶粘剂）、二甲醚、DMF、农药医药中间体。
3. **关键显性库存**：
   - **华东沿海港口（太仓、江阴、常州、南通、宁波）商业库存**是全国甲醇供需平衡最敏感的“蓄水池”；
   - 港口库存跌破 70 万吨进入高弹性紧平衡；累库超过 100~110 万吨则现货深水贴水施压。
