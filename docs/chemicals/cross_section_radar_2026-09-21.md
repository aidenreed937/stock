## 二、截面核心矛盾与轮动建议

截面呈典型的**两极哑铃结构**：左侧击穿赔率区（纯碱/PVC）与右侧高景气/高位钝化区并存，中端寡头防御区温和。

### 1. 左侧极值赔率大底组合（OVERWEIGHT_LEFT）— 逢低布局抗亏龙头

- **纯碱（SA，95 分，置信度 100%）**：市价 1077 元/吨，仅覆盖边际现金成本 41.1%，深度击穿现金保本线，倒逼冷修减产，左侧极值赔率属性最强；同时期现呈现货升水（基差 +6.6%）、交易所仓单加速注销、微观结构强共振看多，是**左侧组合中右侧确认信号最完整**的品种。首选抗亏龙头远兴能源，业绩弹性看山东海化（100 元/吨跳变 EPS +0.208 元）。
- **PVC（V，95 分，置信度 85%）**：市价 4710 元/吨，现金覆盖率仅 19.3%，是全截面击穿最深的品种；出口量价齐升提供外需缓冲。但期货深度贴水（基差 -1.6%）、交易所仓单天量压顶（分位 95.2% 且仍在加速累单），右侧反转需等待显性库存消化；叠加"氯碱 ECU 平衡"（烧碱端高毛利反哺），出清节奏被延缓。配置上以左侧分批为主，右侧确认（仓单去化 + 基差修复）后再加码。首选中泰化学，弹性看新疆天业。

### 2. 右侧高景气与配额溢价组合（OVERWEIGHT_RIGHT）— 右侧进攻/温和配置

- **制冷剂 R32（95 分，置信度 68%）**：法定配额冻结供给，市价 65,000 元/吨、单吨加工差 49,424 元处于超额利润区，外需价驱动（价格 +21.9% 但出口量 -40.0%）。评分最高但数据置信度折价（无周度开工/库存/期现腿），属于"强逻辑、缺高频确证"的右侧高景气标的。首选巨化股份，弹性看三美股份。
- **钛白粉（TiO2，70 分，置信度 78%）**：寡头格局稳固、开工率 73.3% 正常运转，海外出口稳定（量 +3.7%、价 +19.6%），处于右侧温和修复区；但缺周度企业库存腿，评分被压制在 70 分。逢低配置龙头龙佰集团。

### 3. 中性跟踪（NEUTRAL_WATCH）— 弱平衡与维度不完整，防乐观偏差

- **聚合MDI（65 分）**：寡头平稳、外需稳定，但缺周度开工与企业库存高频确证，暂中性跟踪；龙头万华化学。
- **尿素（50 分）**：供需弱平衡、吨毛利中枢窄幅震荡，无强方向信号；华鲁恒升/阳煤化工。
- **烧碱（50 分，置信度仅 53%）**：出口量驱动（量 +64.5%、价 -12.9%）但价弱；价差日期严重陈旧（2026-03-06）且缺周度开工库存；另有 ECU 平衡提示——PVC 深亏累库或引发胀气反噬烧碱负荷，谨慎中性。

### 4. 周期高位钝化与防守回避（UNDERWEIGHT_TRIM）— 逢高减配，警惕低 PE 陷阱

- **TA / MEG / MA / EB / PP / PX（均 38 分）**：全部处于高盈利/暴利区间（super_profit 或 high_profit），库存时钟进入主动补库，静态低 PE 陷阱与远期产能投放压制风险大，量化评分被统一压制在 38 分防守线。
- **特别注意**：MEG（出口量 +85.3%、价 +25.3% 出口景气）与 MA（出口量 +510.3% 出口景气）外需动量极强，但引擎对 A 类大宗高盈利品种**一票压制至 38 分**（`_evaluate_cross_section` 高位钝化分支），不因出口弹性上调——这是防过拟合纪律，而非数据矛盾；此类品种应在价格/价差回落确认后再评估右侧机会。
- 恒力石化（TA/MEG/EB 弹性前列）、宝丰能源（MA/PP）需防"高景气幻觉"，逢高止盈为主。

## 四、风险提示

1. **Ground Truth 边界**：本报告所有点位/评分来自本地 Mart；未联网核验 09-21 之后的检修、排产与现货成交，外部高频变化可能使部分结论滞后 1~5 天。
2. **左侧品种左侧风险**：纯碱/PVC 虽处击穿区，但左侧建仓可能面临更深的现金成本击穿与更长出清时间；PVC 需以仓单去化与基差修复作为右侧确认，而非单纯抄底。
3. **配额品种数据缺腿**：R32 高评分依赖配额逻辑，缺库存与开工确证；若后续配额政策或下游排产变化，价格波动可能剧烈。
4. **高位品种低 PE 陷阱**：TA/MEG/MA 等暴利区品种静态估值低但处周期顶部区域，减配纪律优先于报表利润。
5. **数据时效**：TA 企业库存（06-12）、V 开工率（08-07）、SH 价差（03-06）等陈旧字段已被打分引擎隔离或折价，但解读时不应将其当作当前事实引用。
