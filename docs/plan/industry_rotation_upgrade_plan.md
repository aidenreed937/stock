# 中观行业轮动一线化路线图 v2

> 定位：把中观行业轮动从 Sharpe 0.33 重做到券商一线水平（0.5+）的完整路线。
> v2 相比 v1 的核心升级：经过连续实证，**瓶颈从「因子工程」转向「数据口径（全球共振）
> + 相态择时 + 供需质量修正」**。
>
> 所有「已验证」结论均为本地可复现实证（脚本见 §7）；「待验证」为推断。
> 数据区间 2015-01 ~ 2026-08（2833 交易日，31 申万一级行业）。

---

## 0. 一句话结论

中观卡在 Sharpe 0.38 的根本原因，**不是因子权重没调好，而是用了「内需总量口径」的景气
去打分一个「全球化制造业市场」**。正确路径 = 补「全球共振」数据维度 + 供需质量修正
（只做量价齐升）+ 相态择时 + 拥挤度防守。

## 2. 正确因子骨架（五层，每层对应一条实证）

```
composite = 全球共振的供需景气（进攻）
          − 拥挤度（防守，样本外风险翻倍）
          × 相态择时（常态期降仓，极端期满仓）
```

| 层 | 正确做法 | 错误做法（现状） | 依据 |
| :--- | :--- | :--- | :--- |
| 进攻 | 现实景气：业绩预告/快报的**量价齐升** | 分析师预期（衰减）+ 供给收缩剪刀差（奖励假繁荣） | 判断 6/7/9 |
| 供需质量 | 需求驱动（营收增速 + 净利增速双正） | `ind_scissors = 净利增速 − 营收增速`（营收负时虚高） | 判断 9 |
| 需求来源 | 全球共振（海外收入占比高 × 全球产业景气向上） | 内需总量口径（天花板 0.38） | 判断 10 |
| 防守 | 拥挤度（tcr 高位一票否决/减仓） | 仅 meta_router 残缺路由 | 判断 8 |
| 择时 | 相态（panic/overheat 决定权益仓位） | 满仓硬扛常态期 | 判断 3 |

### 2.1 「全球共振」的三层判定（方向 × 供需 × 议价权）

「全球共振」不是一句笼统的话，而是三层可执行判定；**三层同时成立才是「真全球景气」**：

| 层 | 回答的问题 | 判定标准 | 数据来源 |
| :--- | :--- | :--- | :--- |
| 方向 | 资本开支是不是全球性的 | 对应全球景气代理向上（SOX/装机/出货） | §3.2 全球指标 |
| 供需 | 承接的是需求驱动还是产能过剩 | 量价齐升（营收 + 净利双正），非扩产过剩 | revenue/profit_growth_ttm |
| 议价权 | 这个制造环节有没有定价权 | 毛利率扩张 + 营收高增（微笑曲线偏上，非代工） | 毛利率/净利率趋势 |

**反例警示**：光伏承接了全球碳中和资本开支（方向✅），但产能大规模落地后过剩、
价格战（供需❌），且组件环节议价权弱（议价权❌）→ 三层只满足一层，故不是真 alpha。

## 3. 数据缺口（关键新发现，v2 相对 v1 的核心增量）

### 3.1 已确认的缺口

`global_macro_daily` 仅有宏观利率/汇率/商品（美债、美元、黄金、铜、VIX），**无全球产业
景气指标**；整个 tushare fetcher **无海外收入/出口字段**。现有景气因子全部是内需总量口径。

### 3.2 要补的数据（接口均在手上，无需新采购）

**全球共振产业的共同驱动**：全球性政策/公约（碳中和、AI 竞赛）+ 全球技术周期 +
全球资本开支周期 + 中国是全球供应链核心。景气是「全球需求通过中国供应链的外溢」，
识别它的正确信号是「全球资本开支/出货量」，而非 A 股内需营收。

**全球共振产业 → 全球景气代理 → 申万行业映射**：

| 产业 | 全球驱动 | 全球景气代理指标 | 申万行业 |
| :--- | :--- | :--- | :--- |
| AI 算力 | 大模型竞赛 + 云厂 capex | 费半 SOX、全球半导体销售额(SIA)、北美云厂 capex | 电子/通信/计算机 |
| 新能源 | 全球碳中和 | 全球光伏装机、新能源车销量、动力电池出货 | 电力设备/有色 |
| 机器人/AI+制造 | 具身智能 + 自动化 | 工业机器人出货、自动化渗透率、具身融资 | 机械/电子/计算机 |

**落地数据（以全球产业指标为主，海外收入占比为辅）**：
1. **全球产业景气指标**（方向层，核心）：费半 SOX（yfinance，已有）、全球 PMI（FRED，已有）、
   光伏装机/新能源车销量/半导体销售额/机器人出货（按上表逐产业接入）。
   全球指标本身即「全球需求」的直接度量，优先于间接的海外收入占比。
2. **海外收入占比**（可选辅助）：TuShare `fina_mainbz` 的 `type='D'`（按地区）分支，
   需 `fina_mainbz_vip`（5000 积分）批量，且披露覆盖率有限——只作为共振的辅助确认，
   不作为主信号。
3. **三层共振信号**：`对应全球指标向上（方向） × 量价齐升（供需） × 毛利率扩张（议价权）`
   全部成立才确认「真全球景气」。

## 4. 分阶段路线图

### P0（已完成，结论收敛）

- 频率扫描：升频有限，天花板 0.38；momentum 双周最优。
- 用满面板因子：IC 检验 + 复合回测，换因子突破不了 0.38，样本外只打平（0.34 vs 0.35），
  但拥挤度防守把回撤 42% → 26%。

### P1（进行中，部分完成）

已完成（均有脚本留档）：
1. **供需质量修正** ✅：`ind_scissors` → 量价齐升口径，全周期 0.16 → 0.36；
2. **趋势确认（环比改善）** ✅：季度调仓追「景气方向」而非「景气高低」，
   **样本外 Sharpe 0.22 → 0.39（里程碑，逼近 0.4）**。

已验证失败（结论固化）：
3. **拐点预警（A 股内部信号）** ❌：拥挤度滞后、环比噪声大，退出全劣于不退出。
   拐点预警的正确信号在「全球资本开支见顶」，不在 A 股内部。

剩余（核心增量）：
4. **全球共振数据接入**：SOX/装机/出货全球指标（§3.2），用「全球指标见顶」做拐点预警，
   替代 A 股内部信号。

   **产业趋势跟踪体系已落地**（skill + 管线 + 策略 + CLI，方向层接口已预留）：
   - Skill：`.agents/skills/industry-trend-tracking/`（三层共振框架 + 因子定义）；
   - 管线：`src/stock_analytics/pipelines/industry_trend/`（因子面板，三层因子 + 现实景气 + 拥挤度
     + `composite_trend_score` + `trend_momentum`，默认权重对齐 milestone）；
   - 策略：`src/stock_strategy/pool/industry_trend_tracking.py`（`IndustryTrendTrackingStrategy`，
     季度调仓追 `trend_momentum`，可选 `supply_demand_min`/`crowding_max` 过滤）；
   - CLI：`make industry-trend-factors` / `make industry-trend-strategy`。
   - 方向层 `direction_score` 由 `global_resonance_map.parquet` 提供，缺失时中性 50；
     数据补齐后激活 `weights.direction` 即可。

> 验收：接全球指标后，样本外（2022 后）Sharpe ≥ 0.45，且拐点预警能降回撤。

### P2（3-4 周）

4. 风格中性化（个股层回归残差再聚合，东方证券 IC 提升 50%+）；
5. 分散度：Top3 → Top5+，降低选错单一行业的冲击。

> 验收：完整五层框架，样本外 Sharpe ≥ 0.5，相对中证全指年化超额 8%+。

## 6. 风险

1. **全球共振数据可能仍然不够**：fina_mainbz 海外收入的覆盖率和历史深度需先审计；
   SOX/PMI 是宏观/指数级指标，映射到申万行业有损耗。
2. **景气因子周期性失效**（2022 抱团瓦解教训）：复合因子必须含拥挤度防守 + 相态择时，
   不能单赌景气。
3. **样本外验证是硬门槛**：每一层改进都用 2022 后样本外检验，不拿全样本刷参数
   （前面「分析师预期样本内 0.47、样本外 0.15」就是反例）。
4. **历史结论非未来保证**：一线 0.5+ 是卖方样本内口径，实盘打七折预期。
