# ADR 0002：第一阶段业务边界

## 状态

已接受

## 决策

第一阶段只交付可信日线数据、指标计算、配置驱动的 Double SMA + RSI 策略和可审计 SignalReport。

第一阶段不包含回测、撮合、订单、券商接入、实盘执行和绩效归因。回测作为第二阶段，必须在数据契约、复权口径和时间可见性明确后单独设计。

## 原因

在数据身份和质量门禁未稳定前实现回测，会把缓存污染、单位不一致和前视偏差固化到收益结论中。

## 阶段退出条件

- Ruff、Mypy、Pytest 通过。
- DatasetKey 缓存不会串用或覆盖不同请求。
- 缺少契约或质量失败的数据不能进入 Curated。
- 策略配置的指标、阈值和仓位上限都有实际调用方。
- 固定输入可生成一致的结构化信号报告。
