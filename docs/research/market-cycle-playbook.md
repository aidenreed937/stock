# 市场跨周期研究手册

## 第一性原理

市场长期受盈利和估值约束，短期受资金和情绪驱动，风险受拥挤度放大。任何市场判断先区分三层：

- 能不能参与：系统风险、综合温度、估值约束和资金确认。
- 参与什么方向：行业结构分、候选行业、拥挤风险和落后方向。
- 怎么控制风险：60日趋势确认、TCR拥挤度、资金是否持续改善。

## 标准流程

1. 生成或确认四类产物：
   - `data/analytics/market_temperature`
   - `data/analytics/industry_structure`
   - `data/analytics/investor_brief`
   - `data/analytics/quant_brief`
2. 跑一致性校验：

```bash
make report-consistency START=YYYY-MM-DD END=YYYY-MM-DD
```

3. 生成跨周期复盘：

```bash
make market-cycle-review START=YYYY-MM-DD END=YYYY-MM-DD
```

4. 按以下顺序解读：
   - 综合温度和风险等级；
   - 估值、资金、情绪、技术、基本面、宏观流动性；
   - 行业20日/60日扩散；
   - 候选行业、拥挤行业、落后行业；
   - `quant_brief` 的基础温度仓位、风险上限、有效仓位和结构领先但未入选方向；
   - TCR成交占比迁移。

## 关键判断规则

- 估值高温表示安全边际收缩，不代表盈利改善。
- 资金温度强但技术弱，说明交易活跃但趋势未确认。
- 技术温度强但资金弱，说明价格先行、资金确认不足。
- 20日上涨行业多而60日上涨行业少，只能称为短线修复。
- TCR高说明成交主战场，不等同于低风险配置方向。
- 基本面和宏观月频/季频数据是底座，不解释日内或20日内每一次波动。

## 普通投资者读法

普通投资者不应先问哪个行业会涨，而应先问：

1. 系统风险是否允许参与；
2. 行业方向是否低拥挤且有确认；
3. 仓位是否匹配风险等级。

当报告出现“中等偏高风险、估值高温、资金未确认”时，默认结论是可以小心参与，但不是全面进攻。
