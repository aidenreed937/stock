# A股量化研究与实盘交易框架 (A-Share Quant Research & Trading Framework)

本框架基于“**宏观β定价 → 中观行业轮动 → 微观量价与杠杆博弈**”的三层量化研究体系，依托本地落盘的 TuShare、理杏仁 (LiXinger)、yfinance 与 FRED 等高品质数据资产，构建从宏观赔率定调、中观拥挤度风控、到微观买卖点识别与实盘组合管理的完整闭环。

---

## 一、 核心定价维度与无量纲指标体系

为彻底消除 A 股 12 年间上市公司扩容（2,500 家 $\to$ 5,500+ 家）、流通市值膨胀与无风险利率大幅下行（4.0% $\to$ 1.7%）导致的“水涨船高”和“历史中枢漂移”，本框架全面采用**无量纲相对比率与横截面指标体系**：

### 1. 跨资产定价与宏观估值（系统性赔率锚）

*   **无量纲股债收益比 (Earnings Yield / Bond Yield Ratio, EY/BY)**：
    $$\text{EY/BY} = \frac{1 / \text{PE}_{\text{TTM}}}{\text{10Y 国债到期收益率}} = \frac{\text{股票盈利收益率}}{\text{无风险利率}}$$
    *   **核心逻辑**：衡量“承担股票波动风险所获得的潜在回报，是无风险买入国债的几倍”，消除低利率范式漂移。
    *   **牛熊标尺**：$\text{EY/BY} > 2.2\text{x} \sim 2.7\text{x}$ 为战略级大熊底（股票性价比极高）；$\text{EY/BY} < 0.8\text{x} \sim 1.15\text{x}$ 为大牛顶警戒（收益率倒挂或平水）。*(数据源: `lixinger/index_fundamental`, `lixinger/national_debt`)*
*   **证券化率 (巴菲特指标总市值 / GDP)**：
    $$\text{证券化率} = \frac{\text{A 股总市值}}{\text{滚动 4 季度 GDP TTM}} \times 100\%$$
    *   **A 股本土化标尺**：$< 56\% \sim 65\%$ 为历史大底黄金建仓带；$> 86\% \sim 102\%$ 为极端泡沫过热区。*(数据源: `tushare/daily_basic`, `tushare/cn_gdp`)*
*   **海外宏观与全球流动性潮汐**：
    *   美联储基准利率 (`FEDFUNDS`)、10 年期美债收益率 (`^TNX`)、美元指数 (`DX-Y.NYB`) 与恐慌指数 (`^VIX`)，用于监控外资 Risk-On / Risk-Off 情绪与中美利差压力。*(数据源: `fred`, `yfinance`)*

### 2. 中观行业景气度与拥挤度风控（寻找结构性主线）

*   **行业成交额拥挤度 (Trading Crowding Ratio, TCR)**：
    $$\text{TCR}_i = \frac{\text{申万一级行业 } i \text{ 的成交金额}}{\text{全市场 31 行业总成交额}} \times 100\%$$
    *   **风控铁律**：单行业成交占比 $> 20\% \sim 25\%$ 即进入**极端拥挤度警戒区**（如电子成交占比达 27% 时滞涨），极易引发高位放量分歧与资金高低切换。*(数据源: `tushare/sw_daily`)*
*   **行业基本面与估值残差**：
    *   申万 31 个一级行业的营收/净利润增速、分析师一致预期上修比例及行业中性化后的 PB-ROE 残差。*(数据源: `lixinger`, `tushare`)*
*   **资金高低切换雷达**：
    *   监控 120D 领跑行业与 20D 超跌行业的动量反转剪刀差，捕捉资金从高位高拥挤板块向低位超跌板块溢出的结构性轮动机会。

### 3. 市场微观结构、杠杆与筹码博弈（短期交易情绪与买卖点）

*   **两融杠杆渗透率 (Margin Penetration Ratio)**：
    $$\text{两融渗透率} = \frac{\text{全市场两融总余额}}{\text{全市场自由流通总市值}} \times 100\%$$
    *   **牛熊标尺**：$< 2.1\% \sim 2.2\%$ 为杠杆彻底出清底；$> 2.6\% \sim 4.35\%$ 为杠杆过载脆弱区。*(数据源: `tushare/margin`, `tushare/daily_basic`)*
*   **自由流通市值日均换手率**：
    *   $< 2.0\% \sim 2.3\%$ 为“地量见地价”（筹码锁定，大底前夜）；$> 5.0\% \sim 6.0\%$ 为“天量见天价”（主力加速派发，短线极度亢奋）。
*   **多周期市场宽度 (Market Breadth)**：
    *   全市场 5,500+ 只个股站上 MA20（短线进攻度）、MA60（中期生命线）与 MA120（半年线大趋势）的比例。
    *   **宽度底背离**：指数破位但 MA60 站上率从 $<10\%$ 冰点逆势回升；
    *   **宽度顶背离**：指数新高但 MA20 站上率腰斩跌破 $50\%$（少数权重掩护出货）。*(数据源: `tushare/stock_daily_bar`)*
*   **全市场破净率 (PB < 1.0 比例)**：
    *   $> 10\% \sim 15\%$ 为大面积资产清算折价底；$< 1\% \sim 2\%$ 为全线泡沫化。*(数据源: `tushare/daily_basic`)*

## 二、 双层量化风险监控雷达 (Dual-Layer Risk System)

为避免混淆宏观周期大势与中短期交易波动，本框架将风险信号严格划分为**双层架构**：

```
                       【量化风险信号的双层架构】

  ┌────────────────────────────────────────────────────────┐
  │ 1. 宏观周期级大顶 (Macro Bubble Peak)                   │
  │    • 触发条件：EY/BY < 1.15x (收益率倒挂) + 市值/GDP破百 │
  │    • 历史实证：2015-06-12 (5335点)、2018-01-24 (4389点) │
  │    • 应对：大级别战略清仓、大幅降低权益仓位、买入国债避险 │
  ├────────────────────────────────────────────────────────┤
  │ 2. 中短期微观过热顶 (Tactical Heat Peak)                │
  │    • 触发条件：换手率 > 5.5% ~ 9.0% + 单日两融狂买破天量 │
  │    • 历史实证：2024-10-08 (4256点)、2026-01-12 (4789点) │
  │    • 应对：战术性止盈高贝塔品种、禁止追高、防范技术性回踩│
  └────────────────────────────────────────────────────────┘
```

### 1. 宏观四象限状态机（Regime Switch）
结合无量纲股债收益比与货币/信用环境进行大级别仓位管理：
*   **大级别战略机会区（$\text{EY/BY} > 2.2\text{x}$ 且 两融渗透率 $< 2.3\%$）**：高胜率与高赔率大底，维持高仓位，克服恐惧分批建仓并坚定持有。
*   **常态合理轮动区（$1.5\text{x} \le \text{EY/BY} \le 2.0\text{x}$）**：依据行业景气度与动量因子进行结构性阿尔法选股。
*   **宏观泡沫逃顶区（$\text{EY/BY} < 1.15\text{x}$）**：资产收益率倒挂，强制执行全面减仓与宏观避险。

## 三、 从中观轮动到微观选股的落地路径

### 1. 行业轮动打分卡与动态权重
*   **景气度**：ROE 边际改善（低频财报）＋ 分析师预期上修（高频）。
*   **估值性价比**：滚动 PB 分位及行业中性化后的 PB-ROE 残差。
*   **拥挤度惩罚机制**：当行业成交占比 $\text{TCR} > 20\%$ 时，线性下调该行业综合得分，限制组合在该行业的风险暴露上限。

### 2. 多因子选股与组合构建 (Alpha Engine)
*   **因子工程**：对质量因子（ROE 稳定性、现金流/净利润）、成长因子（扣非净利润同比）与量价因子（20D 波动率、动量反转）进行去极值、标准化、行业与市值中性化。
*   **单因子验证**：严格计算 IC 均值、ICIR、多空收益、换手率与衰减周期。
*   **组合优化与风控约束**：施加行业暴露偏离上限（$\pm 3\%$）、个股权重上限（$\le 5\%$）及组合目标波动率约束。

## 四、 实盘交易、执行与风控闭环

1.  **交易与成本模型**：完整模拟 A 股 T+1、涨跌停板、停牌限制，将印花税、过户费、佣金及滑点/冲击成本计入回测。
2.  **组合再平衡管理**：设定固定周期与阈值触发调仓机制，处理分红再投资、现金管理与流动性不足时的撮合损耗。
3.  **风控与熔断系统**：单票流动性约束（不超过日均成交额 10%）、行业集中度硬顶、个股技术与基本面双重止损。
4.  **绩效归因系统**：基于 Brinson 模型与多因子风险模型，拆解超额收益来源（宏观择时、行业配置、纯个股 Alpha）。

## 五、 数据工程与投研第一纪律 (Ground Truth First)

1.  **本地真实数据第一（零臆造）**：
    * 所有市场点位、PE 估值、股债收益比、两融规模等具体量化指标，**必须通过代码查询本地 Curated 黄金表输出，严禁凭模型记忆虚构**。
2.  **三层信息分级透明化**：
    * **Tier 1 (已验证事实)**：代码计算得出的量化结果，附带表路径、计算公式与样本区间；
    * **Tier 2 (机制推断)**：基于金融工程与微观结构的因果机制，阐明逻辑链条与局限；
    * **Tier 3 (外部背景)**：历史节点选择或宏观背景，明确声明为外部参考背景。
3.  **严禁无源叙事污染 (No Ungrounded Narrative Pollution)**：
    * 本地库无政策新闻或会议通稿表，**严禁将外部记忆中的“政策刺激/救市会议”伪装为数据事实写入结论或表格**。
4.  **严格区分 PIT (Point-in-Time)**：
    * 将业绩预告、业绩快报与正式财报分离，回测时依据真实披露公告日 (`ann_date`) 生效；严禁前向填充（FFill）产生前瞻偏差（Look-ahead bias）。
5.  **复权基准分离**：
    * 回测与因子计算统一使用后复权（保证收益率连续）；实盘下单时必须映射回不复权真实价格。
