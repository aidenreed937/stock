# A股量化研究与实盘交易框架

本框架基于“宏观β → 中观行业 → 微观个股”的三层研究体系，结合 TuShare、理杏仁、yfinance 和 FRED 等数据源，旨在构建从数据监控到实盘信号生成、组合管理的完整闭环。

## 一、 核心定价维度与数据映射

### 1. 宏观环境与流动性（系统性β驱动）
*   **海外宏观共振**：美联储基准利率、10年期美债收益率及利差、美元兑人民币（USDCNH）、VIX及美股核心科技指数。 (来源: `fred`, `yfinance`)
*   **国内信用与流动性**：社融存量增速、M1/M2 剪刀差、信贷脉冲、央行政策利率（LPR/MLF）、十年期国债收益率、DR007/R007。
*   **高频中观监控**：票据利率、南华工业品指数、同业存单利率。弥补宏观月度数据的滞后性。
*   **政策与事件日历**：降准降息、LPR操作、重要会议、监管表态。

### 2. 整体估值与风险溢价（系统性赔率）
*   **宽基指数估值**：沪深300、中证500、中证2000等 PE/PB 绝对值与历史分位数。 (来源: `lixinger`, `tushare`)
*   **股权风险溢价 (ERP)**：宽基指数盈利收益率 (1/PE) - 10年期国债无风险收益率。用于判断底部的绝对性价比。
*   **估值漂移修正**：采用滚动窗口（如3-5年）计算 Z-Score，结合股息率-国债收益率，避免单一历史分位数的中枢漂移导致失效。

### 3. 中观行业景气度与轮动（寻找结构性主线）
*   **行业基本面**：申万31个一级行业的营收增速、净利润增速及 ROE 变化趋势。 (来源: `lixinger`, `tushare`)
*   **高阶景气度**：分析师一致预期变化（净利润/营收上修比例）、行业量价数据与库存周期。
*   **拥挤度与性价比**：行业成交额占全市场比例分位、融资买入占比、经行业中性化后的 PB-ROE 残差。

### 4. 市场微观结构与资金面（短期交易情绪）
*   **外资动向**：陆股通前十大活跃股的成交及买卖金额、交易所季度外资持股（QFII/陆股通合并）、EPFR 等外部流向代理数据。（注意：港股通持股仅用于观察南向资金，不可替代北向）。
*   **内资与情绪**：ETF 份额净申购、融资买入占比、解禁规模、新发基金、产业资本增减持。
*   **情绪降噪**：对涨跌停家数、连板高度等游资情绪指标做标准化和移动平均平滑，仅作为极端冰点/高潮的左侧风控信号。

### 5. 微观标的质量与量化因子（个股α选股）
*   **基本面质量因子**：ROE 稳定性、毛利率趋势、扣非净利润同比、经营现金流/净利润。
*   **量价动量因子**：动量（过去1-12个月收益）、反转（近1个月收益）、波动率（20日已实现波动率）。

## 二、 从监控看板到实盘策略的合成路径

### 1. 宏观四象限状态机（Regime Switch）
基于连续的货币与信用评分（如 Z-Score），构建动态状态机，结合指数均线与 ERP 进行仓位管理：
*   **宽货币 + 宽信用**：经济复苏/过热期，高仓位，偏好成长与周期。
*   **宽货币 + 紧信用**：流动性陷阱/衰退期，股市往往涨估值，成长/题材/红利占优。
*   **紧货币 + 宽信用**：经济过热后期，价值/周期可能更强。
*   **紧货币 + 紧信用**：滞胀/衰退期，低仓位防御，现金为王。
*(注：状态切换需加入确认期，避免信号频繁跳变)*

### 2. 行业轮动打分卡与动态权重
在不同市场状态下，动态调整行业打分权重。所有因子必须先进行单因子测试（IC/IR）。
*   **景气度**：ROE 边际改善（低频）+ 分析师预期上修（高频）。
*   **估值性价比**：滚动 PB 分位及行业中性化后的 PB-ROE 残差。
*   **拥挤度防守**：高波动期提升估值权重，降低拥挤度权重。

### 3. 多因子选股与组合构建
*   **因子工程**：对质量与量价因子进行去极值、标准化、行业与市值中性化，消除共线性。
*   **单因子验证**：计算 IC 均值、ICIR、多空收益、换手率。
*   **合成与风控约束**：通过等权、IC加权或机器学习合成 Alpha 信号。组合构建时，施加目标波动率控制、目标暴露上限约束，而非简单的“最大回撤”硬约束。

## 三、 实盘交易、执行与风控闭环

为实现真正落地，系统还需包含以下执行层模块：
1.  **交易与成本模型**：处理 A 股 T+1、涨跌停、停牌限制，将印花税、过户费、佣金及滑点/冲击成本计入回测。
2.  **组合再平衡管理**：设定固定或基于信号阈值的调仓周期，处理现金管理、打新、分红再投资及无法买入/卖出的异常情况。
3.  **风控与熔断系统**：设定个股基本面/技术面止损规则、组合级目标波动率管理、单票流动性约束（如不超过日均成交额10%）。
4.  **绩效归因系统**：拆解超额收益来源（行业偏离、风格偏离、纯个股 Alpha），监控策略跟踪误差。

## 四、 数据工程（Data Pipeline）核心纪律

1.  **严格区分 PIT (Point-in-Time)**：将业绩预告、业绩快报与正式财报分离。回测时依据各自的真实公告日 (`ann_date`) 生效，并区分可信度权重。
2.  **前向填充 (FFill) 陷阱**：宏观与财报数据必须根据“真实发布时间表”进行可用性判断，严禁简单向发布日之前填充数据（Look-ahead bias）。
3.  **复权基准分离**：回测与计算量价因子时使用后复权价格或复权因子（保证收益率计算连续）；实盘下单计算仓位时必须映射回不复权真实价格。
4.  **交易日历对齐**：以国内交易日（`tushare` trade_cal）为基准轴，海外数据 (`fred`/`yfinance`) 节假日缺失值按业务合规规则取前一日值。
