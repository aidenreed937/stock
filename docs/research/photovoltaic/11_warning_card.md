# 三源预警卡（贴顶分位 + 产能周期 + 财报 TTM，季度尺度复合预警）

> 复现：`uv run python scripts/industry_solar_warning_card.py`
> 问题（§9 待办）：是否在季度/拐点层复用「需求分位贴顶」信号，叠加到产能周期状态 + 财报 TTM 之上，
> 构成"贴顶分位 + 产能周期 + 财报 TTM 三源预警卡"。
> 三源（release_date/披露日生效、无前视、日频前向填充、T+1）：
> - 贴顶 cap : 光伏装机 3mma YoY 36 月分位 >= 80（`industry_solar_cap_defense` 贴顶反身口径）。
> - 产能 cycle: 产业层产能周期状态 ∈ {过剩, 下行}（`industry_solar_cycle_position` 危险/过渡区）。
> - 财报 fin : 成分股聚合净利 TTM 同比 < 0（`industry_solar_profit_turn_ext` 恶化认定）。

## 1. 单源独立区分度（fwd2q / fwd4q：alert vs 反事实）

| 源 | alert 天数 | fwd2q 均值/中位/胜率 | fwd4q 均值/中位/胜率 | ~alert fwd4q |
| :-- | --: | --: | --: | --: |
| 贴顶 cap | 568 | 15.2%/0.3%/50% | 28.0%/1.9%/50% | 32.2%/15.8%/64% |
| 产能 cycle | 996 | -3.0%/-10.4%/42% | **-5.9%/-13.9%/38%** | **67.9%/47.9%/81%** |
| 财报 fin | 676 | 11.9%/9.3%/72% | 50.4%/43.7%/91% | 24.8%/-0.0%/50% |

逐个年度 alert 占比（说明三源在时间上如何错开）：

| 年 | %fin alert | %cyc alert | %cap alert | 解读 |
| --: | --: | --: | --: | :-- |
| 2019 | 48.4 | 16.0 | 24.9 | 利润谷底（fin）、贴顶萌芽 |
| 2020 | 0.0 | 7.0 | 72.0 | 景气上行、装机分位冲高（贴顶） |
| 2021 | 0.0 | 0.0 | 29.6 | 无扩产潮高利用率 → 上行 |
| 2022 | 0.0 | 89.7 | 43.0 | 扩产潮 → 过剩（cycle 主导） |
| 2023 | 0.0 | 100.0 | 62.7 | 过剩兑现、去库存 |
| 2024 | 68.2 | 100.0 | 12.8 | 利润转负 + 过剩 |
| 2025 | 100.0 | 100.0 | 0.0 | 深度负利润 + 过剩 |
| 2026 | 100.0 | 1.3 | 0.0 | 利润仍负、状态转上行（剪刀差转正） |

解读：
1. **产能 cycle 是唯一强前瞻危险源**（alert fwd4q -5.9%/38% vs ~alert 67.9%/81%），与 framework
   定稿"产业层产能周期状态门 = 季度尺度唯一前瞻信号"一致（见 [07](07_cycle_position.md)）。
2. **贴顶 cap 在季度尺度几乎无危险区分度**：alert fwd4q 均值 28.0% 与 ~alert 32.2% 相当（胜率
   略低），它主要在 2020-2021 景气上行段（装机分位冲高）误判为危险——贴顶是"高位反身"，但
   若高位恰逢景气主升，当作危险源会砍掉真实上行暴露。
3. **财报 fin 是滞后信号，其高 fwd4q 是聚合假象**：fin<0 的日子 48% 落在 2019（利润谷底→
   2020-2021 景气主升的均值回归，单一 episode 拉高均值），2024-2026 的 fin<0 期 fwd 实际为负。
   因此 fin 的 fwd4q "50.4%/91%" 不可作前瞻买入依据；它只适合作确认恶化后的减仓防守补丁。

## 2. 三源两两重叠（是否冗余）

| 组合 | 双激活 | 仅 A | 仅 B |
| :-- | --: | --: | --: |
| 贴顶×产能 | 337 (16.5%) | 231 | 659 |
| 贴顶×财报 | 11 (0.5%) | 557 | 665 |
| 产能×财报 | 416 (20.3%) | 580 | 260 |

贴顶与财报几乎不重叠（0.5%），与产能重叠 16.5%——贴顶"携带信息"，但该信息主要在景气上行段，
方向是**错误降仓**而非补充危险识别。

## 5. 结论（回答 §9 待办）

1. **§9 定稿：季度/拐点防守层不重用需求分位贴顶信号**。决定性对比：**加入贴顶会劣化防守**——
   cycle+fin 两源（全 13.06/外 -6.47/外MaxDD 30.56）全面优于三源复合卡（全 5.82/外 -12.84/
   外MaxDD 46.84）。贴顶在季度层无危险区分度，只引入 2020-08 后上行段的错误降仓。
2. **最优季度防守形态 = 「产业层产能周期状态 + 财报 TTM 两源防守门」**（外 -6.47%、外MaxDD
   30.56%）——比此前 07 的"cycle 单源状态门"（外 -10.60%、外MaxDD 43.75%）更好：fin 两源叠加大幅
   降仓（权重 54%）主要贡献 MaxDD，cycle 贡献方向性危险识别。两者是互补的。
3. **唯一前瞻危险源仍是产能周期状态门**；财报 fin 是滞后减仓补丁（其对 fwd4q 的高均值是 2019
   谷底→2020 景气的单一 episode 聚合假象，不可作前瞻买入）；贴顶在季度层不新增任何正向能力，
   仅保留在 fwd60 失效层级的研究记录（见 [04](04_cap_defense.md)）。
4. 局限：阈值（贴顶 80、状态分档、fin<0）取自既有研究，非本脚本反向拟合；全周期 CAGR 反超
   纯买入主要依赖 2019-2023 大段降仓（MaxDD 改善了但样本外仍未转正 -6.47%），持续防御语义，
   不宣称择时转正。
