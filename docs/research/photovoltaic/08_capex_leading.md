# 资本开支先导前瞻检验（财报 capex 能否领先产能周期与价格顶）

> 复现：`uv run python scripts/industry_solar_capex_leading.py`
> 动机：产能周期状态门（§7.4）用的是产业层滞后发布数据（2022-01 才见 cap_yoy +93%）；框架
> config 预留 capex_leading 参数（在建工程同比>20%、在建/固资>35% 视为扩张先导）但从未在
> 630500 实证。本检验回答：财报层资本开支/在建工程能否**领先**产业层状态与 2021-08 价格顶。

**领先性（首次触发日 vs 价格顶 2021-08-30；负=提前/正=滞后）**：

| 信号 | 阈值 | 首次触发 | 相对价格顶 |
| :-- | --: | :-- | --: |
| 财报-cip_yoy | >=30 | 2020-08-01 | -394 天（**数据起点即触发=截断假象**） |
| 财报-capex_growth_ttm | >=15 | 2021-04-01 | -151 天（**数据起点即触发=截断假象**） |
| 财报-fix_assets_yoy | >=30 | 2022-05-01 | +244 天（滞后） |
| 财报-cip_to_fa_ratio | >=0.35 | 从未触发（max 0.25） | 该参数在 630500 无效 |
| 产业-cap_yoy | >=30% | 2022-01-01 | +124 天（滞后） |
| 产业-状态首进过剩 | - | 2022-01-01 | +124 天（滞后） |

**fwd4q 分层（样本外 2022+，均值%/中位%/胜率%/n）**：

| 分层 | 扩张区样本外 | 非扩张区样本外 |
| :-- | :-- | :-- |
| 财报-capex_growth_ttm>=15 | -22.5/-24.1/16.2%/681 | +36.8/+41.7/99.5%/194（**全在 2024-10 后回升段=幸存者偏差**） |
| 财报-fix_assets_yoy>=30 | -26.1/-31.0/8.3%/436 | +7.2/+8.0/60.8%/439 |
| 财报-cip_yoy>=30 | -23.0/-23.9/11.6%/318 | -1.6/-2.0/47.8%/557 |
| 产业-状态=过剩（对照） | -31.2/-40.1/5.0%/483 | - |
| 产业-状态=上行（对照） | +82.5/+78.9/85.1%/610（样本外无样本） | - |

**先导检验结论**：
1. **财报 capex 先导不成立**：cip_yoy/capex_growth_ttm 的"首次触发"正是**数据起点**
   （2020-08 首值 104.8、2021-04 首值 22.8），领先 -394/-151 天是样本截断假象，更早扩张
   起点不可观测；唯一可证的是 fix_assets_yoy 滞后 244 天——财报层不早于产业层（+124 天）。
2. **区分度成立但弱于产业层**：财报 capex 高扩张区样本外 fwd4q 显著为负（-22~-26%），
   与产业层过剩反身同机制；但读数更温和、触发依赖披露时滞，不构成独立前瞻腿。
   capex_growth_ttm 非扩张区 +36.8% 全在 2024-10 后回升段，系幸存者偏差不作证据。
3. **定稿维持**：630500 前瞻仍以产业层产能周期状态门（fwd4q 区分度最强）+ 动量兜底为准；
   财报 capex 不新增前瞻能力，强化「财报层滞后验证、不作前瞻选股」框架定稿。
