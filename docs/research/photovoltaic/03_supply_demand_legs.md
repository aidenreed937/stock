### 4.4 供给侧内部对比：硅料是否比电池片更前瞻

研究问题：供给侧观测里，硅料腿是否比电池片腿更早给出信号？

| 剪刀差（装机 − 供给腿） | 全周期 IC | 样本外 2022+ | 产业链位置 |
| :-- | :--: | :--: | :-- |
| 装机−derived_poly（硅料利用率） | +0.163 | +0.036 | 最上游：硅料投产周期 18-24 个月 |
| 装机−cell_prod（电池片产量） | +0.006 | -0.036 | 中游：电池投产周期 12-18 个月 |
| 装机−wafer_util（硅片利用率） | +0.290 | +0.110 | 上游偏中：硅片衔接硅料与电池 |

1. **方向结论：硅料比电池片更前瞻**——全周期 +0.163 vs +0.006，硅料剪刀差 IC 高约一个量级。
   与产业链结构一致：硅料产能投放周期最长，利用率/价格信号最早反转（见 07 产能周期、08 capex），
   电池片是滞后确认环节，剪刀差已几乎无前瞻性（+0.006 贴零）。
2. **但样本外都不达标**：硅料 +0.036 塌向噪声，电池片 -0.036 转负；逐年漂移正负交替
   （硅料 2024 +0.257 → 2025 -0.113 → 2026 -0.144；电池片 2024 +0.345 → 2025 -0.233 → 2026 +0.189），
   单轮周期内符号即不稳定。
3. **最稳的是硅片利用率**（装机−wafer_util +0.290 / +0.110，全周期最高、样本外唯一保持正号），
   但逐年同样剧烈漂移（2024 +0.533 → 2025 -0.212 → 2026 +0.281），2026 重新转正与"过剩延续"叙事矛盾，
   符号本身不可信赖。
4. **证据分级〔B〕**：全周期正相关只是单段(2019-2026)观察，跨周期可重复性未验证。
   作为产业结构解释力成立（解释"硅料为何先见底、电池片为何滞后"），作为择时腿不足；
   与 §4.1/4.2「630500 无可用供给腿」定稿结论一致，不改动决策含义。

#### 4.4.1 两条最高分腿的可用性判定（可交易因子 vs 产业信息）

先拆成两个不混同的层次：**能否作为可交易 IC 因子**，与**是否仍是有用的产业信息**。

| | 硅料腿（装机−derived_poly） | 硅片腿（装机−wafer_util） |
| :-- | :-- | :-- |
| 全周期 IC | +0.163 | +0.290 |
| 样本外 2022+ | +0.036 | +0.110 |
| 逐年漂移 | 2024 +0.257 →25 -0.113 →26 **-0.144** | 2024 +0.533 →25 -0.212 →26 **+0.281** |
| 作为可交易因子 | **不可用** | **不可用**（最不可信） |
| 有用之处 | 判断产业链"谁先见底" | 提示定价与主叙事是否开始松动 |

- **作为可交易因子不可用**：可交易性只认"样本外能否跨周期稳定持仓"。两条 OOS 后逐年符号都正负交替，年初无法机械定单边方向（今天按 + 开多、明年被迫逆着来）；证据分级〔B〕，跨周期可重复性未验证。硅料 2025-2026 连续转负 = 领先性已被市场套利掉，再入因子即接盘；硅片 2026 重新转正与"过剩延续"主叙事直接矛盾，若按它对号入座会给一个反向假动作。
- **作为产业信息仍有用（不产出交易信号）**：硅料腿——用其"领先电池片一个量级、链条最先反转"作产业链定性与周期定位的参考；硅片腿——把"多年同号后开始漂移"当作定价切换 / 拥挤警告的拐点前兆，用于重新审视产业判断，而非跟随新符号开仓。

**一句话定位**：两条都不入择时、不可当 IC 因子；只作为定性解释与拐点预警的参考信息。这与 §4.1/4.2「无可用供给腿」定稿一致，不新增决策含义。

## 结论（含对初稿的修正）

1. **供给腿全部不可接**：derived_poly / cell_prod / wafer_util 三根候选样本外 2022+ 全部转负或归零，
   逐年漂移剧烈（正负交替、跨 ±0.4），无一条通过跨周期稳定性。630500 无可用供给腿。

2. **需求腿不是"后验板块"（修正初稿）**：本地二手实证 framework.md 已证**实物流量 demand 腿
   （含装机）在横截面层是"真前瞻"（fwd60 IC +0.116 / ICIR 0.35）**；逐年多为正。粗加总 OOS 转负的
   真实机制是**"分位贴顶反身"**（需求分位冲到历史高位后 fwd60 转负，与半导体 structural_ic 观测同构），
   叠加 2023-2025 光伏产能过剩（需求高 × capex 狂扩 → 未来 60 日中位 -4.33%，"需求高不是护身符"）。

3. **决策含义**：630500 的可用信号不是"换供给腿"，而是**避免在需求分位贴顶处裸多**——
   中低位装机分位仍有正择时，贴顶区应防守。供给腿无可接。
   成立路径：A 修正失效 docstring 并标注 / B 撤销供给腿回退需求+动量兜底 / C 深挖贴顶防守阈值。

4. **供给侧内部（§4.4）**：硅料剪刀差比电池片更前瞻（结构解释力，〔B〕），但样本外仍塌向噪声，
   最稳的硅片利用率腿也逐年漂移。供给侧观测只用于理解"谁先见底"，不纳入择时。
