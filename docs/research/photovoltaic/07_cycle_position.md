# 产能周期位置指示器（利用率反向腿 + capex 节奏，季度尺度拐点预警）

> 复现：`uv run python scripts/industry_solar_cycle_position.py`
> 机制：资金交易「单瓦盈利边际 = 产能周期位置的反身性预期」；状态（月度 release_date 生效、无前视、T+1）。
> 输入：硅料利用率（derived_polysilicon_utilization_rate）、年产能同比 cap_yoy（capex 代理）、
> 24 月扩产潮记忆（flood_24m）、产量同比 prod_yoy、供需剪刀差 scissors。

| 状态 | 天数 | fwd1q 均值/胜率 | fwd2q 均值/胜率 | fwd4q 均值/胜率 | 判定 |
| :-- | --: | --: | --: | --: | :-- |
| 上行 | 629 | 16.3%/65% | 38.2%/81% | **82.9%/83%** | 机会区 |
| 过剩 | 505 | -6.6%/20% | -17.7%/14% | **-31.5%/3%** | 危险区 |
| 下行 | 491 | 6.5%/54% | 12.1%/70% | 26.7%/83% | 过渡/修复 |
| 底部右侧 | 157 | -13.2%/10% | -26.7%/0% | - | 底部区(样本短) |

状态门（过剩/下行→0.3，T+1）：全周期 CAGR 10.97→14.88%、MaxDD 72.76→53.61%（收益回撤双改善）；
**样本外 2022+ CAGR -17.28→-10.60%、MaxDD 71.93→43.75%——是所有防守方案里样本外减亏效果最好的**，
但仍未转正。

**产能周期指示器结论**：
1. **过剩 vs 上行区分度极强**（fwd4q -31.5% vs +82.9%，胜率 3% vs 83%）——**扩产潮（cap_yoy>=30%）
   及其 24 个月余波是 630500 最强的反向/正向状态开关**，直接验证「资金交易产能周期反身预期」机制：
   2022-2023 扩产潮→过剩→下跌；2019-2021 无扩产潮高利用率→景气→上涨。
2. **下行是过渡态**（2024-2025 扩产潮余波）fwd 略正——此时风险已大部分定价，单独作警告意义弱。
3. **底部右侧**（2026 起）样本仅 ~8 个月，fwd1q 仍负（磨底）、fwd4q 无样本——右侧行情尚未证实；
   该状态作为"买点"目前不可验证，需等更长数据。
4. **状态门作为组合防守门有效**（全周期双改善 + 样本外 MaxDD 71.9→43.8），但规则由历史反推调参，
   有事后拟合风险；样本外仍 -10.6% 负收益，不宣称前瞻有效性。
   **升级**：叠加财报 TTM 两源门后样本外进一步减亏到 -6.47%、外MaxDD 30.6（见 [11](11_warning_card.md)）。
