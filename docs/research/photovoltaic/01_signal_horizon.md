# 供给弹性决定信号可交易尺度：半导体 fwd60 可跟踪 vs 光伏需 fwd2q/4q
> 光伏深度行业研究（2026-09）| 目录：[00 总览](00_study_overview.md) · [01 信号尺度](01_signal_horizon.md) · [02 数据](02_data_availability.md) · [03 供需腿](03_supply_demand_legs.md) · [04 贴顶](04_cap_defense.md) · [05 财报拐头](05_profit_turn.md) · [06 防守门](06_defense_gates.md) · [07 产能周期](07_cycle_position.md) · [08 capex 先导](08_capex_leading.md) · [09 定稿闭环](09_final_closed_loop.md) · [10 待办](10_conclusion_roadmap.md) · [11 三源预警卡](11_warning_card.md) · [12 状态门稳健性](12_cycle_robustness.md)

## 一句话结论

**行业供给弹性（扩产速度）决定资金定价对象，进而决定产业信号的可交易时间尺度**：
半导体（高壁垒、扩产慢）的利用率是"景气延续"正向腿、产业数据为高频连续流 → fwd60（~3 个月）可跟踪；
光伏（低壁垒、扩产快）的利用率是"反身过剩前兆"反向腿、反身传导链 1-2 年 → fwd60 是噪音，
需 fwd2q/fwd4q（6-12 个月）才兑现。**这不是方法缺陷，而是机制差异的必然。**

## 背景与问题

framework 定稿：半导体产业供需剪刀差（demand−supply，TSMC+SIA−SEAJ）是"真前瞻"，fwd60 择时成立；
光伏经全套验证（供需腿 / 贴顶 / 财报右确 / 组合防守门 / 产能周期指示器）后，fwd60 择时腿样本外全部失效，
只能在季度尺度（fwd1q/2q/4q）做拐点预警 + 组合防守门。

问题：为什么同样用 fwd60，半导体能跟踪、光伏不能？

## 实证事实（同一 fwd60 口径）

| 行业 | 腿 | fwd60 Spearman IC | 结论 |
| :-- | :-- | :-- | :-- |
| 半导体 | demand 腿（出货/销量/BD 等实物流量） | **+0.116** / ICIR 0.35（全行业截面实证） | fwd60 可跟踪 ✅ |
| 光伏 | 需求腿（装机） | +0.106（全）但 **OOS -0.166** | fwd60 样本外失效 ❌ |
| 光伏 | 供给腿-硅料利用率 | **-0.157**（OOS -0.247） | 反向腿，fwd60 失效 ❌ |
| 光伏 | 供给腿-硅片利用率 | **-0.307**（OOS -0.283） | 反向腿，fwd60 失效 ❌ |

光伏的供需腿、贴顶、财报右确全按 fwd60 口径测过，全部失败；产能周期状态在 fwd1q（≈fwd60）上区分度也弱
（过剩 -6.6%、上行 +16.3%），到 fwd2q/fwd4q 才拉开（过剩 -17.7%/-31.5%、上行 +38.2%/+82.9%）。

> 注意：fwd60（60 交易日 ≈ 2.86 个月）与 fwd1q（63 交易日 = 1 季度）在技术上几乎同一尺度，
> 差异在时滞梯度本身：fwd1q(3 月) → fwd2q(6 月) → fwd4q(12 月)。详见同目录 `07_cycle_position.md`。

## 机制根源：供给弹性 → 定价对象 → 信号尺度

### 3.1 半导体（高壁垒、扩产慢、建产能 2-3 年）

- **利用率高 = 景气延续（正向腿）**：新增产能短期进不来，高景气能维持，需求/出货的高频数据直接反映当下景气。
- **数据是月度高频连续流**：TSMC 月营收（次月 10 号）、SIA 月销售额、SEAJ 设备出货、DOI 库存，时效好、信息率高。
- **资金定价"当下景气延续"**：景气在 60 日尺度有动量 → 高频腿在 fwd60 有信息。

### 3.2 光伏（低壁垒、扩产快、12-18 个月投产）

- **利用率高 = 过剩前兆（反向腿，反身性）**：高利润立刻吸引扩产，当前高利用率本身在孕育未来过剩。
- **反身传导链很长**：高利用率 → 扩产潮 → 产能落地 → 过剩兑现 → 价格战，**整条链 1-2 年**。
- **资金定价"产能周期位置的反身预期"**（季度/年度尺度）：单月利用率变化（70%→65%）在 60 日尺度是噪音，
  既不代表景气反转、也不代表过剩落地。
- **实测排除"数据发布滞后"解释**：已用 release_date 修正无前视，fwd60 照样失效——问题在信号机制尺度本身，
  不在数据时效。

### 3.3 对比表

| 维度 | 半导体 | 光伏 |
| :-- | :-- | :-- |
| 供给弹性 | 低（扩产慢、2-3 年） | 高（扩产快、12-18 个月） |
| 利用率含义 | 景气延续（**正向**腿） | 反身过剩前兆（**反向**腿） |
| 信号性质 | 高频流量延续 | 产能周期位置 |
| 数据频率 | 月度高时效连续流 | 月度/季度、产能事件低频 |
| 资金定价对象 | 当下景气延续 | 产能周期反身预期 |
| 可交易尺度 | fwd60（~3 个月） | fwd2q/fwd4q（6-12 个月） |
| 定位 | 深研线簇前瞻择时 | 拐点预警 + 组合防守门，不作独立择时 |

## 支持证据（同一指标、方向相反）

1. **同一"利用率"因子方向相反**：半导体利用率=正向腿（景气延续），光伏利用率=负向腿（fwd60 IC -0.157~-0.307）。
   行业供给弹性决定它是"延续信号"还是"反身信号"，进而决定可交易尺度。
2. **光伏周期长度可测**：硅料利用率 2021-12 见顶 94% → 2022-01 扩产潮 cap_yoy 跳 +93% → 2023 过剩兑现 →
   2024-2025 出清 → 2025-12 底部右侧确认。整周期 4-5 年，状态切换间隔均在半年以上，fwd60 尺度无法形成择时样本。
3. **产能周期指示器**（`industry_solar_cycle_position.py`）：过剩/上行状态 fwd4q -31.5% vs +82.9%（胜率 3% vs 83%），
   fwd1q 区分度弱——长窗口是光伏信号的兑现尺度。

## 方法论含义

1. **framework 半导体方法论不可直接照搬光伏**：剪刀差/利用率在半导体是正向腿、在光伏是反向腿；
   半导体的 fwd60 择时腿在光伏是噪音。跨行业推广前必须先按供给弹性判断腿的方向与可交易尺度。
2. **光伏定位已定稿**：无 fwd60 择时腿 → 动量 Top3 兜底 + 组合防守门（产能周期/财报/贴顶）；
   产能周期位置仅作季度拐点预警 + 防守门，不宣称前瞻择时。
3. **对"需求高不是护身符"的机制补充**：需求高×capex 狂扩 → fwd60 中位 -4.33%（framework 实证），
   是"扩产潮反身"在短窗口的直接体现——光伏的需求高本身不构成 60 日买入理由。

## 通用判定清单（新行业：该用 fwd60 还是长窗口？）

对任一产业供需腿，先回答：

1. **扩产周期多长？** < 1 年（低壁垒）→ 信号偏反身、需长窗口；> 2 年（高壁垒）→ 信号偏延续、可能 fwd60。
2. **利用率/产量数据是高频连续流还是低频产能事件？** 高频且时效好 → 可试 fwd60；低频/事件型 → 用 fwd2q/4q。
3. **同指标 IC 方向是什么？** 正向（利用率高→景气延续）→ 延续腿；负向（利用率高→未来跌）→ 反身腿，换长窗口。
4. **资金定价对象？** 若为"当期景气延续"→ fwd60 候选；若为"产能周期反身预期"→ 只能拐点预警/长窗口。
