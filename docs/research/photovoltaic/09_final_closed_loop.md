# 定稿方案闭环实证（动量 Top3 兜底 + 组合防守门）

> 复现：`uv run python scripts/industry_solar_final_closed_loop.py`
> 关键事实：630500 已被剔除出 16 行业方向池（与电池相关 0.77，framework.md），
> 本实证将其放回（17 池）测边际贡献；口径对齐 CLI 基线（return_60d Top3、pe5y<=90、

630500 入选 7 个调仓期（2020-08/2020-12/2021-03/2021-09/2022-06/2024-10/2025-11 起），
入选交易日占比 29.1%，集中在 2020-08~2022-09 与 2024-10~2026-02。

**闭环结论**：
1. **池层（视角 A）：630500 放回方向池是净拖累**——全 CAGR 6.91→4.07%、样本外 1.91→-0.58%
   （转负），全 MaxDD 56.52→60.39%。入选时段集中在 2020-2022 主升与 2024 后阴跌段，
   与电池相关 0.77 意味着放回池只是重复暴露，印证当初因相关性剔除的合理性。
2. **单行业（视角 B）：动量兜底大幅减亏但未转正**——样本外 -17.28→-7.76%（MaxDD 71.93→45.06），
   全周期 7.22→4.02%。动量 Top3 兜底在 630500 上只是"减亏一半"，不是正收益来源。
3. **叠加产能周期门最接近转正**：样本外 -0.89%（其余门 -2.17~-5.77%）、MaxDD 15.99%、
   全周期 8.23% 反超纯买入——与 §7.4 状态门"所有防守方案里样本外减亏最好"一致；
   财报门次之（外 -4.10%，全 7.07% 接近纯买入）；贴顶门最弱（外 -5.77%）。
4. **OR 三门回撤最稳**：全 MaxDD 72.76→21.25%、外 71.93→15.99%，但外 CAGR -2.17% 未转正，
   全周期 3.76%（降仓 13.2% 的代价）。
5. **定稿确认**：630500 即使在动量 Top3 兜底框架下样本外仍为负收益（最好 -0.89%），
   不构成可交易正收益来源；维持「不投入 fwd60 择时腿 + 组合防守门减亏」定稿。
   若未来使用 630500，最佳形态是**动量选中才持有 + 产能周期状态门**（或 OR 三门求回撤稳）。
