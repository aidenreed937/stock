# 产能周期状态门——稳健性审计（阈值敏感性 + 分年切片 + IS/OOS）

> 复现：`uv run python scripts/industry_solar_cycle_robustness.py`
> 动机：07/11 把「产业层产能周期状态门」定为季度尺度（fwd2q/4q）**唯一前瞻信号**，但结论
> 由历史反推调参，**事后拟合风险**被反复标注。本审计显式扰动阈值、分年切片、IS/OOS 分样本，
> 检验「过剩 vs 上行 fwd4q 区分度」是稳健机制还是参数拟合的产物。
> 口径与 cycle_position 对齐（release_date 生效、日频前向填充、fwd4q=252 交易日）。无参数反向拟合。

## 1. 阈值敏感性——稳健（非阈值拟合）

对状态门最关键的 4 组分档阈值做单维扰动，观察「过剩 vs 上行 fwd4q」区分度：

| 参数 | 取值区间 | 过剩均值% | 上行均值% | 均值差pp | 胜率差pp | 判定 |
| :-- | :-- | --: | --: | --: | --: | :-- |
| cap_yoy 扩产潮 | 0.20~0.40 | -18.9~-31.5 | 82.9 | -102~-114 | -60~-80 | 稳健 |
| flood_24m 扩产记忆 | 0.20~0.40 | -31.5 | 82.9 | -114 | -80 | 不影响(只改下行级) |
| util_hi 高利用率上界 | 60~80 | -31.5 | 81~90 | -112~-122 | -73~-81 | 稳健 |
| util_lo 低利用率下界 | 35~55 | -31.5 | 82.9 | -114 | -80 | 不影响(只改右侧级) |

**阈值稳健**：cap_yoy、util_hi 在合理区间扰动下，过剩 vs 上行均值差稳定在 -100~-120pp、
胜率差 -60~-81pp，符号与幅度不翻转。flood_24m/util_lo 只改「下行/底部右侧」相位，不触碰
「过剩 vs 上行」本对比。→ 区分度对参数**不敏感**，排除「阈值拟合」。

## 2. 状态 × 年份构成——样本次数（关键局限）

| 年份 | 上行 | 过剩 | 下行 | 底部右侧 |
| :-- | --: | --: | --: | --: |
| 2019 | 162 | 0 | 36 | 0 |
| 2020 | 199 | 0 | 15 | 0 |
| 2021 | 243 | 0 | 0 | 0 |
| 2022 | 25* | 217 | 0 | 0 |
| 2023 | 0 | 241 | 0 | 0 |
| 2024 | 0 | 47 | 195 | 0 |
| 2025 | 0 | 0 | 243 | 0 |
| 2026 | 0 | 0 | 2 | 159 |

*2022 的 25 天「上行」是 2021 末前向填充残留（非真实新上行段）。

**相位时间完全分离 = 一个完整产能周期的一次实现**：
- 上行只在 2019-2021（景气主升）；过剩只在 2022 中-2024（扩产潮兑现）。
- 「过剩 vs 上行」本质是 **2019-2021 涨 + 2022-2023 跌的先后序列**，而非同年内的横截面判别。

## 3. IS vs OOS——结构上无法同截面验证

| 样本 | 状态构成（天数） |
| :-- | :-- |
| IS 2018-2021 | 上行=604, 下行=51（只有景气，无过剩） |
| OOS 2022+ | 上行=25(残留), 过剩=505, 下行=440, 底部右侧=159 |

IS 段无过剩、OOS 段无真实上行 → **同截面 IS/OOS 的 fwd 区分度在结构上不可能**。之前 11 里
"OOS 上行 82.9%"其实混入 2022 前 25 天前向填充残留 + 前一日语污染，本审计已剔除该偏差。

## 4. 分年度 fwd4q 区分度（默认阈值）

只有 2022 一年同时含过剩(n=217)与上行残留(n=25)，其 fwd4q 均值差 -29.5pp、胜率差 -33.5pp——
其余年份两相位不同时存在，无法年际对比。年度间「区间内判别」样本不足。

## 5. 结论（稳健性判定）

1. **阈值敏感性稳健 → 非阈值拟合**。状态门的区分度对 cap_yoy/util_hi 等关键分档参数不敏感，
   排除「调参凑结论」的可能。这是对本信号支持性极强的一条。
2. **时间稳健性弱（关键局限）**：样本只含**一次完整的景气→过剩循环**。区分度强但来自单一
   实现（2019-2021 涨 + 2022-2023 跌的先后），无法排除「光伏本轮周期仅此一次」的选择性偏差。
3. **IS/OOS 同截面验证不可行**：相位分离导致 IS 无过剩、OOS 无真实上行，fwd 区分度无法在
   相同时间内横截面重验离。
4. **综合判定**：「产业层产能周期状态门 = 季度尺度唯一前瞻信号」结论**成立但置信度受限于单次
   循环实现**。它不是参数拟合（阈值稳健），但跨相位稳健性未证实，需 2026+「底部右侧→新一轮
   上行」的后续数据二次确认（与 07 §3 右侧样本短同源）。定位维持「组合防守门 + 拐点预警」，
   不宣称为可独立择时的重复性信号。
