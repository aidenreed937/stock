# 宏观风控因子 IC 稳定性定期复审 SOP

> 本文定义宏观风控因子选取的**定期复审机制**：周期、命令、判定口径、裁决规则与留痕要求。
> 目的：因子选取是"配置快照"，其稳定性是对已覆盖历史周期的结论，需持续监控——
> 市场机制会漂移，季度复审用于及时发现"年度符号漂移"的因子，防患于未然。
>
> 配套：方法论与既有裁决见 [`factor_selection_methodology.md`](./factor_selection_methodology.md)
> （§5.1-5.5）；IC 计算实现见 `src/stock_strategy/macro/ic.py`；本机制实现见
> `src/stock_strategy/macro/ic_review.py` 与 `src/stock_cli/macro_ic_review.py`。

---

## 1. 为什么需要定期复审

- 双轨指数 / 维度分 / 单因子的 IC 验证与回测验证都是**对已覆盖历史（2011-2026）**的结论；
- 市场机制可能漂移（如范式切换、微观结构变化），某因子的预测方向可能失效或反转；
- 既有教训：`us_yield_curve` 的年度符号跨周期漂移 → 已降级为独立观测（§5.1 之 5）；
  而 `dim_crowding` 的 pooled "短正长负"曾误判为不稳定，实为尺度效应（§5.5）。
- **定期复审 = 用"年度符号稳定性"持续监控，捕捉新漂移，避免因子悄悄失效**。

---

## 2. 复审周期与职责边界：季度巡检，年度裁决

| 周期 | 触发条件 | 性质 | 说明 |
| :-- | :-- | :-- | :-- |
| **季度（默认）** | 每季度末 | **巡检（只观察，不裁决）** | 重跑 IC + 符号稳定性 + 快照对比；发现 `new_stable_drift` 新项 → 记入观察，**不立即改动配置** |
| **事件触发** | 重大范式切换 / 因子口径变更 / 新因子纳入后 | 即时复核 | 专项核验受影响的因子/维度 |
| **年度** | 每年 12 月末 | **裁决（完整证据链）** | 符号稳定性 + 全量回测 + guardrails + 方法论文档同步，是**因子选取的决策时刻** |

**为什么季度不裁决**：宏观因子是慢变量（60D 才显著），一个季度约 60 个交易日，样本增量有限——
频繁做符号稳定性判定会产生噪音（`dim_crowding` 的 pooled 误判就是样本尺度造成的教训）。季度的职责是
**提前发现问题**，年度的职责是**解决问题**；也符合"阈值定稿后不重炒"的纪律。

### 季度 vs 年度执行对照表

| 动作 | 季度（巡检） | 年度（裁决） |
| :-- | :--: | :--: |
| 重跑 IC（`build_ic_report`） | ✅ | ✅ |
| 复审命令（`make macro-ic-review`，符号稳定性 + 快照 diff） | ✅ | ✅ |
| 查看 `new_stable_drift` 新漂移项 | ✅（记入观察清单） | ✅ |
| 变更因子/维度配置 | ❌ **不裁决** | ✅ 可裁决 |
| 全量回测对比（多策略绩效） | ❌ | ✅ |
| 稳定性审计 guardrails | ❌ | ✅ |
| **样本外验证缺口评估**（全周期拟合风险） | ❌ | ✅ |
| 更新 `factor_selection_methodology.md` §5 决策留痕 | ❌（仅追加观察记录可选） | ✅ 必须 |
| 更新 SOP / 阈值定稿 | ❌ | ✅ |

> 季度发现漂移 → 若连续 2 个季度持续且机制无法解释 → 记入年度裁决候选；
> 方向反转（主导符号翻转）为最高优先级例外，可**立即**进入复核（仍须回测验证后裁决，见 §5）。

## 3. 复审命令（可复现）

```bash
# 1. 重跑 IC 验证（12 聚合信号 + 23 单因子，5/20/60D）
uv run python -c "from stock_strategy.macro.ic_report import build_ic_report; build_ic_report()"

# 2. 运行 IC 稳定性复审（默认 60D 年度符号，输出报告 + JSON 快照）
make macro-ic-review
# 等价：uv run python -m stock_cli.macro_ic_review
# 可选参数：
#   --horizon 20          # 用 20D 窗口
#   --stable-ratio 0.7    # 主导符号占比下限
#   --max-flips 2         # 符号翻转次数上限
#   --output-dir PATH     # 指定输出目录
```

**产物**（`data/analytics/macro_strategy/ic/review/`）：

| 文件 | 内容 |
| :-- | :-- |
| `ic_stability_review.md` | 12 信号 + 23 单因子的年度符号稳定性表（✅稳定 / ⚠️漂移候选） |
| `agg_sign_stability.csv` | 聚合信号稳定性数据（机器可读） |
| `single_sign_stability.csv` | 单因子稳定性数据（机器可读） |
| `sign_stability_snapshot.json` | 带生成时间的完整快照，**用于与下次快照 diff** |

## 4. 判定口径（重要）

- **稳定性基于"年度 IC 符号"**，不是 pooled IC——pooled 符号翻转 ≠ 漂移（可能是尺度效应，见
  `factor_selection_methodology.md` §5.5 的 dim_crowding 案例）；
- **稳定判定**：主导符号占比 ≥ `stable_ratio`（默认 0.7）且符号翻转次数 ≤ `max_flips`（默认 2）；
- 年度 IC 缺失（None）不算翻转，但计入可用年份；可用年份 < 3 标记为 `insufficient`（不判稳定）；
- 默认窗口 60D（主决策窗口），可用 `--horizon 20` 复核短期稳定性。

## 5. 复审裁决规则（裁决时点为年度；季度仅巡检）

| 复审结果 | 动作 |
| :-- | :-- |
| **稳定**（✅） | 维持现状，无需改动 |
| **新出现漂移**（本次 ⚠️ 且上次 ✅，`new_stable_drift=true`） | **记入观察清单**，对照机制假说判断是"尺度效应"还是"跨周期漂移"；连续 2 个季度仍漂移且机制无法解释 → 进入年度裁决候选（参考 `us_yield_curve` 降级流程） |
| **持续漂移**（连续 ⚠️） | 列入观察清单；若连续 2 个季度仍漂移且机制无法解释 → 评估降级为独立观测 |
| **方向反转**（主导符号由正转负或反之） | **最高优先级例外**：不受"季度不裁决"限制，**立即**进入复核——对照机制与阈值方向是否仍成立，必要时回测验证后裁决 |

**裁决纪律**（同 `factor_selection_methodology.md` §5）：
- 任何"降级 / 剔除 / 纳入"必须**回测验证 + guardrails**，不能只凭符号漂移定稿；
- 每个裁决写入 `factor_selection_methodology.md` §5 系列作为决策留痕；
- 阈值定稿后不重炒；参数改动属研究参数，需显式记录；
- **样本外验证缺口复核（年度必做）**：确认是否已执行时间切片样本外验证
  （如 walk-forward 滚动验证、前 N 年定参 + 后 M 年只验证不调整）；未执行时，
  评估全周期拟合风险，明确"全周期表现 ≠ 前瞻能力"的局限，并记录为年度裁决的已知限制。
