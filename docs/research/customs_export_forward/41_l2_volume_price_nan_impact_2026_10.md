# L2 行业量价 NaN 影响分析（GACC 段）（金额不缺腿 × 量/价 130 缺腿）

> 数据源：`data/analytics/industry/customs_l2_volume_price_monthly.parquet`（粒度=L2，**GACC 段（source=GACC，2018-01 起）**）；研究面板由 customs_prosperity 管线按 `research_sources=["GACC"]` 构建，底层 customs_trade_gacc.parquet 为纯 GACC（UN 数据见 customs_trade.parquet）
> 口径：3MMA yoy 统一重算；null=前 14 个月暖机期（与 lag12 对齐缺失），
> NaN=数量为 0 / 不可加总导致的判不了（`volume_yoy`/`price_yoy` 非有限值），驱动类型置 null。
> 复现：`uv run python scripts/analyze_customs_l2_vp_nan_impact.py`

## 一句话结论

金额 yoy 是唯一任何可算月份都不缺腿的主序列；量/价 yoy 在 50 条 L2 序列中
**2 条序列**（2 个具名行业）的 **130 个行业-月份**判不了象限
（占面板 2.6%），其中整段缺腿（≥98% 可用月）的行业：
**航空装备Ⅱ（100.0%）、炼化及贸易（100.0%）**。**选 Beta 仍可只看金额，但判驱动类型/量价齐升门在这些月份只剩金额腿**；
三腿 AND 的腿1（金额≥30% 且量价齐升/量驱动）在这些月份无法满足，
相关行业实际可用信号时点要按行业打折。

## 5. 口径与使用建议

- **范围即 GACC 段**：本报告只统计 `customs_trade_gacc.parquet` 中 source=GACC 的行（2018-01 起），已排除 Comtrade 桥接段（2016~2017）；该段的实际缺腿只有炼化及贸易与航空装备Ⅱ两条序列。
- **“金额无 NaN”不是量价列大面积缺失**：量/价缺腿集中在混单位/数量为 0 的行业-月份，
  是“判不了”而非“没数据”；金额缺腿只来自统一的前 14 个月暖机期。
- **判驱动/选 Beta 的处理**：缺腿行业-月一律按金额主口径看（金额 yoy 方向/拐点仍可用）；
  驱动类型与量价齐升/量驱动门在这些月份置 null，不参与四象限统计，也不得把 NaN 当 0 或当缺失补齐。
- **炼化及贸易（801963.SI）**：量价几乎整段 NaN，行业级四象限不可用；景气判断按 skill 既有口径
  转用财报/价差口径（净利 TTM yoy），海关侧只看金额 yoy。
- **航空装备Ⅱ（801742.SI）**：2022-01 起纳入面板、2023-03 起量价连续 NaN（41 个月，整段缺腿）；
  只能看金额腿，驱动类型不可判，按金额择时 + 财报/资金确认处理，勿用量价四象限。
