## 1. 口径与分组

- **三版回测**（`backtest_customs_multi.py --quality-filter`）：
  - `base`：仅出口 yoy 择时（连续 2 月 >0 分 3 批建仓 / 见顶减半 / yoy≤0 清仓）；
  - `quality`：+ 质量门（入场要求量价齐升/量驱动，规避价驱动伪景气）；
  - `quality_filter`：+ 竞争力过滤（§5.4 修订：同产品内部相对比较，见下）。
- **竞争力过滤（§5.4 修订）**：同一产品（product_key）内，最近年报
  netprofit_margin / grossprofit_margin 相对**同产品中位数**分层——亏损型（净利率<0，
  绝对）剔除；低竞争力（净利率 与 毛利率 **均低于同产品中位数**）剔除；其余保留。
  旧口径（净利率<5% 且 ROE<10% 绝对阈值）见附录 A，本节主表用新口径。
- **产品分组**（对齐 METHODOLOGY_COMPANY_FINAL §6 周期结构 + §8 排除清单）：
  按产品主段 3MMA yoy 波动（2021-08~2026-07 窗口，std 阈值 100pp）+ 内销机械标签：

  | 分组 | 产品数 | 定义 |

  | 成长组（= 有效池） | 84 | std<100pp 且非内销机械（成长性周期） |
  | 内销机械 | 5 | forklift/excavator/crane/wheel_loader/machine_tool |

- **普适性度量**：有交易轮次的产品中，平均超额（avg_excess_pp）>0 的占比。

## 3. 核心结论

### 3.1 全池普适性成立（信号本身可扩展）

- **108 产品全池 base 版 80% 产品平均超额为正（86/108），平均 +25.8pp、中位 +13.9pp**；
  成长组有效池（84）更高：81% 正超额、平均 +28.9pp、中位 +14.4pp。
- 即 **出口景气择时信号在远超 11 个强信号产品的范围上依然普适成立**——产品池可从
  11 个扩大，前提是区分周期结构（见 3.2）。

### 3.2 分组梯度：成长组 > 内销机械 > 价格组

- **成长组（84）**：普适率 81%、平均超额 +28.9pp——信号最可靠的主体；
- **价格组（19，快周期/价格性周期）**：普适率 68%、平均超额 +13.2pp（约为成长组一半），
  确认 §6 结论"快周期商品弱但方向转正"，月度确认滞后于商品脉冲的机制风险仍在，
  **维持谨慎/观察，不作主池**；
- **内销机械（5）**：GACC 窗口内回测 5/5 正超额（+20.4pp），但维持 §8.4 的**机制性排除**
  ——股价由国内/全球工程机械周期与内销主导，出口信号是巧合而非因果，回测为正不改变
  该定性（年报口径 7/9 年脱钩的机制证据优先于月度择时巧合）。

### 3.3 竞争力过滤（修正口径）：修复整池误杀，在 quality 门上是弱正向精化

成长组内配对增量（仅两者都可交易的产品配对）：

| 对比 | 配对 | 更优占比 | 平均增量 | 中位增量 |
| :-- | :-- | :-- | :-- | :-- |
| quality_filter vs base | 83 | 42% | −6.5pp | −0.6pp |
| quality_filter vs quality | 83 | **51%** | **+3.2pp** | **+0.1pp** |
| quality vs base | 84 | 37% | −9.6pp | −1.7pp |

- **质量门（quality vs base）平均 −9.6pp**：量价齐升/量驱动门砍掉的价驱动伪轮中，很多
  在 2019-2026 GACC 窗口其实赚钱（价格脉冲期），所以平均超额被拉低——质量门的价值在
  规避伪轮与缩短持有（稳健性），不在平均超额增强；**主要超额牺牲来自质量门，而非竞争力过滤**；
- **竞争力过滤（quality_filter vs quality）修正后平均 +3.2pp、中位 +0.1pp、51% 产品更优**：
  相对旧绝对口径（+1.4pp、42% 更优、清空 16 产品）明显改善——同产品内部相对比较只剔除
  产品内最弱环节（bottom-left 象限），不再整池误杀，故是 quality 门上的**弱正向选股精化**；
- **quality_filter vs base 仍为负（−6.5pp）**：因 base 无质量门，二者不可直接对比；
  竞争力过滤本质仍是"剔除同产品最弱环节"的下行保护，非独立强 alpha 源。

**结论：竞争力过滤定位为 quality 门之上的"同产品选股精化层"，常态可叠加（+3.2pp、51% 更优、
不再误杀整产品），但增益温和；其核心价值仍是下行保护，不作全池无条件强制前置。**

## 5. 操作含义（更新）

1. **信号本身可扩展**：出口景气择时在 108 产品全池 80% 正超额，产品池可显著扩大，
   但按周期结构分层使用——成长组为主池，价格组（快周期）维持谨慎/观察；
2. **竞争力过滤（§5.4 修订）**：改用同产品内部相对比较（净利率×毛利率均低于同产品中位数
   剔除），作为 quality 门之上的**常态选股精化层**（+3.2pp、51% 更优、不再整池误杀）；
   其本质仍是下行保护，增益温和，不作全池无条件强制前置；
3. **质量门（--quality-gate）的价值在稳健性**（规避价驱动伪轮、缩短持有），会牺牲部分
   平均超额（−9.6pp），实盘推演继续强制开启，不作增强器看待。

## 6. 边界与复现

- 等权组合、月度再平衡，未做市值加权/风险平价/手续费敏感性（换手集中在景气切换，
  成本影响有限但需量化）；
- 内销机械（5）回测为正但不改变机制性排除（§8.4），GACC 窗口短、月度择时巧合风险；
- 复现：
  ```bash
  # 1) 全池三版回测（108 产品，--quality-filter 用 §5.4 修订口径）
  uv run python scripts/backtest_customs_multi.py \
    --products $(tail -n +2 config/data/customs/company_exposure_map.csv | cut -d, -f1 | sort -u | tr '\n' ' ') \
    --quality-filter --output data/analytics/industry/customs_signal_multi_fullpool.parquet
  # 2) 分组普适性分析（本文 §2/§3/§4 全部表格来源）
  uv run python scratch/analyze_fullpool.py
  ```
- 分析产物：`data/analytics/industry/customs_signal_multi_fullpool.parquet`（108×3 版逐产品）
  与 `..._analyzed.csv`（含分组/std 标注）。
