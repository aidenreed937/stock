# 海关出口 × 行业财报 前瞻关联研究 (Customs Export Forward)

> 研究定位：**行业基本面前瞻**——用月度海关出口量价数据，把"财报滞后验证"升级为"近实时前瞻验证"。
> 实证日期：2026-09（数据截至 2026-07 出口、2026 中报财报）
> 数据源：`data/curated/industry/customs_trade.parquet`（UN_Comtrade 2016-2024 + GACC 2025-2026）
> 关联对象：申万二级行业 L2 财报 TTM 营收同比（`sw_2021_l2_fs_non_financial`）

---

## 1. 一句话结论

**出口月频（T+20 天发布）机制性领先财报（T+40~80 天发布）1-2 个季度；45 个二级行业中有 11 个
方向一致率 ≥0.85（出口是可靠的基本面前瞻代理），有 7 个 ≤0.42（出口对该行业财报无前瞻价值）。**

它不是择时/选股因子，而是**基本面兑现的前瞻代理**：财报出来前先预判行业营收方向，用于
① 验证剪刀差/动量选出的行业是否真在兑现；② 对无产业腿行业提供唯一的前瞻基本面信号。

## 3. 研究边界（必须声明）

1. **方向一致率 ≠ 预测力**：衡量"出口转正后财报是否转正"的伴随关系，需配合拐点时间差（领先月数）使用；
   只在出口占行业营收比高、映射产品代表性足时成立。
2. **光伏教训**：出口 2026-07 已 +6.3%（领先 9 个月转正），财报仍 -12.2%——出口前瞻的是**营收方向**，
   不是盈利方向，更不是股价。财报兑现滞后是常态，不能因出口转正就立刻判定盈利反转。
3. **前瞻成立的产业前提——行业定价权在外需**：出口前瞻财报（尤其净利）隐含的产业机制是
   "全球定价 × 格局稳定 × 玩家有限"（如电网设备变压器、半导体、医疗器械）。光伏是反例：
   - **重资产 + 低门槛**：重资产折旧刚性，低门槛导致产能易复制，玩家众多、格局未定；
   - **供给国内占大头**：全球产能 90%+ 在国内，**价格由国内供需（内卷）决定，不由出口决定**——
     出口只是去化过剩产能的边际通道，量的回升不改变行业整体供需过剩；
   - **不成熟产业**：技术迭代期格局未定，价格战由国内玩家主导，出口景气无法传导到价差与盈利。
   因此出口前瞻适用性分级：**全球定价+格局稳定行业（出口≈盈利方向）> 国内供需定价行业（出口≈量方向，
   盈利另看价格战）> 无出口映射行业（不适用）**。光伏、电池、乘用车（国内价格战）属于第二档，
   出口信号只回答"量"，盈利兑现还需看产能利用率与价格企稳。
4. **不是择时因子**：方向一致率 0.9 的行业（如光伏 0.92）股价仍可下跌（拥挤度瓦解/盈利担忧），
   前瞻信号只回答"基本面兑现方向"，不回答"市场是否已定价"。
5. **GACC 覆盖缺口**：2025+ 已并入 41 个重点产品（工业金属/商用车/风电/工程机械/电池等主线已覆盖到
   2026-07），但贵金属/煤炭/焦炭/炼化及贸易/普钢/特钢/装修建材/家居用品/消费电子/纺织制造/化学纤维等
   产品仍止于 2024-12——近端面板中这些行业标注为 "出口止于 2024-12"，**2025-2026 的出口 yoy 是缺失的**，
   解读近端状态时须跳过。

## 4. 与既有框架的关系

| 现有框架层 | 关系 |
| :--- | :--- |
| industry-trend-tracking「财报滞后验证」（量价齐升/毛利率扩张） | **本研究的直接升级对象**：财报从"事后确认"变为"出口前瞻+财报确认"双轨 |
| industry-trend-tracking「全球方向」（可选加权/拐点预警） | 出口量价是"全球方向"里可落到 A 股行业口径的硬数据，可作为方向分的替代/补充输入 |
| 产业供需剪刀差（半导体等有腿行业） | 互补：剪刀差看供需矛盾，出口看外需兑现；有腿行业用剪刀差，无腿行业用出口前瞻 |
| 三条件框架（全球定价 × 高频数据可见 × 景气兑现） | 出口前瞻有效性 = 三条件的交集：**全球定价**（价格由全球供需决定，出口≈盈利方向）是核心前提；**高频可见**（月频量价）本研究已验证；**景气兑现**（财报 TTM 双正）是滞后确认层。光伏/电池/乘用车满足"高频可见"但缺"全球定价"（国内供需定价），故出口只前瞻量、不前瞻盈利 |
| industry-rotation-strategy（20-60 日轮动） | 不同尺度，不混用；本研究的月度信号不适合 60 日截面博弈 |
