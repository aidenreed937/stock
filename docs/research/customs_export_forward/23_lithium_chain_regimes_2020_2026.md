# 23 锂电产业链出口规律（2020-2026，环节弹性梯度）

> **性质**：从 battery（电芯）趋势外推到锂电全产业链（电芯 + 6 个材料/结构件环节）的
> 规律归纳，数据取自 GACC 黄金表 `customs_product_volume_price.parquet` 月度金额 3MMA yoy
> （各产品主段），2020-2026。区分**数据事实**（序列本身）与**机制推断**（归纳概括）。
>
> **关联**：本文的"环节弹性梯度"直接解释了 21 号文档 §5 的量拐门产品级分化
> （电芯量价同动受益、材料金额领先量滞后受害）。

---

## 1. 结论速览

1. 电芯是"低波动成长"，材料是"高弹性放大器"（振幅差 2~3 倍）；
2. 全产业链**同周期、强耦合**，无独立环节行情；
3. 复苏顺序分化：铜箔 → 电芯 → 正极 → 电解液依次转正，**负极长期掉队**；
4. 电芯"量价同动"、材料"价驱动"频现，决定量拐门在环节间的分化。

## 2. 环节弹性梯度（数据事实）

| 环节 | 产品键 | 2020-2026 金额 yoy 振幅 |
| :-- | :-- | :-- |
| 电芯 | battery | −17% ~ +96% |
| 电解液 | electrolyte_salt | −46% ~ +219% |
| 正极 | cathode_material | −65% ~ +272% |
| 铜箔 | battery_copper_foil | −19% ~ +128% |

**机制推断**：材料是"量 × 价"中"价"弹性更大的上游（锂盐、六氟磷酸锂、铜价），
景气上行暴涨更猛、下行跌得更深，呈典型的"上游放大器"结构。

## 3. 同周期传导（一条腿）

七个环节走同一轮周期：

- `2021-2022` 高景气（几乎全部量价齐升）；
- `2023` 见顶回落（电芯仍扛，材料先转负）；
- `2024` 深度调整（材料深负，电芯转负）；
- `2025` 复苏（电芯、铜箔、正极陆续转正）；
- `2026` 二次扩张（电芯 +55%，铜箔 +128%、电解液 +85%）。

## 4. 复苏顺序（领先-滞后，数据事实）

| 环节 | 转正时点 | 2026-06 yoy |
| :-- | :-- | :-- |
| 铜箔 | 2024-09（+27%） | +128% |
| 电芯 | 2024-12（+6%） | +33% |
| 正极 | 2025-03（+2.6%） | +96% |
| 电解液 | 2026-03（+85%） | +71% |
| 负极 | **至今未转正** | **−17%** |

- 铜箔最早（跟铜价/新能源车量），电芯次之，材料弹性大但启动晚、起来后冲得猛；
- **负极（石墨）是本轮唯一掉队环节**——`2023-09` 转负后一路负到 `2026-06`，
  提示结构性过剩/价格战，不随本轮复苏修复。

## 5. 与量拐门分化的呼应

电芯大部分时间"量价齐升"（量价同动），电解液/正极频繁"价驱动"（价格弹性主导、
量滞后）——解释 21 号文档 §5 的分化：

- 电芯量拐门受益（量价同动，筛伪景气代价小）；
- 材料量拐门受害（金额领先量滞后，晚进场少赚）——battery_copper_foil −8.6pp、
  cathode_precursor −8.5pp、electrolyte_salt −9.9pp 的负 delta 更典型。

## 6. 量价能推什么/不能推什么（方法论边界）

从锂电案例外推到一般方法：出口量价分离能推什么、不能推什么。

### 6.1 能推的（结构规律 + 需求端量的真实性）

1. 环节间关系：同步性、领先-滞后、弹性梯度、掉队环节（本文 §2~§4）；
2. 需求端"量"的真实性：量价齐升（量价同动）/ 量驱动（量真扩张价没跟）/ 价驱动（价撑、量未确认）；
3. 前瞻拐点：量拐、二阶导。

### 6.2 不能单靠量价推的（终审层）

1. **价驱动 ≠ 假景气**：battery 2020 年初价驱动是"真涨前奏"（量滞后 5 月），transformer
   2022 年初价驱动才是伪景气（量没动、金额转负）——同样是价驱动，光看量价分不出真假；
2. **量价齐升 ≠ 保证真成长**：量的扩张能否落成利润要财报毛利率/净利率坐实（负极掉队是
   量价提示，成因需财报佐证）；
3. **21 号文档已证伪**：`mode=价驱动` 作真假景气分类轴不可用，量价自动分类这条路部分走不通。

### 6.3 定位

量价是"即时质量检验"，财报是"终审"——对应 METHODOLOGY_COMPANY_FINAL §5.5 三层信号判读
（f1 入场券 / 质量门即时检验 / f3 财报后视终审）。量价管"量是不是真动"，财报管"动得
赚不赚钱"，两者合起来才是完整判定。

## 7. 诚实局限

1. 本文化用**产品主段金额 yoy**做环节对比，未做量价分离（各环节"价"的弹性来源不同：
   锂盐/六氟磷酸锂是商品价格，铜箔是铜价 + 加工费，不能直接比价弹性大小）；
2. "上游放大器""结构性过剩"是机制推断，需财报毛利率/产能利用率佐证，本文未展开；
3. 环节转正顺序基于季度抽样（3/6/9/12 月），月内拐点可能略有前移/后移。

uv run python - <<'PY'
import polars as pl
pv = pl.read_parquet("data/analytics/industry/customs_product_volume_price.parquet")
prods = ["battery","cathode_material","anode_material","electrolyte_salt",
         "battery_copper_foil","battery_separator","battery_aluminum_foil"]
for p in prods:
    s = (pv.filter(pl.col("product_key")==p)
         .select(["report_month","value_yoy_3mma","驱动类型"]).sort("report_month"))
    print(p, s.tail(3).to_pandas().to_dict("records"))
PY
