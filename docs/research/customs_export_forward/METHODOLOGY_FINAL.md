# 申万行业 × 海关出口 景气研究方法论定稿（v1）

> **定位：唯一权威方法论**。本文档取代 00-11 系列中的探索性内容，后续一切实现、
> 面板与报告一律按本文档口径执行。系列文档仅保留为证据出处，不再作为方法论源。
>
> **核心一句话**：研究**商品量价拐点**（量最领先、价确认、金额合成），量价驱动
> **申万二级/三级行业景气度变化**，财报 TTM 只作**后视验证**。
>
> **三大正确原则（强制）**：① 数据无前视（§6）；② 量化无过拟合（§5.1）；
> ③ 量价关系优先（量领先价确认金额合成，§2）。其余一律从简。
>
> **已排除（不实现）**：方向分（`direction_score`/`global_resonance_l2_map`）、
> price 腿合成总分、方向防守门、单腿资金吸筹——均为已证伪或零预测力信号，见 §5。

## 1. 核心命题

1. **海关出口（月频，T+20 发布）是行业基本面前瞻代理**，机制性领先财报 1-2 季度
   （出口 3MMA yoy 拐点领先财报 TTM 拐点 3-13 个月，中位 3-9 个月）。
2. **金额 = 量 × 价，三条序列分开研究**：
   - **量（数量 yoy）= 最领先变量**：量增速见顶领先股价顶 4-11 个月、
     量转负领先财报转负约 14 个月；
   - **价（ASP yoy）= 弹性确认腿**：价格底（ASP 转正/跌幅收窄）是底部二阶导信号；
   - **金额（= 量价合成）= 主口径**，但对 21 个价格主导行业标注"价格污染"。
3. **行业景气度由出口量价驱动**——研究"量价驱动类型"（量价齐升/量驱动/价驱动/双弱）
   与"量价拐点时序"（二阶导），不作方向分等合成打分。
4. **财报 TTM（量价齐升）只作后视验证**：不参与前瞻选股，只回答"供需逻辑是否兑现"。
   出口前瞻的是**营收方向**，不是盈利方向，更不是股价。

## 2. 信号定义（唯一口径）

### 2.1 三条序列（全部 3MMA yoy，hs8 同码桥接、跨源统一重算）

```
金额 yoy = v3mma / v3mma_lag12 − 1
量   yoy = q3mma / q3mma_lag12 − 1     # 仅 volume_aggregable=True 产品参与
价   yoy = asp3mma / asp3mma_lag12 − 1  # asp3mma = v3mma / q3mma
```

无前视要点：
- 按 hs8 码补全完整月序后统一重算（缺月置 null 不填 0，区分真实缺失）；
- 跨源（Comtrade 2024 → GACC 2025）不做分源分段计算，避免 2025 全年同比缺失；
- 数量跨 HS 混用单位（半导体设备/PCB/etc.）置空，不得参与行业聚合。

### 2.2 驱动类型四象限（当前状态分类）

| 驱动类型 | 量 yoy | 价 yoy | 含义 |
| :--- | :--- | :--- | :--- |
| 量价齐升 | >0 | >0 | 量价双扩，最健康 |
| 量驱动 | >0 | ≤0 | 放量降价（需求启动/价格战） |
| 价驱动 | ≤0 | >0 | 量歇价升（顶部前兆/供给收缩涨价） |
| 双弱 | ≤0 | ≤0 | 量价齐跌（衰退/出清） |

### 2.3 拐点与二阶导（研究重心）

- **拐点（一阶导符号翻转）**：金额 3MMA yoy 由负转正 = 景气启动；
  由正转负 = 见顶/退出。
- **二阶导 = 量增速方向**（择时看二阶导、确认看一阶导）：
  | 结构 | 判定 | 处置 |
  | :--- | :--- | :--- |
  | 底部 | 量先转正、价跌幅收窄 | 前瞻候选池 |
  | 主升 | 量价齐升持续（一阶导水平） | 持有，二阶导定节奏 |
  | **顶部前兆** | **量增速见顶回落 / 量转负** | 减仓观察 |
  | **最危险组合** | **量回落 × 财报仍加速** | 历史 6m 中位 −7.9%，离场触发 |
  | 衰退 | 金额转负 + 量价双弱 | 回避 |

### 2.4 方向一致率分级（出口→财报方向可预测性）

| 分级 | 一致率 | 行业数 | 用途 |
| :--- | :--- | :--- | :--- |
| A 可靠前瞻 | ≥0.85 | 6（电网设备/炼化/光伏/焦炭/电池/半导体） | 出口读数可直接推断财报方向 |
| B 可用参考 | 0.62-0.77 | 22 | 出口有参考价值，需结合其他信号 |
| C 弱/无效 | ≤0.58 | 12（通信/消费电子/家居/特钢/风电等） | 映射代表性不足，**出口不作前瞻判断** |

> 2026-09 审计勘误：行业数由旧口径"B 19 / C 15"更正为 **B 22 / C 12**
> （以 02 文档 §2 全表为准，此前 §1 摘要沿用 9-14 主表合并前旧数）。
> 共 40 行业；其中厨卫电器（0.38，C 级）在 catalog 无产品映射，观察表不出现该行。

## 4. 财报后视验证规则

```
量价齐升型（需求驱动）: 营收 TTM 转正 AND 净利 TTM 转正 → 适用出口框架，三腿验证合格
毛利率扩张型（成本/价差驱动）: 营收未转正 + 净利转正 + 毛利率抬升 → 不适用出口框架
```

- **价格主导行业（21 个，金额yoy×量yoy corr<0.5）**：金额上涨可能纯由价格驱动，
  不构成需求拐点，一致率结论打折；
- **国内供需定价行业（光伏/电池/乘用车）**：出口只有"量"的语义，出口回升 ≠ 盈利
  回升（重资产低门槛、价格战），财报兑现另看产能利用率与价格企稳；
- **机制校验优先于统计**：炼化一致率 1.0 是油价周期伪相关（油价同时推高出口金额
  与炼化利润），正确信号是裂解价差，不是海关出口。

### 5.1 量化无过拟合（强制）

1. **样本外验证**：任何新信号/规则必须用 **2022-01 之后样本外** 检验
   （对齐国泰海通拆分），不拿全样本刷参数（04 文档反例：分析师预期样本内 0.47、
   样本外 0.15）；
2. **基线对照**：新信号的有效性 = 超越基线（16 行业方向池裸动量全周期 +5.42%、
   样本外 Sharpe 0.18）的增量，不单独看自身收益；
3. **单次循环不宣称规律**：光伏产能周期仅一次实现（2019-21 上行 vs 2022-24 过剩），
   跨相位无法同截面验证，结论标注"待 2026+ 二轮循环二次确认"；
4. **事件研究基准对照**：信号收益必须对照同期市场行业中位（超额口径），不比较
   绝对收益；样本量小的结论标注置信区间（三腿共振 27 事件置信区间较宽）；
5. **最小参数原则**：阈值（如拐点窗口 ±3 月、分位窗口 36 个月）来自机制或
   官方口径，不从历史数据反推拟合；
6. **分年度稳健性**：跨年度结论需列出分年度表现，避免依赖特定市场结构
   （如 2020 后注册制/量化时代与 2015 牛市结论相反）。

## 6. 无前视铁律（实现强制）

1. 腿1 拐点有效窗口 **[T+1, T+3]**（GACC 月度 T+20 发布，T+1 为发布滞后缓冲）；
2. 腿2 当日收盘判定，收益自**次日**起算（T+1 执行）；
3. 腿3 财报只可见已披露报告期（`eff_date`/`reportDate` 前向填充 join_asof）；
4. **假拐点过滤**：信号月 yoy ≥ 0（拐点后再次转负的行业剔除）；
5. 拐点判定只用历史：3MMA yoy 由负转正（prev<0 且 ≥0），不依赖未来值。

## 6.5 行业桥接强制规则（L2/L3，2026-09 审计后定稿）

> 桥接正确性是研究生命线：海关 HS 商品 → 申万 L2/L3 行业的映射错一处，
> 行业级量价景气结论即失真。以下规则与审计结果为**强制要求**，新脚本必须内置校验。

### 桥接链路（唯一信任源）


### 审计结论（2026-09，必须随新脚本复检）

| 检查项 | 结果 | 规则 |
| :--- | :--- | :--- |
| catalog L2 唯一码存在性 | 43 唯一码，**42 存在**；1 个缺失 = 组合码 `801033.SI;801034.SI` | 组合码按多映射处理，不入行业主表 |
| catalog L3 唯一码存在性 | **73/73 全部存在，0 缺失，0 空值** | L3 桥接健康 |

### 强制规则

1. **映射只在 `hs_codes_catalog.csv` 维护**，raw 不存映射；修复映射只改 catalog +
   重刷 curated，不追溯 raw。
2. **指数码 ↔ 行业码桥接一律走 `sw_2021_industry_dimension` 黄金表**
   （`index_code ↔ industry_code ↔ parent_code`），禁止手工名称/代码猜匹配。
3. **L3 归属校验**：脚本内置断言 `parent_code == 该行 L2 industry_code`，
   不一致即报错，不静默产出。
4. **组合码（`;` 分隔的多映射行）在行业聚合中跳过**（如 `801033.SI;801034.SI`
   化学原料;化学制品 与 `tio2`），报告披露被跳过产品与规模，不抹入单行业。
5. **空映射行**：L2/L3 映射任一为空的产品行，行业级面板中剔除并在报告标注
   （catalog 当前 L3 无空值，规则作为防御）。
6. **复用校验函数**：`stock_data.fetcher.industry.customs.parsers.catalog` 或
   `.agents/skills/customs-industry-prosperity/scripts/build_customs_export_prosperity.py`
   的 bridge/join 逻辑不在新脚本中复制，统一 import（防口径漂移）。
