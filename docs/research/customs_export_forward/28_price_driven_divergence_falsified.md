# 28 量价背离深度分类轴证伪 + 对齐后量拐门 delta 为噪声（2026-09）

> **性质**：接 24 号 §5 的机制假设，验证「量价背离深度」（价驱动阶段的量跌深度 × 价涨
> 幅度）能否预测产品级量拐门 delta（quality − base）。结果是**证伪**，并引出一个更根本的
> 收敛结论：**对齐后量拐门的产品级 delta 本身是采样噪声，不存在可预测的分类轴**。
> §8.5「产品级细分质量门」方向因此**关闭**（不再是"缺分类轴"，而是"前提不成立"）。
>
> **数据底座**：出口量价序列 `customs_product_volume_price.parquet`（产品主段）；量拐门
> delta 取自 `customs_signal_multi_fullpool_aligned.parquet`（108 产品 × base/quality/quality_filter，
> 对齐后口径，见 26 号文档）。

---

## 1. 结论速览

1. **量价背离深度分类轴证伪**：背离度、价涨幅度、量跌深度与对齐后 delta 的 Pearson
   相关均 ≈ 0（+0.03、+0.03、+0.05），分组无区分度；
2. **更根本的收敛**：对齐后量拐门 delta 是**采样噪声**——均值 −0.04、中位 0、std 3.82、
   单样本 t=−0.10（不显著）、bootstrap 95% CI [−0.80, +0.65] 含 0、正负对半（36 受益 /
   33 受害 / 39 零）；
3. **噪声来源**：|delta| 与轮次数负相关（−0.31）——13 个 |delta|>5pp 的产品全是轮次少
   （3~7 轮）的；轮次足够（≥4 轮）的 98 个产品 |delta| 中位仅 **0.59pp**；
4. **对 §8.5 的修正**：前视口径下的「产品级分化真实存在」（21 号 §5：89 产品仅 37% 更优）
   在消除前视后消失——那条分化是「量拐门提前 1 个月抓拐点」的前视伪影，不是可预测的
   产品级结构。§8.5 方向关闭。

## 2. 研究动机与假设（24 号 §5）

24 号 §5 用前视口径给出机制：量拐门受害/受益取决于「价驱动阶段的性质」——

- battery（前视受害 −20.8pp）：量浅跌 −11~−18%、价温和涨 +22~35%（真涨前奏，量 5 个月后
  转正，量拐门白等）；
- transformer（前视受益 +12.7pp）：量深崩 −56%、价暴涨 +125%（段结构升级假象，量不转正，
  量拐门躲过）。

据此假设：**「量价背离深度」= 价驱动阶段（价 yoy>0 且量 yoy<0）的价涨幅度 × 量跌深度，
可预测量拐门 delta**——低背离受害、高背离受益。

## 3. 特征构造

每产品取主段（金额最大段）量价序列，价驱动月 = `price_yoy_3mma>0 且 volume_yoy_3mma<0`，
提取：

- `max_price` = 价驱动月内 max(price_yoy_3mma)（价涨幅度）；
- `min_vol` = 价驱动月内 min(volume_yoy_3mma)（量跌深度，负值）；
- `divergence` = max_price × (−min_vol)（背离度）；
- `n_pd` / `pd_ratio` = 价驱动月数 / 占比（备选特征）。

## 4. 验证结果：背离度与 delta 零相关

对 108 产品（对齐后 delta 非空），特征 vs delta 的 Pearson / Spearman：

| 特征 | Pearson | Spearman |
| :-- | :-- | :-- |
| 背离度 divergence | +0.03 | +0.09 |
| 价涨幅度 max_price | +0.03 | +0.07 |
| 量跌深度 min_vol | +0.05 | −0.13 |
| 价驱动月数 n_pd | +0.15 | +0.20 |

分组（按背离度中位 0.14 切）：高背离组 delta 均值 −0.36、低背离组 +0.29——无区分度
（且都接近 0）。轮次足够（≥4 轮）的 98 产品子集内，背离度 vs delta 仍仅 +0.03。

**关键案例**（背离度相差 100 倍、delta 却同号）：

| 产品 | 背离度 | max 价涨 | 对齐后 delta |
| :-- | :-- | :-- | :-- |
| battery | 0.24 | +1.13（温和） | **−6.38pp** |
| transformer | 28.04 | +29.35（暴涨） | **−5.19pp** |

前视口径下两者一受害一受益（−20.8 vs +12.7），对齐后**双双受害且幅度相近**——背离度
完全无法区分。transformer 前视的「受益」正是量拐门提前抓拐点的伪影，消除后消失。

## 5. 更根本的收敛：对齐后 delta 是噪声

| 判据 | 数值 | 含义 |
| :-- | :-- | :-- |
| 均值 / 中位 | −0.04 / 0.00 | 全池平均中性（26 号 §4 已述） |
| std | 3.82 | 波动来自少数产品 |
| 单样本 t | −0.10 | 不显著异于 0 |
| bootstrap 95% CI | [−0.80, +0.65] | 含 0 |
| 正负分布 | 36 受益 / 33 受害 / 39 零 | 对半分 |
| corr(|delta|, 轮次数) | −0.31 | delta 极端来自轮次少 |
| ≥4 轮产品 |delta| 中位 | 0.59pp | 有足够样本时 delta≈0 |

13 个 |delta|>5pp 的产品全部 n_base≤7 轮（bev 5 轮 −25.3pp、wind_parts 5 轮 +13.4pp 等），
是少数几轮交易的随机波动，非稳定产品级结构。

## 6. 对 §8.5 的修正（方向关闭）

§8.5 的前提是「量拐门产品级分化真实存在（成长组 89 产品仅 37% 更优）」，该数字来自
21 号 §5 **前视口径**。消除发布时滞前视后：

- 全池 delta 均值 −0.04、逐产品中位 0、有足够轮次的产品 |delta|≈0.6pp——**分化是噪声**；
- 因此「按产品细分质量门」方向的前提（存在可预测的产品级 delta 信号）不成立，**关闭**；
- 已排除的三条候选轴（`mode=价驱动` 21 号 §6、量价结构占比 24 号 §4、量价背离深度本文）
  之所以都失败，根因不是"轴没找对"，而是**对齐后根本没有稳定的产品级 delta 可被预测**。

## 7. 诚实边界

1. delta 取自等权、月度、无成本的回测口径，绝对超额对时滞敏感（26 号 §6）；本文结论
   「delta 是噪声」对该口径内成立；
2. 背离度只用「价驱动月」的极值（max/min），未用阶段时变、段金额占比时变等更细特征，
   但极值是最直接的「背离深度」定义，若连极值都零相关，更细变体预计无望（§8.5 其余
   候选轴同样弱）；
3. n_pd/pd_ratio 有微弱正相关（+0.15/+0.20），方向是「价驱动越多 delta 越正」，但幅度
   不足以构成可交易门，且与 §8.5 结论（量拐门中性）一致，不单独成轴。
