# 31 高分化产品筛查与段内排名扩展验证（2026-09）

> **性质**：把 30 号「段内景气排名仅 transformer 有效」向外扩展——对全池无段定义产品做
> 高分化候选筛查，找出第二、第三个「段结构分化」产品并验证段内排名。核心结论：
> **段内排名的有效前提是「税号按同一物理属性轴分层 + 段间金额占比均衡 + 低端→高端
> 结构切换」**，auto_drive_motor（功率分层）是继 transformer 后的第二个验证有效产品；
> server（机型分层但微型机占 96%）无效。并提炼出一个独立前瞻信号：**结构升级信号**。
>
> **数据底座**：GACC 黄金表 `customs_trade_gacc.parquet`（8 位税号行级）算产品内 HS 税号
> 单价离散度与段级 3MMA yoy；回测复用 30 号动态段内排名口径（对齐后 base、同一受益公司池）。

---

## 1. 结论速览

1. **真高分化 ≠ 单价差大**：单价离散度 Top 候选里，多数是「品类异质」（CT/超声/心电图、
   片仔癀/普通药）或「catalog 污染」（磷化物/蒸馏水混入），真正的段结构分化是**税号按
   同一物理属性轴分层**（功率/容量/机型/载重/尺寸）；
2. **auto_drive_motor（功率分层）段内排名有效**：动态排名 +15.7pp vs 产品级 +10.9pp
   （+4.8pp），固定 mid 段 +19.5pp 最优——是继 transformer 后的第二个验证案例；
3. **server（机型分层）无效**：微型机段稳定占 92~97%，产品级聚合就是微型机本身，无段间
   扭曲，动态排名反引入换段噪声（+5.1pp < 产品级 +6.1pp）——从候选剔除；
4. **有效前提 = 段间占比均衡 + 结构切换**：transformer（ultra 段占比飙升）、auto_drive_motor
   （large 段 10%→18%）都有「低端→高端」结构切换；server（micro 段稳定 96%）没有；
5. **结构升级机制（非独立前瞻因子）**：高单价段金额占比持续上升 = 出口竞争力向中高端
   跃迁的**机制**，解释了段内排名的有效性；但时序验证（2026-09）显示它**无独立前瞻性**
   （对财报毛利率 corr≈0、对未来股价 IC≈0），见 §5。

## 2. 高分化候选筛查（单价离散度 + 真/假判定）

对 51 个可比候选（单位一致 + 税号≥3 + 排除快周期/出口非主导），按产品内 HS 税号单价
p90/p10 排序，再按税号 `hs_name` 判定「同一物理轴分层 vs 品类异质/污染」：

| 候选 | p90/p10 | 税号结构 | 判定 |
| :-- | :-- | :-- | :-- |
| medical_device | 6575x | CT/超声/心电图 | 品类异质 ✗ |
| cathode_precursor | 1131x | 混入磷化物/蒸馏水 | catalog 污染 ✗ |
| pharma_chemicals | 648x | 片仔癀/安宫/普通药 | 品类异质 ✗ |
| **auto_drive_motor** | 85x | **按输出功率**（≤750W/750W-75kW/>75kW） | **真分层 ✓** |
| furniture | 68x | 红木/金属 | 品类异质 ✗ |
| **server** | 57x | 按机型（巨型/大型/小型/微型） | 分层但占比失衡（见 §4） |
| flat_panel_module | 53x | OLED电视/车载/监视器 | 品类异质 ✗ |

另有次优先真分层候选（均有保留）：shipbuilding（载重分层，强周期装备）、washing_machine
（干衣量分层，单价分化弱）、polysilicon（硅棒直径分层，光伏上游出口非主导）。

## 3. auto_drive_motor 验证（有效）

段定义按 HS 输出功率三档：small（≤750W）、mid（750W-75kW）、large（>75kW）。受益公司
精进电动/方正电机/大洋电机/卧龙电驱/汇川技术等权，对齐后 base：

| 信号 | 超额 | 轮次 |
| :-- | :-- | :-- |
| 固定产品级 | +10.9pp | 6 |
| 固定 small | +17.4pp | 5 |
| 固定 mid | +19.5pp | 6 |
| 固定 large | +10.8pp | 5 |
| **动态段内排名** | **+15.7pp** | 5 |

动态排名 +15.7pp 优于产品级 +10.9pp（+4.8pp），接近固定 mid（事后最优 +19.5pp）。机制与
transformer 同构：large 段（>75kW，新能源车驱动电机）金额占比 2020→2025 从 10% 翻到 18%
（小电机→大电机的结构升级），产品级聚合被高单价大电机段的景气波动带偏，段内排名能动态
选到当期景气最好的段。

## 4. server 验证（无效，剔除）

段定义按机型：micro（微型）、mini（小型）、big（巨型/其他）。受益公司浪潮信息/中科曙光/
工业富联/紫光股份等权：

| 信号 | 超额 | 轮次 |
| :-- | :-- | :-- |
| 固定产品级 | +6.1pp | 5 |
| 固定 micro | +5.2pp | 5 |
| 固定 mini / big | +3.7pp | 5~6 |
| 动态段内排名 | +5.1pp | 10 |

micro 段稳定占 92~97%，产品级聚合 ≈ micro 段，无段间扭曲、无结构切换。server 的「单价
离散度高」是假象——巨型机单价 6.5 万是微型机 110 倍，但金额占比仅 0.07%，不影响产品级。
段内排名选 mini/big 段等于选小样本噪声段，反而引入换段噪声。

## 5. 结构升级机制（时序验证：非独立前瞻因子）

**机制（成立）**：产品内高单价段（高技术/高附加值）金额占比持续上升 = 出口竞争力从
「低端走量」向「中高端跃迁」。这是段内排名有效的**机制解释**，实证锚 auto_drive_motor
的 large 段（新能源车驱动电机，10%→18%）、transformer 的 ultra 段（特高压）都是
「中高端跃迁」实例，对绑定高单价段的公司是长期推动力（产品升级 → 竞争力 → 成长）。

**时序验证（2026-09，未通过前瞻性）**：把「结构升级」量化为两个指标——均价 yoy（金额
加权均价 3MMA 同比，混通胀）与高单价段金额占比的 yoy 变化（纯结构），分别对财报毛利率
和未来股价超额做前瞻检验：

| 验证链 | 指标 | 结果 |
| :-- | :-- | :-- |
| → 财报毛利率 Δ（行业层逐序列领先-滞后） | 均价 yoy | 峰值 k=0 同步 +0.088，不领先 |
| → 财报毛利率 Δ | 高单价段占比变化 | 全程 ≈ 0（+0.005~+0.048），无峰值 |
| → 未来股价超额（横截面 IC） | 均价 yoy | 未来 3/6/12 月 IC = +0.001/−0.002/−0.011 |

结论：**结构升级是「择时机制前提」，不是「独立横截面前瞻因子」**——它能解释「为什么
段内排名在 transformer/auto_drive_motor 有效」，但无法单独预测「哪些产品/公司未来财报
或股价更好」（IC≈0、corr≈0）。可能的机制原因：结构升级是低频慢变量、传导链长（出口
结构→公司产品结构→定价权→毛利→股价）、且信息可能已被市场定价。

**落地修正**：不把「高单价段占比变化」作为腿1 的独立前瞻因子使用；其价值限定在**段内
排名的有效性判据**（判断某产品是否值得分段择时），而非横截面选股/选池因子。

## 6. 诚实边界

1. 有效样本仍只有 2 个（transformer、auto_drive_motor），shipbuilding/washing_machine/
   polysilicon 未验证（分别受周期品/分化弱/出口非主导限制），「判据」是方向性发现非统计；
2. 段定义依赖 HS 码的物理属性档，部分产品税号不按单一轴分层（品类混搭），无法套用；
3. 结构升级已做时序验证（2026-09）：对财报毛利率 corr≈0、对未来股价超额 IC≈0，**非独立
   前瞻因子**——机制成立（解释段内排名）但无横截面预测力，见 §5；
4. 动态排名仍受 30 号 §7 的「低基数误选」「换段噪声」限制。
