## 3. 分级结论

### A 级（≥0.85）：出口是可靠前瞻
- **共性**：出口占行业营收比高、映射产品代表性强（整机/大宗/组件出口直接构成行业收入）。
- 典型：电网设备（变压器 100%）、炼化及贸易（成品油/化工品 100%）、电池（6 月领先）、
  光伏设备（9 月领先——组件出口是行业最直接的外需代理）、半导体（3 月领先）、焦炭Ⅱ。

### C 级（≤0.58）：出口对该行业财报无前瞻价值
- **共性**：出口占比低，或映射产品只是行业收入一小部分，或出口与国内财报驱动脱节。
- 通信设备（0.42）：映射仅光模块，行业收入还含国内运营商设备、手机等——映射代表性不足；
- 消费电子（0.42）：映射手机/笔电出口，但行业收入大头是国内整机代工+零部件内销；
- 家居用品/厨卫电器/特钢/风电设备：出口占收入比低，外需不是行业基本面主导。
- **工业金属（0.46，C 级）**：GACC 合入后出口刷新到 2026-07 +113%（铜/铝出口高增），
  但历史一致率仅 0.46——工业金属价格由全球定价、国内供需双重驱动，出口量价与 A 股行业财报
  （含冶炼加工费、内需）脱节；出口高增可作为"全球需求"参考，不能直接推断财报方向。

## 4. 修复影响说明（2026-09）

- **9-13 映射修复**：修复 7 处 L2 行业错配（挖掘机/叉车/电动工具/扫地机器人/农药代码错配 +
  MDI/制冷剂名称错配），矩阵 42 → 40 行业；工程机械 0.85 → 0.46、小家电 0.92 → 0.54
  （此前高一致率部分来自错误映射）。详见 04 文档。
- **9-14 主表合并**：GACC 24 → 41 个产品并入主表后，工业金属 0.65 → 0.46、风电设备 0.62 → 0.31、
  商用车 0.62（滞后 9→3 月）——近端序列完整后一致率整体更保守可信。
