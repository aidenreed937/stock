# 01 方法论：海关出口 → 行业财报 关联验证

## 1. 数据链路（映射血缘）

```
UN Comtrade API / GACC CSV (raw, 纯原始数据, 无行业映射)
        │  fetcher 入库时从 catalog join（src/stock_data/fetcher/industry/customs/catalog.py）
        ▼
hs_codes_catalog.csv (config/data/customs/)  ← 行业映射唯一信任源
        │  按 hs_code（8 位完整 + 6 位前缀双向索引）
        ▼
data/curated/industry/customs_trade.parquet  ← 黄金事实表（含 target_l1/l2/l3 映射列）
        │  target_l2_codes（如 801735.SI）↔ 维度黄金表 index_code（6 位行业码 630500 ↔ 801735.SI）
        ▼
sw_2021_l2_fs_non_financial（理杏仁 L2 财报 TTM 营收/净利 yoy、毛利率）
```

关键点：
- **raw 不含行业映射**：映射是入库时从 catalog 写入 curated 的；修复映射只需改 catalog + 重刷 curated，raw 不用动。
- **6 位 ↔ 8 位（现状）**：`customs_trade.parquet` 的 Comtrade 段（2016-2024）已并入 8 位子目
  tariffline 数据（632 码、108 产品，raw 源 `data/raw/industry/customs/comtrade_tariffline/`），
  与 GACC 8 位码做同码桥接（hs8 出口层 640 码，both 交集 564）；仅 Comtrade 早期 6 位段
  （197 码）不参与 hs8 桥接面板。2026-09-08 catalog 码对齐后，8 位细分精度缺口残留 29 码
  （catalog 277 个 hs8 细分中 248 个已有自身 8 位数据，其中 23 个旧父级码的产品数据已由
  现行细分补齐、6 个 870370 细分属官方无出口记录）。
- **行业代码格式**：海关表用指数代码（801735.SI），理杏仁财报用 6 位行业码（630500）；两者通过
  `sw_2021_industry_dimension_golden`（`load_sw_2021_industry_dimension(level="L2")`）的
  `industry_code ↔ index_code` 映射桥接。

## 2. 产品去重与版本桥接

- **产品主 HS 选择**：同一产品可能对应多个 HS（如光伏 854140→854143 版本迁移、组件多子目）。
  对每个 (product, 月)，取该月存在的 HS 中"最新仍在更新"的现行码（`hs_max_ym` 最大者），
  避免：① 同一产品多 HS 重复计数；② 覆盖最长主 HS 策略丢失版本迁移后的新码与 GACC 2025+ 数据。
- **版本迁移边界**：HS2017 / HS2022 版新增编码（面板 8524xx、光伏 854143、手机 851714、HEV 870370 等）
  只有新版本年份有数据，跨码合并才能覆盖全周期（如正极前驱体 285300(2016) + 285390(2017+)）。

## 3. 行业出口指数与 3MMA YoY

1. 按 (月, target_l2_codes) 聚合产品出口额（主 HS 去重后求和）。
2. 3 个月滚动均值（`rolling_mean(3)`），对 12 个月前滚动均值算 YoY：
   `ind_yoy_3mma = (mma3 / mma3_lag12 - 1) × 100`。
3. 与单产品口径一致（`yoy_growth_3mma` 字段同规则）。

## 4. 关联验证：两个互补检验

### 4.1 拐点对齐（符号翻转时间差）

- 拐点 = 3MMA YoY / 财报 TTM yoy 的**符号翻转**（负→正 +1，正→负 -1）。
- 对每个财报拐点，找 2 年内最近的前置出口拐点，同向对齐，计算时间差（月）。
- 输出：中位领先月数 + 范围。**避免单调趋势伪相关**：不比较原始序列相关性（趋势序列交叉相关
  会产生 lag -2 季度 r=0.55 / lag +2 季度 r=-0.85 这类伪影），只比较拐点先后与同向性。

### 4.2 方向一致率（滞后 k 月符号匹配）

- 财报 TTM yoy 符号 vs 滞后 k 个月（3/6/9）出口 yoy 符号，一致比例。
- 财报日期用 `report_date`（公告日）对齐；出口取滞后 k 个月的当月末值（`join_asof backward`）。
- 解读：一致率随 k 增大而升 → 出口领先；一致率在 k=3 最高 → 同步/滞后。

## 5. 口径与陷阱清单

| 陷阱 | 说明 |
| :--- | :--- |
| 趋势伪相关 | 两个单调增长序列交叉相关必有"领先/滞后"假象；必须用拐点对齐+方向一致率 |
| 出口占比 | 出口占行业营收比低的行业（通用设备/厨卫/家居），一致率差是正常的 |
| 映射代表性 | 通信设备出口映射只有光模块，不能代表行业全貌（一致率仅 0.42） |
| 盈利 vs 营收 | 出口前瞻的是营收方向；净利还受价格/成本/产能利用率影响，光伏是反例 |
| **国内供需定价** | **出口只有"量"的语义：若行业价格由国内供需决定（光伏/电池/乘用车——重资产低门槛、玩家多、供给国内占大头），出口回升不等于盈利回升，财报兑现需另看价格战与产能利用率** |
| GACC 覆盖 | 2025+ 已并入 41 个重点产品；贵金属/煤炭/焦炭/炼化等仍止于 2024-12，近端解读须标注 |
| 版本迁移 | 面板/光伏组件/手机等 2022 版新码只有 2022+ 数据；跨码合并才完整 |
