# 22 交易模拟演练（2020-2026 复盘：等权回测 vs 实战选池）

> **性质**：本文是操作层复盘演练，把定稿择时规则翻译成"某月该做什么"的可执行叙事，
> 并记录**回测口径与实战选池的边界**。不新增结论，方法论口径仍以
> [`METHODOLOGY_COMPANY_FINAL.md`](METHODOLOGY_COMPANY_FINAL.md) 为唯一权威。
>
> **数据口径**：GACC 黄金表 2019-01~2026-08，受益公司等权 vs 沪深300，无未来函数。
> 复现 `scripts/backtest_customs_multi.py --detail` + `customs_product_volume_price.parquet`。

## 1. 决策框架（当前可用口径，一句话）

- **建仓**：产品出口 3MMA yoy 连续 2 月 >0，且量 yoy>0（量拐，即量价齐升/量驱动）→ 分 3 批建仓（每月 1/3）；
- **减仓**：满仓后 yoy 连续 2 月环比下降（见顶回落）→ 减半（可再加回）；
- **清仓**：yoy≤0（只看金额，量信号不管离场）；
- **排除**：快周期商品（铜/锂/银）不参与；竞争力过滤（--quality-filter）作同产品选股精化层，不作全池强制门。

## 3. 时间线复盘

### 3.1 battery（量拐门代价：金额领先、量滞后）

| 月份 | 金额 yoy | 驱动 | 操作 |
| :-- | :-- | :-- | :-- |
| 2020-03 | +6.2% | 价驱动 | 量没跟，不入场 |
| 2020-04~07 | +3.9%~+14% | 仍价驱动 | 继续等 |
| 2020-08 | +16.4% | 量价齐升 | 量拐第 1 月 |
| 2020-09 | +28.5% | 量价齐升 | 连续 2 月 → 建仓 1/3 |
| 2020-10~11 | +33%~+38% | 量价齐升 | 加到满仓 |
| 2023-12 | +2.5% | 量价齐升 | 从 +110% 一路回落，见顶反复减半加回 |
| 2024-01 | −5.8% | 量驱动 | **yoy≤0 清仓**，第一轮结束 |

- 轮 1（2020-09 ~ 2024-01，40 月）：+14.5%，超额 +43.3pp；
- 轮 2（2025-01 ~ 2026-08，13 月）：+21.6%，超额 +13.2pp；
- **代价**：无门版 2020-04 即入场，轮 1 +78.0%、超额 +84.9pp——量拐门晚 5 个月，少赚约 60pp。

### 3.2 transformer（量拐门收益：价驱动是伪景气）

| 月份 | 金额 yoy | 驱动 | 操作 |
| :-- | :-- | :-- | :-- |
| 2022-01 | +26.5% | 价驱动 | 量没跟，不入场 |
| 2022-06 | −0.26% | 价驱动 | （无门版在此亏损清仓） |
| 2022-09 | +84.0% | 量驱动 | 量拐第 1 月 |
| 2022-10 | +71.2% | 量驱动 | 连续 2 月 → 建仓 |
| 2023-05 | +110.8% | 价驱动 | 主升段持有中 |

- 质量版 3 轮 **67% 胜率、+45.1pp**；无门版 4 轮仅 50% 胜率、+32.4pp；
- 量拐门挡住 2022-01 价驱动伪景气，等到 9 月量价真动才进场，吃到 2023 大轮。

### 3.3 semiconductor_equipment（量价全程同动，门无损失）

- 轮 1（2020-07 ~ 2022-10，27 月）：+63.1%，超额 +71.7pp；
- 轮 2（2024-06 ~ 2026-08，20 月）：+255.0%，超额 +235.9pp——组合最大单笔；
- 量拐门与无门版完全一致（全程量价齐升），说明量拐门对"量价同动"产品不产生入场损失。

## 4. battery vs transformer 的本质差异

| 维度 | battery | transformer |
| :-- | :-- | :-- |
| 金额转正时的量 | 滞后 5 个月（价先涨） | 不动（假涨） |
| 价驱动阶段性质 | 真涨、量慢半拍 | 伪景气、量没跟 |
| 量拐门效果 | 白等、少赚（受害） | 躲坑（受益） |
| 量化（quality−base delta） | −20.8pp | +12.7pp |

根因见 21 号文档 §5：量拐门 = 等"量、金额都转正"才入场，筛掉"金额先涨（价驱动）、
量未跟"的早期涨幅；量价同动产品代价小且筛伪景气，金额领先产品代价大。分类轴
`mode=价驱动` 已证伪（21 号文档 §6），按产品细分质量门仍为后续研究（METHODOLOGY §8 第 5 条）。

## 6. 实战演练（三层叠加）

等权回测只验证"出口择时信号本身"，实战 = **择时信号 + 竞争力过滤 + 三层信号选池**
三层叠加。其中三层信号仅有 2026-05~07 快照（资金/财报腿无历史月度序列落盘），只能
做"当下"演练；可历史回测的实战层是择时信号 + 竞争力过滤（静态分层）。

### 6.1 竞争力过滤（可历史回测）

真实剔除名单（`load_quality_layers`，最新年报静态分层套历史）：

| 产品 | 剔除 | 保留 | quality → quality_filter 超额 |
| :-- | :-- | :-- | :-- |
| battery | 欣旺达、孚能科技（亏损型） | 宁德/亿纬/国轩（3 家） | +28.2pp → **+49.3pp** |
| transformer | 明阳电气、特变电工、中国西电（低竞争力） | 思源/华明/金盘（3 家） | +45.1pp → **+62.1pp** |

两主仓均显著提升；但**非普适**：cathode_material 过滤后下降（+22.7→+14.2pp）、
solar_cell 被清空只剩 1 家转亏——印证竞争力过滤是"弱正向、51% 产品更优"的精化层，
非强制门（17 号文档 §5.4）。

### 6.2 三层信号选池（2026-07 快照）

**battery（5 家）**：

| 公司 | 评级 | 依据 |
| :-- | :-- | :-- |
| 宁德时代 | **A强机会** | 量价齐升 + 资金正 + 真扩张 |
| 国轩高科 | C兑现中 | 出口+财报正，资金平 |
| 孚能科技 | D前瞻观察 | 营收 −17%、净利 −145% |
| 欣旺达 | D前瞻观察 | 增收不增利（净利 −30%） |
| 亿纬锂能 | **回避·顶背离⚠** | 出口强正但资金负、融资负 |

**transformer（6 家，段级信号，部分公司多段各一行）**：

| 公司 | 评级 | 依据 |
| :-- | :-- | :-- |
| 思源电气 | **A强机会** | 量价齐升 + 资金正 + 真扩张 |
| 华明装备 | C兑现中 | 资金负 |
| 金盘科技 | C兑现中 | 资金平 |
| 明阳电气 | D前瞻观察 | 营收 −26%、净利 −72% |
| 特变电工 | D前瞻观察 | 增收不增利（净利 −20%） |
| 中国西电 | **回避·顶背离⚠** | 出口仍强但主力 −5%、融资 −11% |

### 6.3 叠加后的实战持仓（2026-07）

- **只做**：battery → 宁德时代；transformer → 思源电气（同时过"三层信号 A 档 +
  竞争力正常"双重筛选）；
- **回避**：亿纬锂能、中国西电（顶背离——出口仍强但资金在撤）；欣旺达/孚能/明阳/
  特变（D 档 + 亏损/低竞争力）；
- **对比等权回测**：回测"全买 5/6 家"会把顶背离/亏损股平均进去，实战选池的价值正是
  把它们剔除。等权回测收益 = 实战的下界（不含选股增益）。

## 7. 诚实局限

1. 本文是**事后复盘**——收益是事后统计，规则本身无未来函数（确认月数、3MMA、量拐
   均为当月可得滞后量）；
2. 量拐门非普适：battery 类"金额领先"产品会晚进场少赚，当前无精准分类轴，统一量拐门
   是"全局最优、局部有代价"的选择。
