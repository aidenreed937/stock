# 36 地产复苏 → 钛白粉传导框架与三公司对比（2026-10）

> **版本**：2026-10 · 范围：地产周期向钛白粉及相关材料传导的研究框架（用户口述框架登记）
> + 龙佰集团 / 钛能化学（中核钛白）/ 安纳达 三公司对比。
> **数据边界**：财务/H8 出口/弹性 = 本地 Curated（fina_indicator、income、overseas_revenue mart、

> 现有出口侧结论见 35 号（钛白粉=产品级 V 型复苏，p36 97，价差 2026-09 年内低点）。

## 0. 核心修正（vs 传统"地产周期股"框架）

1. **新房开工不再是领先需求**：二手房成交 ↑ → 装修 ↑ → 涂料 ↑ → 钛白粉 ↑，早于 新房开工 → 水泥/钢材/玻璃；
2. 钛白粉是"**地产（装修/涂料腿）+ 出口 + 汽车/工业/存量更新**"的混合周期，不是纯地产品种；
3. 本轮大概率"**量不强、价与利润弹性强**"：需求温和 + 供给出清 → 价差扩张 > 销量增长；
4. 确认信号不看"地产复苏"整体，看四条件：**销售筑底 + 钛白粉库存见底 + 产品价格企稳 + 行业盈利恢复**。

## 1. 地产阶段与传导顺序（用户框架）

| 阶段 | 时间判断 | 房地产 | 最先受益 |
| :-- | :-- | :-- | :-- |
| 深度出清 | 2024-2026 | 销售/开工继续下降，库存收缩 | 供给出清 |
| 筑底 | 2026-2027 | 销售跌幅收窄 | 二手房、装修 |
| 弱复苏 | 2027-2028 | 核心城市改善 | 涂料、家居、家电 |
| 扩散 | 2028-2030 | 部分城市地产链恢复 | 建材、设备 |
| 新常态 | 2030+ | 低增速/分化 | 存量住宅更新 |

当前判定：**仍处出清尾部**（2026 年 1-7 月开发投资 -19.2%、新开工 -24.0%、销售 -11.8%，但待售面积 -0.8% = 供给收缩）——"需求未起、供给已缩"正是周期利润弹性酝酿阶段（来源：国家统计局，外部）。

## 4. 结论

1. **进攻弹性首选：钛能化学（中核钛白）**——可投集合内弹性第一（+8.04%）、H8 exp 84% 纯度最高、A 双正、52 周位置最低（0.05）：最贴合"地产装修/涂料腿 + 出口 + 价差修复"逻辑，也最受益于"量不强、价利强"；
2. **龙头防御/行业确认锚：龙佰集团**——成本与氯化法护城河最强、海外占比最高，但当前利润未兑现（净利 -39.1% → 弹性 -5.61%）：等 Q3 净利转正再谈配置（它是"行业级确认"信号，不是短弹性标的）；
3. **安纳达**：弹性第二但属扭亏型（FY25 亏损 → 硬门排除）：只作观察，Q3 确认且年报质量层更新为正常后可升级；
4. **国城矿业**（毛利 54%、ROE 30%）为铅锌+钛混合业务，exp 仅 30%，不作钛白粉主线；
5. 跟踪锚点（2026-09/10）：8 月出口量价（9/20 GACC）、9-10 月硫酸/钛精矿/钛白粉价格与价差、Q3 财报（龙佰净利转正 = 行业确认；钛能/安纳达利润趋势）。
