## 1. 三腿框架总览

```
腿 1：产业事实（海关出口量价）
  领先 3-9 个月 | 识别候选行业 + 拐点预警 | 月度 T+20

腿 2：资金吸筹（主力净流入 × 价格突破）★新增
  右侧启动时机 | 识别进场点 | 日频

腿 3：财报量价齐升（TTM 营收+净利双正；毛利率扩张型不适用）
  事后质检 | 持有/放弃 | 季度 T+40~80
```

**三腿各有分工，缺一不可**：腿 1 回答"哪些行业基本面在改善"（候选池），
腿 2 回答"何时进场"（时机），腿 3 回答"兑现了没有"（持有/放弃）。

## 2. 腿 2 信号定义与实证

### 信号定义（量价资金共振）

```
右侧启动信号 = 资金吸筹20日 AND 突破60日高
  资金吸筹20日 = 主力净流入 20 日累计 > 0（net_mf_amount 行业聚合）
  突破60日高   = 收盘价 >= 60 日滚动最高
```

### 全样本有效性（2014-2026，6749 次信号）

| 指标 | 信号后中位 | 基准 |
| :--- | :--- | :--- |
| 后 20 日 | **+15.9%**（65% 为正） | +0.3% |
| 后 60 日 | **+43.9%**（78% 为正） | +0.0% |

> **⚠ 此表是全样本（含 2015 牛市/2018 熊市），存在严重乐观偏差，已被 2020 后
> 子样本证伪——见下方"2020 后强度失效实证"，本节数字仅作历史参考，不作为
> 当前信号有效性依据。**

### 2020 后强度失效实证（关键修正，2026-09 复核）

注册制/量化时代（2020 起）所有"突破新高 + 资金流入"组合的**超额收益全部为负**：

| 信号定义 | 样本 | 超额120日 | >0占比 |
| :--- | :--- | :--- | :--- |
| 突破60日高+资金20日流入 | 3958 | **-1.2%** | 46.6% |
| 突破60日高+资金60日流入 | 1707 | -1.9% | 45.7% |
| 突破120日高+资金20日流入 | 2671 | -0.9% | 48.0% |
| 突破120日高+资金60日流入 | 1333 | -2.3% | 45.4% |
| 突破250日高+资金60日流入 | 998 | **-3.4%** | 43.9% |

**反直觉规律：突破越高、资金流入越久，信号反而越差**（-1.2% → -3.4%）——
"创 250 日新高"意味着行业已大涨（突破 60 日高的样本前 60 日涨幅基本 >35%），
此时的突破+流入是**末端接盘信号**，不是上升趋势确认。

分层检验同样无效：拥挤度 <40 仍 -1.1%、40-70 -0.4%、≥70 -1.8%；前 60 日涨幅
分层无一为正。

**结论：单腿"突破+资金"不是强度指标，而是时点指标**——只说明"价格已启动、资金
在参与"，无法区分启动初期与末端接盘。2020 后单用它必然是负超额。

**真正的"足够强度" = 量价信号与基本面拐点的共振时序**（见 §4）：
基本面拐点（出口转正）±3 月窗口内出现的突破+资金才有意义（+2.7%~+3.9%）；
脱离基本面窗口的突破+资金即使叠加财报兑现也无效（-2.4%）。

### 分行业强弱（信号后 60 日中位收益，全样本历史参考）

| 档位 | 行业 |
| :--- | :--- |
| 最强 | 通信设备 +428%、电池 +274%、贵金属 +227%、小金属 +145%、半导体 +90% |

## 3. 事件对齐：吸筹信号领先出口拐点约 7 个月（核心发现）

对 23 个出口可靠前瞻行业的 140 次出口拐点事件，找拐点 ±12 月窗口内首个吸筹信号：

| 统计量 | 结果 |
| :--- | :--- |
| 拐点窗口内出现吸筹信号比例 | 79.3%（111/140） |
| **吸筹相对出口拐点时点** | **中位提前 7 个月**（均值 -5.2 月） |
| 提前（≤-1 月）占比 | **75.7%** |
| 同步（0~1 月） | 7.2% |
| 滞后（≥2 月） | 17.1% |

**按梯队细分**（05 文档分类）：

| 梯队 | 吸筹中位提前量 | 提前占比 |
| :--- | :--- | :--- |
| 一梯队（真抢跑） | -7 个月 | 79% |
| 二梯队（假抢跑） | -6 个月 | 80% |
| 三梯队（无抢跑） | **-9 个月** | 76% |
| 其他 | -5.5 个月 | 69% |

### 解读

1. **资金吸筹是出口拐点之前的信号，不是之后**：中位提前 7 个月——资金通过订单/
   产业链调研在出口数据转正前就已进场，出口确认时吸筹已完成（与 05 文档"资金
   提前 3-6 个月定价"互相印证，吸筹腿捕捉的是更早的建仓段）。
2. **三梯队都提前**：连"资金滞后"的三梯队（其他电源/半导体/航海装备）吸筹也提前
   9 个月——说明**吸筹腿对所有梯队都领先于出口拐点**，是比出口数据更早的时机信号。
3. **警告（窗口截断）**：拐点前 6 月内出现吸筹的样本中，提前/同步/滞后约 5:1.5:3.5——
   部分"提前"可能来自 ±12 月窗口的截断（吸筹在 -12 月前已发生）；保守解读为
   **吸筹普遍早于或同步于出口拐点，而非晚于**。

> **2026-10 案例实证（光模块/通信设备 2025）**：§3"吸筹领先出口拐点约 7 个月"
> 的机制在光模块案例完整复现——腿2（资金右侧启动）在 **2025-04-10 起**（关税
> 低点后首个吸筹+突破窗口）触发，领先"出口量价齐升确认"（2025-11，价格 yoy
> 转正）约 **7 个月**；而量价齐升确认时通信设备指数已较 2025-04-30 低点
> **+126.7%**（2618 → 5935）。结论：**腿2 是解决"基本面确认滞后"的入场腿**，
> 量价齐升只作持有增强/验证（10 文档 §8.3 边界注）；科技景气行业的入场前兆
> 组合 = 量驱动转正 + 价格跌幅收窄 + 财报 TTM 斜率抬头（2025 年 4-8 月可观测），
> 与腿2 资金右侧启动共振。

## 4. 三腿组合实证：AND 共振是唯一有效信号（2026-09 验证）

对"资金持续吸筹 → 景气持续 → 财报兑现 → 资金接盘"的因果链逐环验证
（超额收益 = 信号后 120 日收益 − 市场同期行业中位）：

### 环 1：吸筹 → 出口景气持续上升（成立）

吸筹信号后出口 3MMA yoy 中位变化：信号时 7.8% → +3 月 11.3% → +6 月 10.9% →
+9 月 9.9%，**未来 > 信号时占比约 55-57%**——资金持续吸筹的行业，后期景气度
中位持续上升（与"资金选择后续景气行业"一致）。

### 环 2：财报兑现 → 资金接盘（只在出口拐点窗内成立，关键修正）

2020 后样本（注册制/量化时代），信号后 120 日超额收益：

| 信号组合 | 样本 | 超额120日 | >0占比 |
| :--- | :--- | :--- | :--- |
| **三腿共振（出口拐点窗 ±3月 + 吸筹 + 财报兑现）** | 119 | **+2.7%** | **62.4%** |
| 出口拐点窗 + 吸筹（未看财报） | 261 | +3.9% | 64.4% |
| 吸筹 + 财报兑现（但不在出口拐点窗） | 2087 | **-2.4%** | 42.8% |
| 全部吸筹信号（对照） | 3973 | -1.3% | 46.2% |
| 财报兑现事件（全行业对照，无吸筹约束） | 289 | 0.0% | ~50% |

**结论（修正"资金接盘"假设）**：

1. **三腿 AND 共振是唯一有效组合**：出口拐点窗内吸筹 + 财报兑现 → 超额 +2.7%、
   62.4% 胜率。任何单腿或两腿组合均无效或为负。
2. **"资金接盘"的前提是吸筹发生在出口拐点（基本面确认）附近**：脱离出口拐点的
   "吸筹+财报兑现"超额 -2.4%——那种兑现已被市场充分预期，资金不会接盘。
3. **单腿吸筹在 2020 后已失效**：全部吸筹信号超额 -1.3%，分年度 2021/2022/2025/2026
   均为负——简单的"突破 60 日高 + 资金流入"已被注册制/量化时代充分套利，
   必须叠加基本面腿（出口拐点）才能恢复有效性。
4. **原始线性链不成立**：不是"资金做 → 景气 → 兑现 → 接盘"的单向传导，而是
   **基本面拐点（腿1）是必要条件，资金（腿2）是放大器，兑现（腿3）是过滤器**。

### 兑现类型区分：量价齐升 vs 毛利率扩张（关键前提，2026-09 补充）

腿 3 的"财报兑现"必须严格限定为**量价齐升型**（需求驱动），不能混入
**毛利率扩张型**（成本/价差驱动）。判定与适用性：

| 兑现类型 | 判定 | 驱动机制 | 是否适用出口框架 |
| :--- | :--- | :--- | :--- |
| **量价齐升**（需求驱动） | 营收 TTM 转正 且 净利 TTM 转正 | 出口/需求复苏 | ✅ 适用（三腿共振） |
| **毛利率扩张**（成本/价差驱动） | 营收未转正 + 净利转正 + 毛利率抬升 | 油价/原料成本/加工价差 | ❌ 不适用（用价格类信号，如裂解价差/油价） |

**逻辑闭环**：腿 1 是出口（需求侧信号）→ 腿 3 必须对应需求驱动的兑现（营收转正）
才有意义。若只凭净利转正判"兑现"，会把成本驱动型行业误纳入出口框架——
它们的盈利不由出口决定，出口数据无法前瞻。

**炼化及贸易（750300）案例（伪相关警示）**：

| 指标 | 2026 中报 |
| :--- | :--- |
| 营收 TTM | -0.5%（未转正） |
| 净利 TTM | **+22.5%**（已转正） |
| 毛利率 TTM | **18.87%**（近年新高，前值 17.4-18.3%） |

- 净利兑现靠**毛利率扩张**（油价下跌 → 炼化成本下降 → 裂解价差改善），
  出口止于 2024-12 且占比小——**兑现不由出口驱动**。
- 其一致率 1.0 是**油价周期伪相关**：油价涨同时推高出口金额（价涨）与炼化利润
  （库存收益），不是"出口领先财报"的机制，而是共同被油价驱动。
- 正确前瞻信号是裂解价差/原油价格，不是海关出口；按量价齐升口径
  腿 3 未兑现的判定是正确的，三腿共振不应也不会选它。

## 4.5 出口量价分离核查：金额信号的价格污染与数量信号修复（2026-09 落地）

> 背景：腿 1 使用出口金额 yoy 作为基本面拐点信号。2026-09 复核发现金额信号存在
> 两处系统性问题，本节为核查结果、修复落地与使用规则。
> 复现脚本：`scratch/volume_price_check.py`（输出 `scratch/volume_price_check_products.csv`、
> `scratch/volume_price_check_industry.csv`）；数据：`customs_trade` 黄金表
> （2016-01 ~ 2026-07，export 方向，HS 版本桥接 + 3MMA yoy，与 §4 同口径）。

### 问题 1：数量单位混用 → export_volume 行业聚合不可信

- 106 个产品中 **42 个跨 HS/数据源混用计量单位**（`units`/`台`/`个`/`kg`/`千克`/
  `辆`/`艘`/`块`/`sqm`），直接对 `export_volume` 求和得到无意义的混合单位数量；
- 同义单位归一（`千克`→`kg`、`台/个/辆/艘/块/件/套/只`→`units`）后，**真混用剩 4 个**：
  `semiconductor_equipment`（units vs kg）、`pcb`（kg vs 块）、`auto_glass`（sqm vs 千克）、
  `robot_vacuum`（units vs `-`）——这些产品的数量跨 HS 不可加总；
- **修复**：`customs_trade` 黄金表统一产出 `quantity_unit_norm` / `unit_known` /
  `volume_aggregable` 三列（`transform.py` 落地）；`volume_aggregable=False` 的产品行
  数量不得参与行业加总。同义单位产品（如 `wind_parts`/`anode_material` 的 kg/千克）
  归一后仍可安全加总。

> ⚠ **2026-09 修订（10 文档 §8.1）**：上段"真混用剩 4 个"低估了问题——UN Comtrade
> 段计量单位使用 HS 计量单位代码（`u`/`l`/`m²`/`条`）未被 `UNIT_CANONICAL` 收录，
> 导致 Comtrade 段 58% 行被判未知单位、`volume_aggregable` 全表仅 1 个产品 True。
> 修复已落地 `volume_price.py`：补 `u→units`/`l→l`/`m²→sqm`/`条→units` 映射
> （逐码对照 GACC 中文单位验证一致），且 0 量占位行（N/A/mixed）不参与单位判定。
> 修复后 **94/106 产品数量可加总**，真混用剩 12 个（半导体设备/PCB/轮胎/汽车件
> kg vs units、电池隔膜 kg vs m、平板玻璃 kg vs sqm、精炼产品 kg vs l vs `-`、
> 扫地机器人 units vs `-`、白银 kg vs 克）。黄金表三列为旧口径，下次 replay 刷新；
> 量价分解面板见 `data/analytics/industry/customs_l2_volume_price_monthly.parquet`。

### 问题 2：金额信号被价格主导（21/41 行业，corr < 0.5）

行业级金额yoy × 数量yoy 相关度（数量经单位归一 + 混用置空口径，Pearson）：

| 分组（判定） | 行业（corr） |
| :--- | :--- |
| **价格主导⚠（21）** | 乘用车 -0.07、医疗器械 +0.04、航海装备 +0.15、黑色家电 +0.15、厨卫电器 +0.16、半导体 +0.17、摩托车及其他 +0.19、电网设备 +0.20、风电设备 +0.23、计算机设备 +0.26、中药 +0.27、消费电子 +0.28、小家电 +0.28、电池 +0.29、化学制药 +0.30、家居用品 +0.33、其他电源设备 +0.37、服装家纺 +0.37、通用设备 +0.41、玻璃玻纤 +0.41、农化制品 +0.45 |
| **量价一致（18）** | 化学纤维 +0.52、商用车 +0.54、炼化及贸易 +0.55、汽车零部件 +0.60、白色家电 +0.61、工程机械 +0.63、装修建材 +0.74、通信设备 +0.74、普钢 +0.75、煤炭开采 +0.82、纺织制造 +0.84、光学光电子 +0.85、焦炭 +0.86、化学原料 +0.86、特钢 +0.87、渔业 +0.90、工业金属 +0.91、贵金属 +0.97 |
| **数量信号不可用/受限（2）** | 元件（混用产品置空后样本不足）；光伏设备（2016-2021 数量缺失 + 跨 HS 版本数量断裂约 460 倍，全周期数量不可信——见 07 §4.2；版本稳定期 2022+ corr=0.667） |

**与上轮结论的差异（精化）**：上轮"10 个 nan 行业（光伏/电网/半导体等）"实为
数量含 0 值 → 3MMA yoy 除零（±inf）→ `corr` 退化为 NaN。修正过滤非有限值后，
这些行业大多可算出相关度：**电网/风电/计算机/中药/其他电源均为价格主导
（0.20~0.37），通信/装修建材/商用车为量价一致（0.54~0.74）**；半导体数量混用
置空后相关度仍 +0.17（价格主导，仅剩 IC 数量）。光伏设备的"全周期 0.074"是
数量缺失 + 版本断裂的伪影，版本稳定期真实 corr=0.667（量价一致）且量价强反向
（-0.952，跌价刺激放量）——金额对价格敏感来自**价格周期主导 + 量价反向**。
真正数量信号不可用的只有元件；光伏数量只能版本内比较。

**使用规则**：

1. **金额 yoy 仍是主口径，但 21 个价格主导行业需加"价格污染"标注**——金额上涨可能
   纯由价格驱动（如光伏组件 ASP 波动），不构成需求拐点，这些行业的一致率结论打折；
2. **数量信号落地前提**：先过滤 `volume_aggregable=False` 的产品行，否则
   `export_volume` 行业聚合不可信；聚合时优先用黄金表三列标注；
3. **炼化及贸易 corr=0.55 在 0.5 阈值之上，但机制判定优先**——§4 炼化案例已证伪
   一致率 1.0（油价周期伪相关），阈值与机制双重校验，以机制为准；
4. **ASP 是待挖掘的第三维**：光伏设备金额与数量 yoy 经常背离（2026-03 金额 +68% vs
   数量 +42%；ASP 41.85→54.8→52.6→45.68 美元），金额波动主要来自组件价格——
   **ASP 转正可作"价格底"信号**，与数量拐点合成"量价齐升"完整判断（待验证项）。

## 5. 三腿组合的使用规则（2026-09 修正版）

```
正确用法（三腿 AND，缺一不可）：
  腿1 出口拐点 ±3 月窗口（基本面确认，时序锚）
  × 腿2 资金吸筹 + 突破 60 日高（时机确认）
  × 腿3 财报量价齐升（营收+净利 TTM 双正；毛利率扩张型不适用）
  → 超额 +2.7% / 62% 胜率（2020 后样本）

顺序：腿1 定池（月度）→ 腿2 定时机（日频）→ 腿3 定去留（季度）
禁止：单用腿2（-1.3%）、非拐点窗的腿2+腿3（-2.4%）
```

- **一梯队行业（光伏/工程机械/白电/贵金属）**：出口拐点已晚（资金提前定价），
  以腿 2 吸筹捕捉启动点，但**必须落在出口拐点 ±3 月窗口内**（06 §4 实证），
  腿 3 兑现后持有 3-8 个月（05 文档实证）。
- **三梯队行业（其他电源/半导体/航海装备）**：出口拐点本身可用（资金滞后），
  吸筹信号作为提前确认；腿 2 + 腿 1 双确认更稳。
- **资源品（煤/焦炭/炼化）**：腿 2 信号可用但需叠加 05 止盈规则——
  吸筹后一旦利润增速跌穿 30% 立即清仓（二梯队抢跑后回吐 -28% 的教训）。
- **银行/保险/旅游等**：腿 2 不适用（信号后收益 ≈ 0 或为负），只用腿 1/腿 3。

## 6. 使用边界

1. **腿 2 是量价信号不是基本面信号**：识别"资金正在买 + 价格已启动"，不解释为什么；
   与腿 1 事件对齐证明其领先性，但个股层面需防主力资金"对倒/出货"伪装吸筹
   （行业聚合可部分缓解）。
2. **自相关与假信号**：日频信号在强趋势中连续触发，需月度去重；突破 60 日高在
   高位震荡市会产生假突破，建议叠加拥挤度（tcr）过滤——拥挤度高位一票否决。
3. **样本窗口与时点依赖**：全样本（2014-2026）含 2015 牛市/2018 熊市等极端段，
   **§2 早期 +44% 中位收益已被 2020 后子样本证伪**（2020 后单腿吸筹超额 -1.2%，
   所有突破强度组合均为负）；唯一有效的是三腿共振（+2.7%，2020 后样本）。
   信号有效性随市场结构变化（注册制/量化套利），需季度复核三腿共振是否持续有效。
4. **腿 2 数据源**：`moneyflow` 主力资金（tushare），2010 起全历史；行业聚合按
   当前 L2 成分（canonical），历史成分变动未回溯——2020 前行业归属略有偏差。
5. **三腿共振样本量**：拐点窗 ±3 月内吸筹仅 119-261 个事件，胜率 62-64% 的
   置信区间较宽；随出口回填与 GACC 扩展后应重估。
