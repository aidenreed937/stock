# 钛白粉投影模型绝对净利校准设计（2026-09-20）

> 状态：设计稿（未实施）。触发事件：模型 H1 演算 vs 真实中报对账发现系统性偏差（钛能 -6.61 亿 / H1），current_spot 单点年化被质疑不可靠。

## 1. 问题定义与量化证据

### 1.1 现象

| 公司 | 模型 H1 演算归母 | 实际中报 H1 | 偏差 | 年化偏差 |
| :--- | ---: | ---: | ---: | ---: |
| 龙佰集团 | 8.41 亿 | 8.44 亿 | -0.03 亿（-0.4%） | 约 0 |
| 钛能化学 | -2.41 亿 | 4.20 亿 | **-6.61 亿** | 约 -13 亿 |

模型 current_spot 年化：龙佰 +3.06 亿 / 钛能 -8.65 亿（as_of=2026-09-20）。

### 1.2 根因（基于对账证据）

1. **成本栈偏高（钛能主因）**：模型用“攀西 46% 坑口 + 350 运费”与“湖北 98% 冶炼酸”作为外购原料价，固定成本 7,000 元/吨（含折旧）。H1 逐月重演钛能硫酸法单位毛利全月为负，而实际中报 +4.2 亿证明钛能实际单位完全成本显著低于模型口径（或实际售价高于国内出厂价：出口溢价、产品结构、长协价）。
2. **销量/ASP 假设偏保守**：模型按 55 万吨 × 78% 开工率计 H1 营收约 36 亿，实际中报营收 45.57 亿（差约 21%）；全部销量按国内出厂价计价，未体现钛能 50%+ 出口的实际均价。
3. **副业低估**：钛能副业（磷酸铁/磷矿/贸易）用 fina_mainbz 近 3 年年报中位数（年化毛利约 1.71 亿），实际半年贡献更大。
4. **单点年化放大误差**：current_spot 用“单日/单月快照价 × 全年”，把瞬时价差放大为全年盈亏，对出口占比高的公司误差放大。
5. **单季费用切分失真（龙佰）**：期间费用/财务/税按比例年化折半，而实际在季度间集中（龙佰模型 Q1/Q2 主营毛利 6.72/11.25 亿 vs 实际单季净利 1.87/6.57 亿）。

### 1.3 定位修正

- 模型保留用途：**弹性/排序工具**（每 100 元/吨价差对 EPS 的边际影响、情景相对比较）。
- 模型不再承担：**绝对季度/年度盈亏预测**，除非通过校准与对账门禁（本设计 Phase 1-2）。

## 2. 目标与验收标准

### 2.1 目标

1. 模型绝对归母净利对最新实际财报偏差收敛到 ±10%（或 ±1.5 亿，取较宽者）；
2. 输出季度口径（Q1-Q4 + FY），单季费用切分不再用年化折半；
3. 每次运行自动对账并标记可靠性，防止误用。

### 2.2 验收标准

- 2026 H1 重演：钛能偏差从 -6.61 亿收敛到 ±1.5 亿内；龙佰维持 ±5% 内；
- 滚动回测（已定样本窗口 2025Q1~2026Q2）：季度归母净利 MAPE < 15%，方向准确率 ≥ 80%。**注意**：本地现货序列 2025-09 才起（见 3.2），若 2025Q1/Q2 现货未补采，实际可行窗口为 **2025Q3~2026Q2（4 期）**，验收按可行窗口执行并标注；
- manifest 新增 `reconciliation` 字段：`{model_net, actual_net, bias_pct, flag}`，flag ∈ `ok | model_abs_unreliable`。

## 4. 公式设计

### 4.1 出口加权计价（逐月，Phase 1；出口权重已定动态化）

对每个月份 m：

```
p_eff,m = w_exp × ASP_exp,m × FX_m + (1 − w_exp) × p_dom,m
```

- `ASP_exp,m`：GACC 月度离岸均价（USD/吨）；
- `FX_m`：月均 USD/CNY；
- `w_exp`：**动态**，取 fina_mainbz 地区拆分最近报告期的“国外/国际收入 ÷ 总营收”（报告期为半年报/年报粒度时，季度外推可用 GACC 月度“出口量 ÷ 表观消费量”比例修正，或沿用最近报告期并标注时效）；
- `p_dom,m`：国内出厂月均；
- 应用范围：硫酸法、氯化法分部售价均替换为 `p_eff,m`（氯化法叠加 premium）。
- 口径注意：若采用“钛白粉分部出口占比”（trading_gates 口径，钛能约 50%+），则 w_exp 只作用于钛白粉分部；两种口径二选一并动态化（见 3.2 实测表后提示）。

### 4.2 per-company 成本校准（Phase 1，校准样本已定 2025Q1~2026Q2 滚动回测）

将成本公式参数化并加入公司级校准系数：

```
unit_cost_c,m = 2.3 × (α_c × ore_plant,m) + 3 × (β_c × acid_m) + fixed_cost_c − byproduct_c
```

- 校准对象：`α_c`（矿价系数）、`β_c`（酸价系数）、`fixed_cost_c`；
- 初始估计（以 2026 H1 实际毛利率 + 主营构成为样本）：
  - 钛能：`fixed_cost` 7,000 → 待估（预期 5,800~6,200），α/β ∈ [0.85, 1.00]；
  - 龙佰：保持现状（H1 已验证 -0.4%），仅把氯化法 `full_cost_approx=13,000` 与 `cost_models.yaml` 氯化法公式联动（顺带解决复核问题 9）；
- 估计方法：**2025Q1~2026Q2 滚动回测 + 交叉验证**——按季度滚动划分训练/验证窗口，拟合最近 N 期实际季度毛利，取验证集最优参数；样本起点受现货数据约束（见 3.2-5），未补采时窗口收缩为 2025Q3~2026Q2 并标注；
- 输出：校准系数写入 `company_projections.yaml`（companies.*.calibration），manifest 记录系数版本。

### 4.3 副业实际化（Phase 1）

```
aux_rev / aux_gp ← fina_mainbz 最新报告期（2026-06-30）逐季值（× 当期占比）
缺失/季报未披露 → 回退近 3 年年报中位数
```

### 4.4 季度化引擎（Phase 2）

- segment 改为月频构建：`vol_m = capacity × util_m / 12`，价格/成本用月频序列；
- 季度输出：`Q1..Q4 + FY`；
- 期间费用：按最新季度实际 × 情景去杠杆比例（不再年化折半）；
- 所得税：`tax = max(0, op × 实际税率)`，实际税率由 income 表最近报告期估计；
- 少数股东损益：`归母净利 = 净利 × 归母比例`（income 表 n_income_attr_p / n_income 估计）；
- current_spot 保留为“弹性快照”，明确标注不得作绝对预测。

### 4.5 对账门禁（Phase 0，先行）

```
|model_net − actual_net| / |actual_net| > 20% 且 > 2 亿
  → manifest.reconciliation.flag = "model_abs_unreliable"
  → 报告对应数字自动附加“仅弹性口径，绝对盈亏以财报/实际锚定为准”
```

## 7. 风险与对策

1. **过拟合单期财报**：只用 2026 H1 标定可能把一次性因素学进去 → 用 2025Q1~2026Q2 滚动回测（现货不足时收缩窗口），系数取交叉验证最优，且保留人工上限/下限。
2. **出口权重与退税率不确定**：权重做成参数并做敏感性（±10 个百分点）；出口退税（约 13%）对利润表的影响单列说明，不混入单价。
3. **数据缺口（1-3 月矿价、1-4 月开工率、FX）**：先插值/固定假设，运行期打“assumption”标记；补采后再校准一次。
4. **季度费用季节性**：按季实际摊销后仍可能有 Q4 奖金/减值等一次性项 → 对账门禁阈值对 Q4 单独放宽并标注。
